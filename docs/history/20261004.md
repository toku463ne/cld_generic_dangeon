- **段階8 は「休める場所を建てる」から逆算して切る（ユーザ判断）。** 前から順（地形 → 資源 → 採取 → スキル → 加工）では、使い道の無い段階が「動かない」で続く。値打ちが値付けに見える物を先に決め、要る地形・資源・スキルだけを入れる。候補は建てる・防寒着（皮が要り段階10 の後）・保存食（蓄えの余地は2度の数えでほぼ 0）・前から順、の4つで、建てるを選んだ。
