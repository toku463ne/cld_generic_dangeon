## 1-2e: 実装（意図と、決め直すきっかけ）

- `Config.Recheck`（既定 300）を足し、身体は決めた手を**意図**として持つ（`engine/intent.go`）。決め直すのは、足元の食料の有無・見えている食料の集合・次の一歩が陸の外か別の地域・食料への歩きが縮まない・`Recheck` tick 経過、のどれかが真になった tick だけ。決め直しは `decide` の1か所で、値付けも同点の破り方も 1-2r のまま。`Recheck` 0 は 1-2r と同じ世界で、指紋が一致する（条件 `everytick`）。`random`・`blind`・`restless`・`straightback` の各条件も `Recheck` 0 にし、それぞれの段階の指紋のまま。
- **「食料へ歩く」意図の定義を途中で直した。** 最初は「選んだ手の死ぬ確率を、見えている食料へ歩く続きで読んだ」なら食料へ歩く意図とした。制約の地図では決定の 22% が「道が縮まない」で決め直しになり、その 97% が同じ手を選び直していた。**食料の多い地域では全部の手の死ぬ確率が 0 に丸まり、向きを保つ同点の破り方が食料から離れる手を選ぶ**——死ぬ確率は食料へ歩く続きで読んでいても、身体は食料へ向かっていない。そこで、**選んだ一歩がその食料への歩き（`walkTicks`）を 1 tick 縮めるときだけ**食料へ歩く意図とし、そうでなければ向きを保って歩く意図とした。これで決定の割合は 1 シードの試しで平坦 0.055・制約 0.11 になった。
- 「道が縮まない」の判定も、最初の「オクタイル距離が1歩ぶん（`Speed`）縮まない」から、**値付けと同じ目盛り（`walkTicks`、切り上げの tick 数）で 1 tick 縮まない**に直した。前者は値付けより細かく、値付けが同点と見る手を「縮まない」と数えていた。
- 採らなかった形: きっかけを「死ぬ確率の順位が変わりうるか」で判定する（値付けを毎 tick 回すことになり、減らしたいものそのもの）。

## 1-2e: 1回目の測定で平坦な地図の人口が下がり、見え方を身体から見た位置に直す

レポート: [`docs/experiments/20260926-1-2e.md`](../experiments/20260926-1-2e.md)

- 3faa168 で測ると、平坦な地図の 40000 tick の人口が `everytick` との対の差で **−3.17 ± 0.49（有意に低い）**。制約の地図は −6.67 ± 4.39（有意でない）。完了条件を満たさない。
- 1つ目の疑い: **待つが意図として残る。** 待っている身体は何も見え方が変わらないので、`Recheck` まで立ち止まる（待つの割合が 0.00% → 0.12〜0.20%）。`PLAN.md` の意図は3つ（食べる・食料へ歩く・向きを保つ）で待つを含まないので、**待つは 1 tick だけにして決め直す**（きっかけ `waited`）に直した。人口の差は −2.83 ± 0.66 で、原因ではなかった。
- 2つ目: 使い捨てのコードで、意図に従っている tick のうち、その場で値付けしたら意図の手が最善の手の中に無い割合を数えた（3シード、tick 5000〜20000）。平坦な地図で全体 0.39%、**死んだ身体の最後の 1000 tick では 0.82%（2倍）**。その 97% は「今なら見えている食料へ歩くほうが良い」。**食料が視界に入った瞬間は、食料の多い地図では全部の手の死ぬ確率が 0 に丸まって同点になり、向きを保って通り過ぎる。数 tick 後に体力が減ると食料へ歩くほうが良くなるが、見えている食料の集合は変わらないので決め直さない。**
- 直し方: **見え方を、地図の上の位置ではなく身体から見た位置（自分のタイルからのずれ）で持つ。** 食料が見えている間はタイルをまたぐたびに見え方が変わって決め直し、何も見えていなければまたいでも変わらない。知覚を身体中心にするのは知覚の定義として自然で、体力の帯のような閾値を足さずに済む。直したあとの差は平坦 −0.17 ± 0.59・制約 +0.92 ± 4.42（どちらも有意でない）で、決定の割合は 0.054 → 0.062（平坦）・0.125 → 0.142（制約）。
- 採らなかった形: (1) 体力の帯でも決め直す（閾値。`PLAN.md` の壊してはいけない線）。(2) 死ぬ確率を対数で持って同点を減らす（値付けそのものを変えるので 1-2r の世界が変わる。1段階1規則に反する）。(3) `Recheck` を短くする（食料が視界を通り過ぎるのは 12 tick ほどで、それより短い間隔は毎 tick 決めるのとほとんど変わらない）。
