# 5-4 の事前カウント: 見た相手の位置を覚える余地（`materoom`）

判断は [`docs/history/20261002.md`](../history/20261002.md) の「5-4 の事前カウント」。

## 1. 概要

- 確かめたかったこと: M-1（見た異性の最後の位置を覚え、そこへ向かう手を値付けに足す）の余地。交配できる身体（成人・老人でない・休んでいない・払える）が、視界に相手もおらず要求も届かない時間がどれだけあり、そのとき最近見た相手がまだ見た場所の近くにいるか。個体数の帯ごと（罠は個体数が薄いときに働く）。
- 分かったこと:
  - **交配できる女は、相手が視界にも要求の範囲にもいない標本が 44%**（男は 87〜89%）。ただし交配できる女の標本は男の約 20 分の 1——女はすぐ相手を得て交配できなくなる（M-3 で、相手を得るまで中央値 7 tick）。
  - そのとき 1000 tick 以内に相手を見ていた割合は女 75〜88%、男 73〜84%。**その相手がまだ見た場所の近く（視界＋要求の範囲）にいるのは女 10〜23%、男 24〜34%**。見た場所までは中央値 8〜10 タイル。
  - **個体数が薄いとき（110 未満、制約の崩壊したシード）**: 女で相手がどちらにも無い標本 75%、200 tick 以内に見ていた 29%、まだ近くにいる 10%。
- 読み: 覚えた相手の位置は、たいてい古い——5 回に 4 回は、行ってもそこにいない。罠が働く薄い世界では、覚えている相手そのものが少ない。**M-1 は罠を外す見込みが小さい。** 女の待ちは要求ですでに短い。
- 次にすること: M-1 を入れるか、先に罠そのもの（薄い世界で何が出生を縛っているか）を調べるかをユーザに確かめる。
