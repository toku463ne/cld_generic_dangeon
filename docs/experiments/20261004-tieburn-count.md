# 6-3a の事前カウント: 同点を費やす量で破る余地（`tieburn`）

判断は [`docs/history/20261004.md`](../history/20261004.md) の「同点を費やす量で破る余地」。

## 1. 概要

- 確かめたかったこと: 危険（− 子の値打ち）が同じ手の中から、その手の続きが Window tick に費やす体力の少ないほうを取る規則（`TieSpend`）が、手を変えうる余地。
- 分かったこと:
  - **同点は全員の決定の 54〜55%、休んでいる母の 92%。** 満腹に近い身体は窓の中の危険がほぼ 0 で、手が同点になりやすい。
  - 今の世界では、同点の手の費やす量が違うのは 2.5%（母 8〜9%）、選んだ手が一番費やさない手でないのは 0.1%（母 0.3〜0.4%）。規則だけでは世界はほとんど動かない。
- 読み: 余地は、手の続きの費やす量が違うとき——休める場所で休む続き（6-3）があるとき——に出る。
