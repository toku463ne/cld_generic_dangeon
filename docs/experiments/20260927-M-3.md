# M-3: 交配要求の発信（Requests）

判断は [`docs/history/20260927.md`](../history/20260927.md) の「M-3 の測定」。事前カウントは [mating-count](20260927-mating-count.md)・[request-count](20260927-request-count.md)。

## 1. 概要

- 確かめたかったこと: 交配できて視界に相手がいない身体が交配要求を発信し（要求そのものが同意、5 タイル・100 tick）、受け手が自分の値付けで向かう形で、交配がどれだけ増えるか。`unasked`（3-7）との対の差で読む。
- 分かったこと:
  - **出生が 16〜18% 増えた**（平坦 +833、制約 +699）。予想（数 %）より大きい。**出生の 98% が交配要求で成り立った。**
  - **交配できる女が相手を得るまでが縮んだ**: 交配できる状態の長さの中央値 36〜41 → **7 tick**、出産で終わる割合 85〜88% → **97%**。払えるようになった女が、払えなくなる前（食べられず体力が落ちる・死ぬ）に相手を得るようになった。
  - 餓死も +19〜20%（出生と釣り合う）。個体数は平坦 +6.4 ± 3.4（約 1.9 SE）、制約 +3.5 ± 4.6（有意でない）。成人到達率・女の割合は変わらない。崩壊 0。決定の割合 +0.4〜0.7 ポイント。
  - 申し出の行方の数え（`mating`）は、この世界では視界の外の要求者へ向かう1歩も「申し出」に数えるので（30〜37% が「相手が視界にいなかった」）、事前カウントと直には比べられない。
- 読み: 要求は、払える女が相手を得る待ちを縮め、払えなくなる前に交配を終えさせた。事前カウントでは「待ちは約 40 tick で、縮めても出生はほとんど増えない」と読んだが、待ちのあいだに払えなくなる女（12〜15%）を取りこぼしていたぶんが大きかった。個体数は食料で頭打ちなので、増えた出生は主に入れ替わり（餓死）に回った。
- 次にすること: M-1・M-2（個体の位置を覚える・伝える）の効き目を見直す。要求が出会いを担うようになったので、位置の記憶の余地は小さい見込み。
