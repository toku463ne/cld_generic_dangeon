# 1-2q 数え上げ: 探索性能と生存

判断は [`docs/history/20260924.md`](../history/20260924.md) の「探索性能と生存: 短期の死は食料視認率でほぼ説明がつく」。

## 概要

- 確かめたかったこと: 探索性能を身体ごとの1つの数字として定義し、生存との関係を直接測る（ユーザの依頼）。これまでの変更（視界・向きの持続）は探索を間接的に上げてきたが、探索と生存の関係そのものを数字にしたことがなかった。この結果で、記憶（1-6）を前倒しするかを判断する。
- 分かったこと: **定義で答えが分かれる。** 食料視認率（新しく視界に入る食料の数 / tick）は、次の 1000 tick に死ぬかどうかを、体力そのものとほぼ同じ精度で見分ける（base の AUC: flat 0.83、constrained 0.91。体力は 0.87・0.91）。未踏タイル率（初めて立つタイルの数 / tick）は逆向き（AUC 0.32〜0.33）で、死ぬ直前の身体のほうが新しいタイルを多く踏んでいる。**base では、ある窓の食料視認率はその後の長い寿命をほとんど予測しない**（順位相関 ≈ 0）。死は、個体の持続的な性質ではなく、食料が見えない時期が続くことで起きている。
- 次にすること: 記憶の前倒しを判断する（history 参照）。食料が見えない時期の身体がどこにいるか（地域・縁・混み具合）を数える。

## 条件

| 項目 | 値 |
| --- | --- |
| コミット | 563b25c |
| マップ | flat (64x48) / constrained (64x48) |
| tick 数 | 40000 |
| シード数 | 12（最初のシード 1） |
| 比較対象（base） | blind（視界なし・向きを保たない）、restless（視界あり・向きを保たない） |

**再現方法**:

```
go run ./cmd/count -what explore -map flat -w 64 -h 48 -seeds 12 -ticks 40000
go run ./cmd/count -what explore -map constrained -w 64 -h 48 -seeds 12 -ticks 40000
```

**数え方**:

- **未踏タイル率**: 窓の中で、その身体が生まれてから一度も決定をしたことのないタイルで決定した回数 ÷ 窓の tick 数。
- **食料視認率**: 窓の中で、決定の時点の `Valuation.Seen` にあり、その身体の直前の決定の `Seen` に無かった食料の数 ÷ 窓の tick 数。blind は何も見えないので常に 0。
- **生涯を通した率は取らない。** 全員が tick 0 に生まれ、地図が小さいので、長く生きるほど未踏のタイルが減り、長生きした身体の率が低く出る。代わりに固定の窓（0〜1000・9000〜10000 tick）で率を取り、窓のあとの寿命と比べる。生き残りは打ち切り（40000 tick）の値で順位をつける。
- **次の窓で死ぬか**: 1000 tick ごとの窓を通して生きていた身体について、窓の中の率と窓の終わりの体力が、次の 1000 tick に死ぬかどうかをどれだけ見分けるかを AUC で出す。全区間をシードごとにまとめ、シードで平均する。「死んだ」「生き残った」の数は、身体 × 窓の組の数。
- 身体は ID の順に読み、五分位は安定に並べる（同じシードなら同じレポートになる）。

## 読み方

- **短期の死は、食料視認率でほぼ説明がつく。** base の食料視認率の AUC（0.83・0.91）は、死の直接の原因である体力の AUC（0.87・0.91）とほぼ同じ。「食料が見えない → 食べない → 体力が尽きる」の鎖の最初の輪で、死がほぼ決まっている。ただし食料視認率は、身体の歩き方だけでなく、その場所の食料の密度（他の個体が食べた後か）にも左右される。純粋な「性能」ではなく「出会い」の量。
- **未踏タイル率は探索性能の指標にならない。** base で AUC が 0.5 を下回る（死ぬ直前の身体のほうが新しいタイルを多く踏む）。満ちた身体は食料のそばで留まり、空腹の身体はまっすぐ歩き続けるため、と考えられる（確かめていない）。率が身体の状態の結果になっていて、状態を説明する側に立たない。
- **base では、ある窓の率はその後の長い寿命を予測しない**（flat の両方の窓、constrained の 9000〜10000 で順位相関 ≈ 0）。全員が同じ規則に従うので、持続的に探索の下手な個体はいない。死は、食料が見えない時期が偶然続くことで起きる。例外は constrained の最初の窓（0.56）で、乏しい地域に置かれた身体は見える食料が少なく、早く死ぬ（場所の差であって、個体の差ではない）。
- **条件をまたぐと、探索と生存は一緒に上がる。** 最初の窓の未踏タイル率は blind 0.039 → restless 0.041 → base 0.182（flat）、窓のあとの寿命は 1081 → 4251 → 27861。視界と向きの持続が生存を上げた経路は、探索を上げたことだと読める。
