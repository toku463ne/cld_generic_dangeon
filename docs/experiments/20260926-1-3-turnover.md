# 1-3 数え上げ: 老いが無いのに世代が回る理由（世代交代か、大量死からの再生か）

判断は [`docs/history/20260926.md`](../history/20260926.md) の「1-3: 世代が回る理由」。

## 概要

- 確かめたかったこと: 1-3 の世界で最初の身体が1体も残らないのは、身体が次々に入れ替わる世代交代なのか、一斉に死んで生き残りから増え直すのか。死んだ年齢と、餓死の内訳から切り分ける。
- 分かったこと: **大量死からの再生ではない。** 100 tick ごとの死亡数は分散 ÷ 平均が約 1.1（でたらめに一様な死に方とほぼ同じ）、人口の変動係数は 4%、最小でも平均の 88%。**世代交代だが、老いではなく「子の代金を払ったあとの餓死」で回っている。** 死亡の約 75% は直前 1000 tick 以内に子の代金を払った成人で、払ってから死ぬまでの中央値は約 105 tick。死んだ成人の年齢は 1150〜1700 tick（成人して数百 tick）に固まり、2000 tick を超えて生きている身体は 0.6% しかいない。
- 次にすること: 老いによる死（O8）は急がない。`VISION.md` に足された「死にかけのノードは回復手段が見つからないとき、確率的に子孫を残す行動をとる」の判定を `VISION_CHECKS.md` に足す。

**再現方法**:

```
go run ./cmd/count -what turnover -map flat -w 64 -h 48 -seeds 12 -ticks 40000
go run ./cmd/count -what turnover -map constrained -w 64 -h 48 -seeds 12 -ticks 40000
```

**数え方**: 子が生まれた tick に、その子の両親の「最後に払った tick」と子の数を記録する。死亡は、成人前か、成人なら最後に払ってからの tick が満腹から餓死までの tick 数（1000）以内か、で分ける。死因は1-3 の世界には餓死しか無いので、内訳は「餓死した身体が直前に何をしていたか」の分け方である。

## 読み方

- **一斉には死んでいない。** 死亡数の分散 ÷ 平均が 1 に近く（1.11・1.13）、一番多い 100 tick でも平均の 2 倍。人口は平均の ±4% で揺れるだけ。立ち上がり（tick 2000 前後の谷）を除けば、大量死と再生の繰り返しは無い。
- **大人を殺しているのは子の代金。** 払った tick の親の体力の中央値は 45〜46（満腹の半分以下）で、25 を払うと残りは約 20（200 tick 分）。払ってから死ぬまでの中央値は約 105 tick、90% 点は 220〜235 tick で、払った 25（250 tick 分）の中に収まる。**払わなければ死ななかったかは、この数え方では分からない**（その間に食べられたかどうかは反実仮想）が、死亡の 4 分の 3 が支払いの直後に起きている。
- **一生の形は「成人してすぐ産み、産み疲れて死ぬ」。** 死んだ成人の子の数は中央値 2、成人してから死ぬまでは数百 tick。一度も払わずに死んだ成人は 6%、成人前に死んだ子は 19〜20%。
- 地図による違いはほとんど無い。
