# 9-7b-3b 植物の形 A、苗床あり——`SeedRate` の掃引（小の測定）

判断は [`docs/history/20261010.md`](../history/20261010.md)。**小の測定**（constrained・4 シード・20000 tick・`-brief`・1 並列）。基準 `roomy`、対照 `planted`（`SeedRate` 0.005）・`planted4`（0.02）・`planted10`（0.05）・`strewn`（取り分で戻る）。植物は上限 600 の 3 分の 1（200）で人間・獣が食べ、苗床 20 単位。コミット 0817d60。**4 シードなので差の有無と向きだけを読む。**

## 1. 概要

- 確かめたかったこと: 苗床のある形 A で、どの率なら植物が広がり、個体数と住み分けはどうなるか。
- 分かったこと:
  - **率が植物の池の戻る速さをそのまま決め、世界の豊かさを決める。** 0.005 は群れ 64 単位で毎 tick 0.3 の種——自分の池（空き × 0.002 ≈ 0.3）と同じ速さなのに個体数は `roomy` の 57%（106）。0.02 は群れ 139 で毎 tick 2.8 の種（自分の池の 5 倍）、個体数 +15%（212）。0.05 は群れ 160 で 8 の種、個体数 +31%（241、獣 162）。
  - **広がり方は率で変わらない**: 植物のある地域数は 2.3〜2.6 で、取り分で戻る `strewn` の 4.0 に届かない。苗床の単位は取り分で散るが、群れは苗床のまわりに固まる。
  - **共有の植物は率が高いほど住み分けを崩す。** 人間が下半分にいる割合: `roomy` 0.056 → 0.005 で 0.08、0.02 で 0.29、0.05 で 0.24。獣が上半分: 0.051 → 0.11、0.23、0.25。植物が多いほど、相手の半分へ食べに行く。
  - 0.005 で個体数が減るのは不思議に見えるが、群れが固まるので地域の食料の数（生存の表が読む）に対して歩いて出会う率が低く、見込みが実際より豊かになる（「情報を足しても居場所は動かない」の裏: 固まった食料は数のわりに見つからない）。
- 予想との照合: 0.005 が留まる（当たり）、個体数は `strewn` より少ない（当たり、幅は予想より大きい −43%）。0.02 で 3〜4 地域（外れ: 2.5）・個体数 `roomy` 並み（当たり寄り: +15%）。0.05 で 4 地域（外れ）・`roomy` より多い（当たり）。住み分けの崩れは予想（0.1〜0.2）より大きい（0.24〜0.29）。
- 読み: 形 A は動く（苗床から群れが育ち、率で速さが決まる）。残る設計の問いは 2 つ——(1) 植物の池の戻る速さ（`SeedRate`）は他の食料と同じ目盛りに置くべきか（0.02 で自分の池の 5 倍）、(2) 種族が共有する植物は住み分けを 2〜3 割崩す——これを「時々接触する」として受け入れるか、植物を種族の地域ごとに分けるか。
- 次にすること: ユーザの判断（上の 2 つ）→ 9-7b を閉じる大の測定。
