# 9-5b 予算の大きさを遺伝子の枠にし、消耗で価格を付ける（`AllotBudget`・`BudgetBurn`）

判断は [`docs/history/20261007.md`](../history/20261007.md)。`unsized`（9-5a、予算は全員 1）を基準に、base（5 段・1 段 1.25 倍・消耗が予算に比例）と `unpriced`（同じ枠で価格なし——前身で予算が際限なく上がった形）を比べた。**flat だけ**——patches は 1 本 5 分かかる途中で OOM に殺され、constrained は Claude Code がメモリ逼迫で止めた（取り直しはユーザ判断待ち。先に表の天井の丸め `FullStep` を入れて軽くしてから取る案）。

## 1. 概要

- 確かめたかったこと: 予算の大きさを離散の段として親から継がせ、1 tick の消耗を予算に比例させたとき、(a) 価格が無ければ前身のように予算が上がり続けるか、(b) 価格があれば横ばいになるか、(c) 世界がどう動くか、(d) 子の予算と親の予算の相関（`VISION.md`「予算の大きさは親の予算の影響を受ける」）が正か。
- 分かったこと:
  - **価格が無いと予算は上がり続ける（前身の再現）**: `unpriced` の成人の平均予算は 1.386、後半 − 前半のドリフト +0.070 ± 0.015（4.7σ）、最大段の成人 51%（引きは 20%）。世代ごとの平均予算は 1.06（世代 0）→ 1.31（10）→ 1.42（40）→ 1.44（60）でまだ上がる。
  - **価格があると横ばいになる**: base の世代ごとの平均予算は 1.06 → 1.11（10）→ 1.13（30）→ 1.10（40）→ 1.07（50）。最小段の成人 2.1%、最大段 4.0%（引きは各 20%）で、両端が削られ中央の段に集まる。横ばいの位置は中立より少し上（約 1.1）。**ただし「予算のドリフト」の行は NaN**——1 シードが崩壊して後半の見取りが無く、その NaN が平均を潰した（計器の不具合。次の取り直しまでに直す）。
  - **世界は価格を払って弱くなる**: base は個体数 −26.8 ± 6.9（−27%）、出生 −29%、成人到達率 −0.062 ± 0.009、崩壊 1/12。`unpriced` は個体数 +12.3 ± 2.9（+12%）、出生 +18%——大きい身体がただで手に入る世界。中立より上に落ち着く分だけ 1 体の消費が増え、食料で頭打ちの個体数が減る。段 0 と段 4 を引く身体（最初の 40%、以後も変異 0.1 で出続ける）が両方とも不利なので、9-3 の変異の重荷と同じ形の負担が乗る。
  - **子の予算と親の予算の相関は +0.66 ± 0.01**（base・`unpriced` とも）。`VISION_CHECKS.md` の判定を flat で満たす。
- 予想との照合: (a) 当たり。(b) 当たり（横ばいの段は中立より上、予想どおり）。(c) 「flat で減る」は当たりだが大きさは外れ（−27% と 1 崩壊は想定より大きい）。(d) 当たり。
- **追記（2026-10-07、[fullstep](20261007-fullstep.md) の `exact` 列、同じ世界を計器を直して読んだもの）**: base の予算のドリフト（後半 − 前半）は 0.004 ± 0.017 で誤差内、成人の平均予算は 1.097 ± 0.018。**完了条件「base で誤差内・`unpriced` で有意に正」を flat で満たす。**
- 速さ: `cmd/experiment` の 1 本が flat で約 2 倍、constrained では `unsized` 30 秒に対し base 4 分（8 倍）。表の作り直しが原因（`docs/history/20261007.md`）。
- 次にすること: 表の天井を `FullStep` に丸めて軽くし、`exact` 対 base で世界が動かないことを確かめてから、patches・constrained を取る（ユーザ判断）。
