# 9-7b-1 食料の種類と種族タグ（`FoodKinds` / `Foods`）

判断は [`docs/history/20261009.md`](../history/20261009.md)。全部の形式。`single`（1 種族・1 池・上限 300）を基準に、base（人間の池 150・獣の池 150。総量は `single` と同じ）、`shared`（2 種族が 1 池 300 を分け合う。9-7a の世界）、`halffed`（1 種族・上限 150・最初の身体 100。事前の数え上げ）、`ample`（人間の池 300・獣の池 300。各種族が `single` の世界を持つ）を比べた。12 シード・flat と constrained は 2 並列・patches は 3 並列。コミット 6c4e88b。**崩壊したシードの「人間の個体数（最終）」「獣の個体数（最終）」は、このコミットでは落ちる直前のチェックポイントの数を読んでいる**（全体の「人口（最終）」は落ちた tick の数）。次のコミットで落ちた tick の数に直した。

## 1. 概要

- 確かめたかったこと: 同じ陸で別の池を食べる 2 種族は共存するか（9-7a で、同じ池を争う 2 種族は 60 世代で片方が消えた）。(a) 池を分ければ constrained・patches で両方残るか、(b) flat は直るか、(c) 予算は変わらないか、(d) 種族ごとの食料は池 1 つ分になるか。
- 分かったこと:
  - **(a) 地位を分ければ共存する——ただし各種族が `single` の世界を持つとき。** `ample` は constrained・patches とも崩壊 0/12・絶滅 0/12 で、人間 61 / 獣 63（constrained。`single` は 65）、人間 101 / 獣 98（patches。`single` は 116）。同じ地図で同じ池を分け合う `shared` は片方の絶滅が constrained 12/12（人間 9・獣 3）、patches 11/12（人間 6・獣 5）——9-7a の再現。
  - **総量を変えずに池を分けた base は 3 地図とも 12/12 で下限を割る。** 1 種族あたり 150 単位の世界は、種族を分けた base でも 1 種族だけの `halffed` でも、constrained で 16〜33 体に落ち着き、崩壊の下限 20（300 単位の世界で決めた）の下にいる。**種族が絶滅したのではない**（base の絶滅は constrained 0、flat 0、patches で獣 3/12）。世界が小さいだけで、共存しないのとは別のこと。
  - **(b) flat は `ample` でも 1 種族ずつ見れば `single` と同じ脆さ。** 世界の崩壊は 0/12（合計は 104 体で `single` の 65 より多い）だが、絶滅は人間 2/12・獣 5/12——`single` の崩壊 4/12 と同じ程度の、種族ごとの交配相手の密度の問題。獣が人間より多く消えるのは目盛りのずれ（`Size` 1。最初の数世代で若い死が増える）で、constrained・patches では差が出ない。
  - **(c) 当たり——成人の平均予算は両種族とも 1.1 前後で、池を分けても動かない。**
  - **(d) 当たり——人間の食料（地面）は `ample` で `single` と同じ（constrained 125 対 114、flat 125 対 125）。** patches だけ `ample` が多い（63 対 34）: 池 1 つあたりの個体数が `single` より少なく（101 対 116）、食料が余る。
- 予想との照合: (a) 当たり（`ample` で両種族が残り、個体数は `single` と同じ。base と `halffed` の崩壊も当たり）。(b) 当たり（flat は世界の崩壊としては 0/12 で予想の 4〜8 より少ないが、種族ごとの絶滅で見れば同じ脆さ）。(c) 当たり。(d) 当たり（patches の余りは予想になかった）。
- 読み: **`VISION.md` の「種族ごとに食べるものを分ける」は共存の条件そのもので、分ければ 2 種族は同じ地図に 60 世代以上共存する。** 9-7a の「同じ地位に 2 種族は要らない」はこれで閉じる。残るのは世界の大きさ——1 種族あたりに `single` と同じ食料（300 単位）が要り、総量を据え置いて池を分けた世界（1 種族 150 単位）は崩壊の下限の下に落ち着く。既定の世界をそのままにすると既定が崩壊する世界になるので、**既定の `FoodCap` を 600 にして各種族の池を 300 にする**（`single` は 300 のまま——9-6a の世界）。flat は種族ごとに `single` と同じ脆さで、「簡単に絶滅しない」には交配相手の密度（地図の広さか交配要求の届く範囲）が要る——9-7a で書いたとおり。
- 次にすること: 既定の `FoodCap` を 600 に（次のコミット）。9-7b-2 水と魚（水を「入れるが危ない」地形に、水の中に沸く ID、魚の行は水だけ）。
