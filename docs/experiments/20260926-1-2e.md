# 1-2e: イベント単位の判断

判断は [`docs/history/20260926.md`](../history/20260926.md) の「1-2e」の各節。

## 1. 概要

- 確かめたかったこと: 身体が手を意図として持ち、出来事が起きた tick にだけ決め直す形（`Recheck` 300）で、決定の回数が大きく減り、毎 tick 決める世界（`everytick` ＝ 1-2r）と人口が変わらないか（`VISION_CHECKS.md`「判断はイベント単位」）。
- 分かったこと: **1回目（3faa168）は平坦な地図の人口が有意に下がった**（−3.17 ± 0.49）。原因は、食料が視界に入った瞬間に全部の手が同点（死ぬ確率 0）で通り過ぎ、あとで空腹になっても見えている集合が変わらないので決め直さないこと。**見え方を身体から見た位置で持つ**ように直した 8778b88 では、両方の地図で人口の差は有意でなく、決定の割合は平坦 0.062・制約 0.142。
- 次にすること: 1-2e を閉じ、1-3（繁殖）の実装前の数え上げに進む。

## 予想との照合（PLAN 1-2e）

| 予想 | 結果 |
| --- | --- |
| 決定の割合 平坦 0.06 以下、制約 0.12 以下 | **外れ（わずかに超えた）**: 0.062・0.142。見え方を身体から見た位置にした分、食料が見えている間はタイルをまたぐたびに決め直す。直す前は 0.054・0.125 |
| 40000 tick の人口は `everytick` との対の差で有意でない（両方の地図） | 当たり（8778b88）。**1回目（3faa168）は平坦な地図で外れた** |
| 崩壊 0 / 12 | 当たり |
| 指紋は変わる | 当たり |
| `BenchmarkWorldStep` は 2 倍以上速くなる | **外れ**（1.24 倍）。ベンチのテスト用の地図は決定が密なため。実験の地図では 1シードあたり 2.2〜2.7 倍速くなった |
