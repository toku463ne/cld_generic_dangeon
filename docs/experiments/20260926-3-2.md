# 3-2: 雌が出産を担う（FemaleBears）

判断は [`docs/history/20260926.md`](../history/20260926.md) の「3-2 の測定」。事前カウントは [3-2-count](20260926-3-2-count.md)。

## 1. 概要

- 確かめたかったこと: 交配の代金（雌雄とも 5）と出産の代金（雌だけ 40）を分け、出産した雌が 400 tick 交配できないようにすると、成人の一生が延び、子の代金で大人が死ぬ世界が変わるか。`even`（3-1）との対の差で読む。
- 分かったこと:
  - **成人の一生が大きく延びた。** 生きている身体×tick のうち子は 59〜66% → **21%**、成人の割合は 0.35〜0.42 → **0.80〜0.81**。一生の長さの平均は約 2,550 tick（死んだ年齢の中央値 1,701、95% は 7,300〜7,650）。
  - **出生が約 3 分の 1 に**（平坦 −3,417、−68%。制約 −2,997）。餓死も同じだけ減った。成人到達率は上がった（+0.066〜0.068）。
  - **個体数**: 平坦は有意でない（+1.08 ± 2.50）。**制約は −26.75 ± 8.50（有意）**、谷の最小 82。崩壊 0。
  - **成人の性比がさらに片寄った——今度は雌が少ない。** 成人のうち少ない側の性の割合は 0.28〜0.33 → **0.12**。代金の回数は成人 1000 tick あたり女 2.0〜2.1・男 0.31〜0.33 で、出生1回に雌雄1体ずつなので、成人の男は女の約 6.5 倍いる。**死んだ女の 85〜89% は最後の代金から 1000 tick 以内に死ぬ**（男は 29%）。女は一生に約 2.2 回産んで死ぬ。
  - 男は払っていない間の体力がわずかに減り続ける（1 tick あたり −0.006）。男の 31〜35% は一度も払わずに死ぬ——女が少なく、相手が見つからない。
- 予想の外れ: 性比の片寄りは縮むと予想したが、逆に強まった。代金を払う側が片寄ると、その側が死んで少なくなる——3-1 で見た「払う側が死ぬ」と同じ仕組みが、今度は出産の代金を担う雌だけにかかった。
- 次にすること: 雌が出産の代金で死ぬのをどう扱うか、ユーザと決める。
