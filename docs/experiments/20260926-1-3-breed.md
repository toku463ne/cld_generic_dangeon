# 1-3 数え上げ: 交配の機会・体力を払う代価・寿命

判断は [`docs/history/20260926.md`](../history/20260926.md) の「1-3: 数え上げ」。

## 概要

- 確かめたかったこと: 1-2e の世界で、(1) 交配できる相手が近くにいる決定はどれだけあるか、(2) 子のために体力を払うと死ぬ確率はどう変わるか（生命を先に比べる読み方で交配が起きうるか）、(3) 死ぬ道が餓死だけのとき身体はいつまで生きるか。
- 分かったこと: 視界（3×3）に他の身体がいる決定は約 34%。**体力を払って死ぬ確率がちょうど変わらない決定は 0%**——生命を先に比べ、子は同点のときだけ数える読み方では誰も交配しない。**最初の身体の 74%（平坦）・42%（制約）が 40000 tick 後も生きている**（満腹の大人はいつまでも生きる）。
- 次にすること: 2通貨を「死ぬ確率 − ChildWorth × 子ができる確率」の1つの比較に入れる（ユーザ決定）。老いによる死は 1-3 の直後に入れる（O8）。

## 条件

| 項目 | 値 |
| --- | --- |
| コミット | 5b2a452（`cmd/count` の `breed` は作業ツリーに足した状態で測った。世界のコードは 5b2a452 のまま） |
| マップ | flat (64x48) / constrained (64x48) |
| tick 数 | 40000（近さ・代価は tick 5000 より後の決定だけ数える） |
| シード数 | 12（最初のシード 1） |
| 比較対象（base） | なし（1-2e の世界の中の割合） |

**再現方法**:

```
go run ./cmd/count -what breed -map flat -w 64 -h 48 -seeds 12 -ticks 40000
go run ./cmd/count -what breed -map constrained -w 64 -h 48 -seeds 12 -ticks 40000
```

**数え方**: 近さは、決定した身体のタイルから各軸で r タイル以内のタイルに、ほかの身体が立っているか（位置は tick の始まりのもの）。代価は、視界に他の身体がいる決定で、真の表の「この地域で動き続ける」の行から、今の体力と、そこから c だけ払った体力で、窓の終わりに死んでいる確率を読んだ差。寿命は実行全体。
