# 7-2b 暗く・明るくなるまでの時間を学び、値付けが読む（`DuskRead`）

判断は [`docs/history/20261003.md`](../history/20261003.md) の「7-2b の測定」。

## 1. 概要

- 確かめたかったこと: 身体が明るさ・向き・今の段になってからの時間を鍵に、暗く・明るくなるまでの tick を自分の経験から学び、値付けが「歩き続ける」の視界を窓の中でその時刻に切り替えて読むと、世界と1日のリズムがどう動くか。夕方に食べる・持つが出るか。
- 分かったこと:
  - **世界はほとんど動かない。** 個体数 制約 +6.6 ± 6.1・平坦 +3.3 ± 4.0（どちらも有意でない）。平坦で出生 −1.5%・餓死 −2%（わずかに有意）。
  - **1日の中の食事・拾う手・餓死・眠る割合は、どの区間も `duskblind` と誤差の内。** 夕方の備えは出ない。事前カウント（明るいときの決定の 1.6〜3.5% で手が変わりうる、変わり方の多くは交配 → 待つ）の見立てどおり。
  - **重さ: 1 tick 約 6 倍、ヒープ約 9 倍**（`PARAMETERS.md`）。実験の最大常駐メモリ 4.4〜5.1 GB。崩壊の 36 シード（`lock`、2 つの世界を並べて走らせる）はメモリ不足で止められ、測れていない。
- 読み: 値付けの窓（1000 tick）は満腹の身体が飢えるまでの長さと同じで、満腹に近い成人は窓の中で死ぬ見込みがほぼ 0——暗くなる時刻を知っても減らす危険が無い（7-2b の事前カウントの読みと同じ）。学ぶ側（行）は軽く、クライアントで見込みが見えるが、読む側（切り替える表）は重さに見合う差を生まない。
- 次にすること: ユーザに確かめる——読む側を戻し、学ぶ側だけ残す（O21「把握する」は満たす）か、全部戻すか、重さを受け入れるか。

## 予想との照合（PLAN 7-2b）

| 予想 | 結果 |
| --- | --- |
| 成人は2日ほどで学び、推定は帯の半分ほどの誤差 | テストで確かめた（`TestDuskLearn`。帯の幅の内）。世界の中での誤差は数えていない |
| 昼の出生がわずかに減る（0〜−5%）、午後〜夕暮れの食事・拾う手が少し増える | 出生は平坦 −1.5%、制約は差なし。食事・拾う手はどの区間も差なし |
| 夜の交配と相手へ歩く手がいくらか増える | 測っていない（1日の中の表では差なし） |
| 個体数 ±5% | 当たり（有意な差なし） |
| 眠る割合の夜への寄りは残る | 当たり |
| 崩壊は増えない | 未測定（メモリ不足） |
| 表は数倍、ヒープと 1 tick を測る | 表 5 倍・ヒープ 9 倍・1 tick 6 倍 |
