# 4-0 の事前カウント: 値付けの同点（`ties`）

判断は [`docs/history/20261002.md`](../history/20261002.md) の「4-0 の事前カウント」。

## 1. 概要

- 確かめたかったこと: 物を持てるようにする前に、値付けが手を見分けられない決定（同点の決定・最善の手の死ぬ確率が 0）がどれだけあり、誰に起きているか。3-4 で見た「休んでいる母が足元の食料を食べ控える」の正体。
- 分かったこと:
  - **休んでいる母の決定の 42〜50% で、最善の手の死ぬ確率がちょうど 0。** 同点の決定は 99%。足元に食料があり体力 0.5 以上のとき、食べるは必ず最善に入っているのに、食べたのは 1.2〜1.6%（向きを保つ移動が選ばれる）。体力 0.5 未満でも 40〜42%。
  - **それ以外の成人で最善の手の死ぬ確率が 0 なのは 1.7〜2.0%。** 同点の決定は 46〜49% だが、ほとんどは同じ地域の中の移動どうし（向きを保つ規則の受け持ち）。足元に食料があって食べるが最善より悪いとき、最善は 97% が交配——`ChildWorth` の働きで、同点ではない。
  - 子は空腹（0.5 未満）なら 99.9% 食べる。最善と次の手の差が 1e-12 以下の決定が 9〜12% ある。
- 読み: 同点は休んでいる母に集中する。値付けは休んでいる母を窓（1000 tick）の全体で半分の消耗として読むので、満腹から餓死まで 2000 tick に見え、体力が半分を超えると窓の中で飢える道筋が無くなる。休みは長くて 400 tick で明けるので、これは同点の扱いではなく予測の誤り。休み明けを予測に入れる規則（4-0）を足す。それ以外の成人は物を持つ規則（4-1）の値付けで手を見分けられる。
- 次にすること: 4-0（`RestAhead`）を実装し、`restblind` と比べる。
