# 2-0: 証拠の寿命を測る計器（伝承なしの世界で 0 になるか）

判断は [`docs/history/20260926.md`](../history/20260926.md) の「2-0」。

## 概要

- 確かめたかったこと: 証拠の出どころの計器（又聞き・孤児の証拠・その年齢）が、伝承の無い 1-6 の世界で 0 を返し、世界を変えないこと。
- 分かったこと: 両方の地図・全ての行で、又聞き・孤児の証拠・又聞きの保有者がすべて 0。崩壊 0 / 12。指紋は 1-6 のまま（テスト）。計器が壊れていないことは、証拠を手で渡すテスト（`TestOrphanEvidence`）で確かめた。基準になる死んだ年齢の中央値は 1201 tick（両方の地図）。
- 次にすること: 2-1（伝承の経路1本）の実装前の数え上げ。
