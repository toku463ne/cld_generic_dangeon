# 11-4 好みと飾り物——小の測定

判断は [`docs/history/20261012.md`](../history/20261012.md)。**小の測定**（constrained・4 シード・20000 tick）。基準 `noornament`（好みも飾り物も無い 11-3 の世界）、対照 `warmed`（好み 3・飾り物 3 種類・欲しさ 60）。コミット 5cb1e1e。8:1 の世界。

## 1. 概要

- 確かめたかったこと: 飾り物が作られ、欲しい身体の手に渡るか。人間の数を動かすか。
- 分かったこと: **渡る**。作った 431、拾われた延べ 519、店で買った 166、身体どうしで売られた 9.5、終わりに好みに合うものを持つ身体 27%。店に送った物 441 → 964（増えた分の多くは飾り物）、店のコイン 261 → 388、身体の手持ちのコイン 402 → 272——飾り物を通ってコインが店へ集まる。そのぶん身体どうしの売買（食料・テント）は 186 → 120（−36%、有意）。人間 139 → 140、餓死・出生は誤差内、成人到達率 −0.007（1.7σ）。
- 予想との照合: 作った 300〜500・店で買った 80〜200・身体どうし 5〜30・人間 −5〜0% は当たり。好みに合うものを持つ割合 0.3〜0.5 は外れ（0.27）。
- 読み: 飾り物は「作れる者が作って店に送り、欲しい者が店で買う」道を通る。身体どうしで少ないのは、欲しい身体と好みの合わない飾り物の持ち主が視界で出会う機会が少ないから（店はその出会いを要らなくする——11-1 と同じ形）。欲しさは店のコインの値打ちで割り引かれるので、店を信じる身体は 3 枚（約 45）を欲しさ 60 で買い、コインの少ない身体は買えない。好みが世界の数を動かさないのは、値付けの例外を生存の読みに入れていないからで、狙いどおり。
- 次にすること: 既定のまま入れ、11-4 を閉じる。**段階 11 を閉じる。** VISION_CHECKS の「飾り物の種類を増やすと売買が増える」は、種類の掃引（3 → 6）で確かめられる——次の段階へ進む前に測るかはユーザと相談する。
