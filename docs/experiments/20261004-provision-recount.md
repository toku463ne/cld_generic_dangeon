# 6-3 の事前カウント: 今の世界で休んでいる母への配分を切る（`unprovided`）

判断は [`docs/history/20261004.md`](../history/20261004.md) の「6-3 の事前カウント」。前の数え: [20261002-4-3](20261002-4-3.md)（4-0 の世界）。

## 1. 概要

- 確かめたかったこと: 6-3（休んでいる母が休める場所を使い、配分を消す）の前に、今の世界（寒い夜・眠りの強制と先読み・休める場所）で配分を切ると何が起きるか。
- 分かったこと:
  - **個体数 平坦 −25%（93 → 70）・制約 −15%（79 → 67）、出生 −29% / −15%。** 平坦で崩壊 2 / 12（配分ありは 0）。
  - 成人のうち女の割合 0.62〜0.63 → 0.51〜0.52（4-3 では 0.36 まで落ちた。眠りと寒さで母の身体の損が前より目立たない）。
  - 成人到達率は変わらない（0.95〜0.96）。
- 読み: 配分は今も世界を支えている（とくに平坦）。切るだけでは崩壊が出る——休める場所が配分の代わりを持たないと消せない。代わりの形はユーザと決める。
