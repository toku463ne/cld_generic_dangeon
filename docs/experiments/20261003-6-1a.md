# 6-1a 休める場所（世界の規則だけ。`Shelter`）

判断は [`docs/history/20261003.md`](../history/20261003.md) の「6-1a の測定」。

## 1. 概要

- 確かめたかったこと: 各象限の中心の 3×3 を夜も平温にした（身体は知らない）とき、たまたまその上にいる身体だけの得で世界が動くか。7-1（世界の規則を先に入れる）と同じ位置づけ。
- 分かったこと: **世界は動かない。** 個体数 平坦 −1.3 ± 4.2・制約 +2.9 ± 3.9、出生・餓死・成人到達率も誤差の内（平坦で老いによる死 −12 ± 4 だけ有意。眠っている割合 制約 +0.002）。予想（夜の餓死 −0.3% 程度、誤差の内）どおり。崩壊 0 / 12（両方の地図）。
- 次にすること: 6-1b（休める場所を知り、歩いて寝る）。
