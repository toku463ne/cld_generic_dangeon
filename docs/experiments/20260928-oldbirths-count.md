# 老人の交配を止める前の事前カウント（`oldbirths`）

判断は [`docs/history/20260928.md`](../history/20260928.md) の「3-8 の事前カウント」。

## 1. 概要

- 確かめたかったこと: `VISION.md`「老人と赤ちゃんは交配できない」を入れる前に、今の世界（M-3）で老人（年齢 `OldAge` 3200 以上）が親になっている出生がどれだけあるか。
- 分かったこと:
  - **出生の 13〜14% はどちらかの親が老人**（平坦 0.135、制約 0.145）。母が老人 7〜8%、父が老人 6〜8%。
  - 成人のうち老人は 8〜9%。老人は成人の割合に見合う分だけ親になっている。
- 読み: 出生を縛るのは女が出産の分を払える状態になる速さ（[request-count](20260927-request-count.md)）なので、**効くのは老いた母の分（7〜8%）**。老いた父の分は若い男が埋める（交配できる男は女の約 7 倍）。出生は 5〜8% 減る見込み。老人は交配の代金を払わなくなり、老いの死が増える。繁殖できる期間は 400〜3200 の 2800 tick で、崩壊した 3-5（2000）と崩壊しなかった 3-5b（3000）の間——崩壊しないか注意して見る。
