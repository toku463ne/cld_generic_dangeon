# 速さ: 前身プロジェクトとの比較・1コア・WASM

判断は [`docs/history/20260926.md`](../history/20260926.md) の「性能: 体感を目標にし、µs を代理指標にする」。

## 概要

- 確かめたかったこと: 同じくらいの個体数の世界を同じ tick 数だけ進めるのに、前身と今のエンジンで何秒かかるか。1コア（`GOMAXPROCS=1`）と WASM（node）でも。
- 分かったこと: **約 127 体・10000 tick で、前身 3.00 秒、今 0.31 秒（約 10 倍速い）。WASM（node）では前身 12.9 秒、今 1.07 秒（約 12 倍）。** どちらのエンジンもゴルーチンを使わないので、`GOMAXPROCS=1` はほとんど変わらない（GC が同じコアに乗るだけ）。**ただし今のエンジンは、セーブを読み込んだ直後の 1000 tick が 13〜17 倍遅い**（生存の表を作り直すため。WASM で 1.7 ms/tick）。
- 次にすること: `PARAMETERS.md`「性能の上限」を体感の目標と代理指標の形に書き換える。読み込み直後の遅さは、配るスナップショットで遊ぶ前に直す（表の作り直しを減らす）候補として残す。

## 条件

| 項目 | 値 |
| --- | --- |
| コミット | 702a104（`cmd/speed` は作業ツリーに足した状態で測った。世界のコードは 702a104 のまま） |
| 機械 | AMD Ryzen 5 5500U（12 スレッド）、WSL2、go1.24.0。node は同じ機械 |
| 今のエンジン | constrained 64x48・`base`（1-4）・シード 5。20000 tick 育ててから 10000 tick を測る。個体数を揃えるため `FoodCap` 230（約 128 体）と既定の 300（約 170 体） |
| 前身 | `cld_human_behaviour`（ee62707）の遊ぶ地図（`cmd/experiment` の `playedMap` と同じ設定）・既定の設定・シード 5。20000 tick 育ててから 10000 tick を測る（前身の 2026-09-19 の測定と同じ手順） |

**再現方法**（今のエンジン）:

```
GOMAXPROCS=1 go run ./cmd/speed -food 230
GOMAXPROCS=1 go run ./cmd/speed
GOOS=js GOARCH=wasm go build -o speed.wasm ./cmd/speed && node "$(go env GOROOT)/lib/wasm/wasm_exec_node.js" speed.wasm -food 230
```

前身は、同じ形の使い捨てのプログラム（`engine.NewWorld` のあと 20000 tick、次の 10000 tick を `time.Now` で測り、100 tick ごとに生きている身体を数える）を前身のモジュールの中に置いて測った。

## 結果（10000 tick にかかった秒数）

| エンジン | 個体数（10000 tick の平均） | ネイティブ | ネイティブ `GOMAXPROCS=1` | WASM（node） |
| --- | --- | --- | --- | --- |
| 前身（遊ぶ地図） | 人 116 ＋ 外敵 11 ＝ 127（WASM では 134 ＋ 10） | 3.05〜3.25 秒 | **3.00 秒** | **12.9 秒** |
| 今（`FoodCap` 230） | 128 | — | **0.31 秒** | **1.07 秒** |
| 今（既定、`FoodCap` 300） | 170 | 0.42〜0.43 秒 | 0.42 秒 | 1.42 秒 |
| 今（既定、flat） | 170 | 0.37〜0.46 秒 | 0.37 秒 | 1.25 秒 |
| 今（`fixed` ＝ 1-3、配分なし） | 171 | 0.33 秒 | — | — |

**セーブを読み込んだ直後の 1000 tick**（今のエンジン）: ネイティブ 1コア 0.47〜0.57 秒（470〜570 µs/tick）、WASM 1.67〜1.70 秒（約 1.7 ms/tick）。育った世界の定常の 13〜17 倍。

- 前身の WASM はネイティブの 4.3 倍遅い（前身の 2026-09-19 の記録は 1.54 倍・614 µs/tick。その後に規則が増えた）。今のエンジンは 3.4 倍。
- 前身の WASM の世界は個体数が違う（`math.Exp`・`math.Pow` の 1 ULP の違いで別の世界になる。前身の記録どおり）。
