# 3-3: 休んでいる母への食料の配分（Provision）

判断は [`docs/history/20260927.md`](../history/20260927.md) の「3-3 の測定」。事前カウントは [3-3-count](20260927-3-3-count.md)。

## 1. 概要

- 確かめたかったこと: 戻ってくる食料の一部を休んでいる母に直接配ると（相手が同じ地域にいれば 0.07、いなければ 0.035）、3-2 で起きた「母が出産の代金で死に、成人の女が 12% になる」が和らぐか。`unfed`（3-2）との対の差で読む。
- 分かったこと:
  - **成人の女の割合が上がった**: 成人のうち少ない側の性（女）の割合 0.12 → **0.23**。釣り合い（0.5）にはまだ遠い。
  - **出生が増えた**（平坦 +753、+47%。制約 +864、+61%）。餓死も同じだけ増えた。成人到達率は下がった（−0.04〜−0.05）。成人の割合は 0.80 → 0.70。
  - **制約の地図の個体数が戻った**: +37.25 ± 8.40（3-2 の −26.75 を取り戻し、谷の最小 82 → 131）。平坦は変わらない。崩壊 0。
  - 母に配られた食料は1シードあたり 1,360〜1,520 単位（戻る食料の約 7%）。
  - **しかし休み明けの母の体力は 52 → 58〜59 にしか上がらなかった**（予想は 90 前後）。休んでいる母の数が 11〜12 → 約 19 に増え、母1体あたりに戻る食料が 0.05 → 0.031〜0.034 に薄まった。女のうち最後の代金から 1000 tick 以内に死ぬ割合は 85〜89% → 80〜83% と、少ししか下がっていない。
- 次にすること: 3-4（寿命と老いによる死）の事前カウントへ。配分の確率は仮のまま（母が増えると1体あたりが薄まる形なので、確率を上げても同じ向きに薄まる）。
