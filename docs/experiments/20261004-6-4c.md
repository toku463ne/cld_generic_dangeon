# 6-4c 持ち主（`Ownership`）

判断は [`docs/history/20261004.md`](../history/20261004.md) の「6-4c の測定」。

## 1. 概要

- 確かめたかったこと: 父が送った食料を母のものにする（他者は取れない）と、母に届くか。比べるのは 6-5a（配分あり、`fatherless`）と 6-4b（持ち主なし、`ownerless`）。
- 分かったこと（base 対 `fatherless`）:
  - **他者が取るのは 26〜34 単位に減った**（6-4b の約 500〜550 から。残るのは母が死んで手放された分）。
  - **それでも母が取ったのは届いた食料の 9〜11%（47〜55 単位）、約 8 割は誰にも取られず古びた。** 母が家に立ったとき食料があったのは 12〜13%。
  - 送る量は 1シードあたり約 700（6-4b の約 1400 の半分。出生も減った）。
  - 平坦: 個体数 99 → 50（−49%）、崩壊 3 / 12。制約: 75 → 60（−20%）、崩壊 0 / 12（36 シードで 3）。6-4b より悪い。
- 読み: 母は求めてすぐ家へ行き、食料がまだ着いていないので「無かった」と学び、次に求めるまで家を読まない。休みが明けると求めなくなり、あとから着いた自分の食料は古びる。母が家を読む時期が、食料が着く時期と合っていない。
- 次にすること: ユーザに確かめる。
