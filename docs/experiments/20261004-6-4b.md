# 6-4b 母は家を食料の見込みの場所として読み、家の食料は中からしか見えない（`HomeRead`・`HideShelter`）

判断は [`docs/history/20261004.md`](../history/20261004.md) の「6-4b の測定」。

## 1. 概要

- 確かめたかったこと: 父が母の求めに応じて送った食料（6-4a）を、母が「求めたあと家へ取りに行く」形で受け取れるか。比べるのは 6-5a（配分あり、`fatherless`）と 6-4a（家を読まない、`homeless`）。
- 分かったこと（base 対 `fatherless`）:
  - **届いた食料を母が取ったのは 35〜51 単位（2.7〜3.5%）、他者は 480〜545（36〜41%）。** 隠しても他者が取る——休める場所のタイルには眠りや通り抜けで多くの身体が立ち、家のタイルに立てば足元の食料は見える。
  - 母が家に立ったのは 1シードあたり約 400 回、そのとき食料があったのは 22〜23%。
  - 平坦: 個体数 99 → 64（−35%）、崩壊 2 / 12、出生 −33%、女の割合 0.63 → 0.53。制約: 75 → 62（−17%）、崩壊 2 / 12（36 シードで 3）、女の割合 0.61 → 0.54。6-4a（求めに応じる形）の平坦 −48% よりは良いが、配分ありには遠く、制約では崩壊が出た。
- 読み: 送る・隠す・取りに行くの3つがそろっても、届いた食料は母より先に他者に取られる。家のタイルは誰でも立てる場所なので、隠れる規則では守れない。母に届けるには、届いた食料を母のものにする（他者は取れない）か、届く先を母の身体にする（配分に近い）か。
- 次にすること: ユーザに確かめる。
