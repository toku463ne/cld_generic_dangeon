# 2-3: 通ったタイルの行も、観測からの時間で重さを減らす（AgePath）

判断は [`docs/history/20260926.md`](../history/20260926.md) の「2-3 の測定」。前の段階は [2-2](20260926-2-2.md)（通ったタイルの行が古びない、条件 `kin`）。

## 1. 概要

- 確かめたかったこと: 全ての証拠を最初に観測した時刻から古びさせれば（2-2 との違いはこの1規則）、先祖の古い証拠が身体の経験を押しつぶすのをやめ、誤った信念が血統に定着しなくなるか。
- 分かったこと:
  - **押しつぶしは解けた。** 身体が持つ証拠のうち自分で見た分は 0.1% 前後 → **4〜12%**。実験の最初の 1/4 に生まれた観測者の証拠は 0 になった。シードごとの比の幅は 2-2（平坦 ×0.36〜1.42）より狭い（平坦 ×0.71〜1.37、制約 ×0.76〜1.14）。
  - **ただし信念は ×1 のあたりに集まった。** 渡さない `untold`（×0.63〜0.92）より高く、1 を超えたシードは平坦 7 / 12・制約 3 / 12。**それより後の観測者（古びたあとに残る新しい証拠）の比そのものが 0.73〜1.48** で、古い証拠の居座りではなく、この世界で今観測される証拠が「通ったタイルは地域より乏しくない」と言っている。地域の推定は世界の値より高めなので、地域を低く見積もったせいでもない。
  - **行動と成人到達率は `untold` より悪い**: 真後ろへの手 +0.042（両方の地図で有意。2-2 は散って有意でなかった）、成人到達率 平坦 −0.0079 ± 0.0023・制約 −0.0050 ± 0.0021（有意）。個体数・餓死数は有意でない。
  - **文化は個体より長生きする**（孤児の証拠 87%、年齢の中央値 約 2,900 tick ＝ 寿命の約 2.4 倍）。予想（寿命前後まで下がる）より長い。
  - **証拠を消しても死ぬ割合は変わらない**（4 回とも有意でない）。
- 次にすること: 通ったタイルの行は、測る世界の振る舞いによって値が変わる量で、「変わらない事実」ではなかった可能性が高い。記憶の対象そのもの（申し送りの論点1）をユーザと見直す。

## 予想との照合（PLAN 2-3）

| 予想 | 結果 |

| 信念の漂いが縮み、`untold` に近い幅に収まり、1 を超えるシードは無くなるか大きく減る | **半分外れ**。幅は縮んだが `untold` より高いところに集まり、1 を超えたシードは平坦 7 / 12（2-2 は 5）・制約 3 / 12（2-2 は 4） |

| 平坦の個体数・成人到達率の悪化が消える | **外れ**。個体数は有意でなくなったが、成人到達率は両方の地図で有意に下がり、真後ろへの手が両方で有意に増えた |
| 孤児の証拠の年齢の中央値は寿命前後まで下がる | **外れ（長い側）**。中央値 約 2,900 tick（寿命の約 2.4 倍）、孤児の証拠 87% |
| 証拠を消す対の比較は有意でない | **当たり** |
