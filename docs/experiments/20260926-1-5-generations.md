# 1-5 数え上げ: 世代の数と、配分にかかる選択

判断は [`docs/history/20260926.md`](../history/20260926.md) の「1-5: 数え上げ」。

## 概要

- 確かめたかったこと: 配分を継承させたとき、40000 tick の中で選択が見えるだけの世代が回るか。
- 分かったこと: 約 37 世代（世代の長さ 約 1160 tick）。配分の選択差は1世代あたり +0.004〜+0.005。2〜3 世代で実験の標準誤差の2倍に届くので、tick 数は延ばさない。
- 次にすること: 両親のどちらか一方の段を継ぎ、確率 0.1 で1段ずらす形で入れる。

## 条件

| 項目 | 値 |
| --- | --- |
| コミット | f13c536（`cmd/count` の `generations` は作業ツリーに足した状態で測った。世界のコードは f13c536 のまま） |
| マップ | flat (64x48) / constrained (64x48) |
| tick 数 | 40000（選択差は tick 10000 より後に生まれ、終わりまでに死んだ身体） |
| シード数 | 12（最初のシード 1） |

**再現方法**:

```
go run ./cmd/count -what generations -map flat -w 64 -h 48 -seeds 12 -ticks 40000
go run ./cmd/count -what generations -map constrained -w 64 -h 48 -seeds 12 -ticks 40000
```

世代は、最初の身体を 0、子を年上の親の世代 ＋ 1 とした。世代の長さは子が生まれたときの親の年齢の平均。選択差は 共分散(配分, 生涯出生数) ÷ 生涯出生数の平均。

## 結果: flat

| 量 | 値 |
| --- | --- |
| 終わりに生きている身体の世代の平均 | 37.4 ± 0.1 |
| 子が生まれたときの親の年齢の平均（世代の長さ、tick） | 1163 ± 1 |
| 速さへの配分の選択差（共分散(配分, 生涯出生数) ÷ 生涯出生数の平均） | 0.00483 ± 0.00080 |
| 生まれた身体の配分の標準偏差 | 0.1585 ± 0.0004 |
| 出生（1シードあたり） | 5758 ± 4 |

## 結果: constrained

| 量 | 値 |
| --- | --- |
| 終わりに生きている身体の世代の平均 | 37.4 ± 0.0 |
| 子が生まれたときの親の年齢の平均（世代の長さ、tick） | 1155 ± 1 |
| 速さへの配分の選択差（共分散(配分, 生涯出生数) ÷ 生涯出生数の平均） | 0.00377 ± 0.00072 |
| 生まれた身体の配分の標準偏差 | 0.1582 ± 0.0002 |
| 出生（1シードあたり） | 5836 ± 4 |
