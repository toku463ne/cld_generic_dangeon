# 人間中心の世界（8:1）の基準——2 回目（小の測定）

判断は [`docs/history/20261011.md`](../history/20261011.md)。**小の測定**（constrained・4 シード・20000 tick・`-brief`）。地面は人間 8/9・獣 1/9（足元の帯、森）、食料と最初の身体は 3/4・1/4 の世界（コミット baae97f）。基準 `warmed`（狩りは 5000 から）、対照 `peaceful`（狩りなし）。以後の測定の基準値。

## 1. 概要

- 確かめたかったこと: 人間中心の世界で獣が続くか、獣が人間の数をどれだけ動かすか。
- 分かったこと: **獣は 4 シードとも続き（37 体）、人間は 141 対 144 で獣の有無はほぼ動かさない**（−2%、誤差内）。攻撃 17・倒された人間 13（うち眠っているところ 4、よその地域 7）、20000 tick に。人間がよその地域にいる割合 0.016、獣がよその地域にいる割合 0.146（帯が 5 行なので、獣はよく人間の地面へはみ出す——人間の地域 0 にいる獣は 9%）。人間の成人の平均予算は獣がいると 1.13 対 1.09 で高い（倒されるのが予算の低い側か、肉か。小では決めない）。
- 予想との照合: 人間 160〜175 と書いたが 141（食料 450 単位で 141 体: 300 単位の 90 体と同じ率）。獣 37 は予想の範囲の上、倒された 13 は範囲内。
- 読み: これが以後の基準。獣は少なく、人間の数を動かさない。狩りの連鎖の規則（脅威・避難所・帰巣・脅威の行）はこの世界では小さな数の上で動くので、以後それらを測るときは半々の世界（10-6 までの測定）の数と比べない。
- 次にすること: 段階 11（交換とコイン）へ。
