# 人間中心の世界（8:1）の基準——1 回目（小の測定、獣は絶滅）

判断は [`docs/history/20261011.md`](../history/20261011.md)。**小の測定**（constrained・4 シード・20000 tick・`-brief`）。地面・最初の身体・食料がすべて人間 8/9・獣 1/9 の世界（コミット 40b6378）。基準 `warmed`（狩りは 5000 から）、対照 `peaceful`（狩りなし）。

## 1. 概要

- 確かめたかったこと: 人間中心の世界で、獣が人間の数をどれだけ動かすか。
- 分かったこと: **獣が 4 シードすべてで絶滅した**（両条件とも。tick 6000〜8000）。最初の獣は 16 体、食料 67 単位は余っている（地面に 20〜45 単位）のに、雌が 1 体 → 0 体になって途絶えた。食料が支える 15〜20 体は、この繁殖（視界の異性と交配、産後の回復）には小さすぎる数。人間は 181 対 180 で、獣の有無は何も変えない（獣がいないので当然）。
- 予想との照合: 外れ（獣 15〜25 体で続くと書いた）。
- 読み: 9-7a の「交配の密度が縛る」と同じ。池の大きさは密度ではなく絶対数を決め、絶対数が 20 を切ると性比の揺らぎで途絶える。
- 次にすること: 地面は 8:1 のまま、食料と最初の身体の取り分を 3:1 にする（`engine.HumanFood`。獣の帯は食料が濃い）。測り直す。
