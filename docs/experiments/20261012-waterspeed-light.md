# 水の中で遅くなる——小の測定

判断は [`docs/history/20261012.md`](../history/20261012.md)。**小の測定**（constrained・4 シード・20000 tick）。基準 `wadefast`（水でも速さが落ちない 12-1 の世界）、対照 `warmed`（`WaterSpeed` 0.5）。コミット 8c0b162。8:1 の世界。constrained の水は 2 タイル幅の帯。

## 1. 概要

- 確かめたかったこと: 泳げない身体が水の中で遅くなる規則（`VISION.md` 追記）が世界をどれだけ動かすか。既定を変えるので測る。
- 分かったこと: **成人到達率が下がる**: 0.819 → 0.801（−0.018、対の差 4.9σ）。水にいる割合 0.0082 → 0.0100（+22%、1.8σ）、獣が水にいる割合 0.009 → 0.016。人間 139 → 132（−5%、誤差内）、餓死・出生・売買は誤差内。人間がよその地域にいる割合 0.009 → 0.013（誤差内）。
- 予想との照合: 予想は書いていなかった（規則を入れてから測った）。
- 読み: 水の帯を渡るのに倍の tick がかかり、そのあいだ消耗が `WaterBurn` 倍なので、渡る身体の損が増える。子は体力の上限が低いので先に響く（成人到達率）。渡る回数そのものは減っていない——値付けは陸に立っているときの速さで水を越える計画を読むので、遅くなることを渡る前には読まない。
- 次にすること: 既定のまま入れる（`VISION.md` の要求）。渡る前に遅さを読ませるなら、歩く tick を経路の地形で読む変更が要る（値付けの全体に効くので、別の段階でユーザと相談する）。
