# 1-3 数え上げ: 死にかけの身体は、回復手段が見つからないときに交配するか

判断は [`docs/history/20260926.md`](../history/20260926.md) の「1-3: 死にかけの身体の交配」。

## 概要

- 確かめたかったこと: `VISION_CHECKS.md`「死にかけのノードは回復手段が見つからないとき、確率的に子孫を残す行動をとる」の (a)（0 より大きい）と (c)（食料が見えるときより多い）を 1-3 の世界で。
- 分かったこと: 承認された判定の「死にかけ」（交配以外の最善の手の死ぬ確率が 0.5 以上）では、**見えている食料へ歩く続きがすでにその確率に入っているので、「食料が見える死にかけ」は食料で助からない身体だけになり、(c) の差が原理的に出ない**（両方 1.0000）。「食べなければ死にかけ」（地域を動き続ける行だけの死ぬ確率が 0.5 以上）で読むと、(a) は満（0.9999・1.0000）、(c) も有意に満たすが差は小さい（+0.0097・+0.0052）。交配してからでも見えている食料へ歩いて食べられるため。(b)（1 より小さい）は満たさない。
- 次にすること: 判定の「死にかけ」を「食べなければ死にかけ」に直す（ユーザに申し出る）。(b) は頭の良さの段階で見る。

## 条件

| 項目 | 値 |
| --- | --- |
| コミット | 3068643（世界のコードは a43c16a のまま） |
| マップ | flat (64x48) / constrained (64x48) |
| tick 数 | 40000（tick 5000 より後の、交配の手が候補にあった決定） |
| シード数 | 12（最初のシード 1） |

**再現方法**:

```
go run ./cmd/count -what mate -map flat -w 64 -h 48 -seeds 12 -ticks 40000
go run ./cmd/count -what mate -map constrained -w 64 -h 48 -seeds 12 -ticks 40000
```

「食料が見える」は視界（足元を含む）に食料が1つ以上あること。
