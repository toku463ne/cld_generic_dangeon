# 7-1b 明るさを連続にする（`TwilightTicks` 100、O21）

判断は [`docs/history/20261002.md`](../history/20261002.md) の「7-1b の測定」。切り替えの 7-1 は [20261002-7-1](20261002-7-1.md)。

## 1. 概要

- 確かめたかったこと: 明るさを台形（夕暮れ・夜明け各 100 tick）にし、薄明では身体とタイルごとの閾値で見えるタイルが決まる形で、切り替えの 7-1 から何が変わるか。
- 分かったこと:
  - **1日の平均の個体数: 平坦 約 151（7-1 は 149、`daylong` 170）、制約 約 140（7-1 は 137、`daylong` 166）。** 夜の損はわずかに小さくなったが、ほとんどは残る。
  - **夜明けの食事の山は低く広くなった**: 夜明けの 100 tick（明るさ平均 0.51）で 4.4〜4.6、続く 100 tick で 2.5（7-1 は夜明けの最初の 100 tick に 5.1）。
  - 夕暮れ（明るさ平均 0.49）の食事は 1.3〜1.4 で、夜（1.3〜1.6）と同じ程度——見える割合が下がるとすぐ食事も下がる。夕暮れの前の食事は昼の他の時間と変わらない（夜を見込まない）。
  - 出生は昼の終わりにそろう（301〜400 tick で個体数が約 14 跳ね上がる）。餓死は夜の後半（801〜900 tick で 1.3〜1.5）。成人の体力が一番低いのは夜明け（約 40）。
  - 崩壊は制約 36 シードで 0。東の身体がいなくなったシードは 12。
- **測り方の注意**: tick 0 を明るさが満ちた最初の tick にしたので、7-1 とは1日の区間が 50 tick ずれている。`cmd/experiment` のチェックポイント（1000 tick ごと）は夜明けの途中に当たる（7-1 は夜の最後）——対の差の「人口（最終）」（平坦 152・制約 134）は7-1 の値（116・100）と比べられない。1日をとおした量は `daynight` の表で比べる。
- 読み: 連続の明るさは 7-1 の世界の形をほぼそのまま残し、夜明けの山をならした。身体はまだ夜を見込まない。
- 次にすること: 7-2（暗く・明るくなるまでの時間を学び、値付けが読む）。

## 予想との照合（PLAN 7-1b）

| 予想 | 結果 |
| --- | --- |
| 夜の損は 7-1 より小さい（1日の平均の個体数は 7-1 と `daylong` の間） | 当たり、ただし差は小さい（平坦 +2、制約 +3） |
| 夜明けの食事の山は低く広くなる | 当たり（5.1 → 4.4〜4.6、続く 100 tick も 2.5） |
| 出生が昼の終わりにそろうのは残る | 当たり |
| 1 tick は切り替えの 7-1 より数 % 重い | +9%（`PARAMETERS.md`） |

## 完了条件

- 明るさの台形・閾値の見え方・設定の検査（`TestNight`）: 満。
