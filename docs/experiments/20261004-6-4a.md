# 6-4a 父が休んでいる母へ食料を送る（`FatherSends`・`SendGate` 0.01、配分なし）

判断は [`docs/history/20261004.md`](../history/20261004.md) の「6-4a の測定」。

## 1. 概要

- 確かめたかったこと: 配分を消し、父が自分の命に効かない足元の食料を休んでいる母の休める場所へ送る（ユーザの案）と、母は養えるか。
- 分かったこと:
  - **父は足元の食料をほとんど全部送る: 1シードあたり 12600（平坦）・17900（制約）単位**——配分（3500・2600）の 4〜7 倍、出生 1 回あたり 11〜13 単位（予想 1〜2 の 10 倍。事前カウントの「足元に残した食料」は決めた tick で数えていて、決めずに歩き過ぎる tick を数えていなかった）。
  - **届いた食料を母が取ったのは 0.4〜0.6%、他者が 7〜8%、残りの約 9 割は休める場所で古びた。** 母は休める場所へ行く理由をまだ持たない（6-4b）。
  - **平坦: 個体数 99 → 47（−53%）、崩壊 5 / 12、出生 −43%。** 制約: 75 → 68（−9%、有意でない）、崩壊 0 / 12（36 シードでも 0）、出生 −16%。
  - 女の割合 0.61〜0.63 は変わらない（配分ありと同じ）。成人到達率も変わらない。
- 読み: 父は満腹なことが多く、門がほとんどいつも開く。送られた食料は探す場所から休める場所へ移り、そこで腐る——食料の総量は保たれるが、身体が届くところから消える。平坦の地図では、休める場所の外の食料が細って崩壊する。送る量を母の要るぶんに絞らないと、母が休める場所に留まっても（6-4b）大半は腐る。
- 次にすること: 送る量の絞り方をユーザに確かめる。
