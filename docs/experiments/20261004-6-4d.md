# 6-4d 家を出産のときに決め、すぐにあきらめない（`HomeKeep`）

判断は [`docs/history/20261004.md`](../history/20261004.md) の「6-4d の測定」。

## 1. 概要

- 確かめたかったこと: 家を出産のときに決め（届く先と行く先を同じタイルに）、母が休みのあいだ家を読み続けると、送られた食料が母に届くか。比べるのは 6-5a（配分あり、`fatherless`）と 6-4c（`homeforget`）。
- 分かったこと（base 対 `fatherless`）:
  - **母が家で食料を見つける割合は 12〜13% → 41〜47%** に上がった（届く先と行く先がそろった）。
  - **それでも届いた食料を母が取ったのは 39 単位（届いた 420〜450 の 9%）、約 85% は古びた。** 家に行って食料があったのは 86〜94 回なのに取ったのは 39——満腹で1食が入らないときは食べずに去り、自分の物として残ったまま古びる。
  - **平坦: 個体数 99 → 40（−59%）、崩壊 5 / 12。制約: 75 → 53（−29%）、崩壊 3 / 12（36 シードで 4）。** 6-4c より悪い。家へ通う分だけ探す時間が減り、出生が −40〜−50%。
- 読み: 届いた食料を母が使えるようになっても、配分の代わりにはならない。配分は母がどこにいても、要るときに体力として入った。送って家に置く形は、母に「取りに行く時間」と「満腹で食べられない」の二つの損を負わせ、届いた食料の大半が古びる。6-3 から 6-4d まで、配分を休める場所と父に置き換える形はどれも配分に届かなかった。
- 次にすること: ユーザに確かめる。
