# 4-3: 配分を切って測る（`unprovided`）

判断は [`docs/history/20261002.md`](../history/20261002.md) の「4-3 の測定」。前は [4-1](20261002-4-1.md)。

## 1. 概要

- 確かめたかったこと: 食料を持てる世界（4-1）で、休んでいる母への配分（3-3 系列）を切っても、母が自分で食べて・持ってやっていけるか。base（4-1）と `unprovided`（配分を切った同じ世界）の対の差で読む。規則は足さない。
- 分かったこと:
  - **持つことは配分の代わりにならない。** 成人のうち女の割合 0.59〜0.62 → **0.36**（平坦 −0.262 ± 0.008、制約 −0.230 ± 0.010）。完了条件の 0.4〜0.6 を外れた。
  - 休み明けの母の体力 75〜78 → 55。母は休みのあいだに自分で食べる回数を 0.31〜0.35 → 0.81〜0.82 に増やして埋め合わせるが、配分の 51〜58 には届かない。
  - 出生 −18〜−24%（平坦 −1301 ± 53、制約 −992 ± 429）、餓死も −22〜−28%、老いによる死 +27〜+31%。**個体数は変わらない**（平坦 +4.8 ± 2.8、制約 +1.4 ± 28）——食料で頭打ちの世界では、出生が減ると入れ替わり（餓死）が減る。成人到達率は変わらない。
  - **崩壊（制約、36 シード）: base 4、`unprovided` 6。** seed 1〜12 は 2 対 2、13〜36 は 2 対 4。崩壊したシードが下限を割った tick は `unprovided` で早い（13〜36 で 13461 ± 2440、base 26994 ± 10430）。差は見分けられない程度だが、配分を切ると強まる向き。
- 読み: 4-1 で持つのは身体の 0.5% で、休んでいる母の食べる量を埋めるほど運ばれない。配分は、場所の記憶と定住場所が入る 6-3 まで残す（PLAN 4-3 の完了条件どおり）。
- 次にすること: 4-4（食料が古びる）は、PLAN の条件（4-1〜4-3 で長く持ち歩く身体が少なければ 6 の直前まで遅らせる）に当たるので遅らせる。段階5（記憶容量と場所）へ。
