# 9-7b-2 種族の住み分け（`Map.PoolFood`）と、他種族に閉じた定住場所（`ClosedPlaces`）

判断は [`docs/history/20261010.md`](../history/20261010.md)。全部の形式。**基準は `roomy`**（人間の食料を上半分／上・左の固まり、獣の食料を下半分／右・下の固まりに戻し、各種族の池を 300 にする——`FoodCap` 2 倍。定住場所は他種族に閉じる）。比べたのは `single`（1 種族・300・地図全体）、`roomytogether`（`roomy` で池を重ねる＝混住。9-7b-1 の `ample`）、`roomyopen`（`roomy` で定住場所を他種族に開く＝9-7b-2b の切り分け）。12 シード、constrained 2 並列・patches 3 並列。コミット 21593b7。flat は池を分けられないので測らない。末尾に、上限 300 のまま地域で分けた最初の測定（constrained、コミット 64f7fb6）を付す。

## 1. 概要

- 確かめたかったこと: (2a) 食料の ID を地域で分けると 2 種族は別々の地域に住み、それぞれ `single` と同じ数に落ち着くか。よその地域へはどれだけ行くか。(2b) 他種族を定住場所に入れないことは世界を動かすか。
- 分かったこと:
  - **(2a) 住み分けは混住より強い。** 同じ総量 600 で、地域で分けた `roomy` は constrained 148 体（人間 79・獣 70）、patches 260 体（138・122）、崩壊 0・絶滅 0。池を重ねた `roomytogether` は constrained 92（50・42。絶滅 人間 1/12・獣 2/12）、patches 137（55・82。各 1/12）。分ければ各種族の食料が自分の半分の地図に集まって 1 タイルあたりの密度が倍になり、どちらの種族も `single`（constrained 65、patches 110）より多く残る。
  - **よその地域にいる身体は約 5%**（constrained、人間・獣とも 0.05）。patches は誰の食料も戻らない地域 0 に `single` でも 25% がいるので、対の差で読むと +0.02。食料が見えない地域へ行くのは「知らない地域」の事前分布による探索だけで、種族は自分の地域にほぼ定住する。
  - **(2b) 定住場所を閉じても世界は動かない。** `roomyopen` は `roomy` と個体数・絶滅・よその地域の割合が同じ（constrained 149 対 148、patches 256 対 260）。開くと他種族の場所で始まる眠りが constrained で 1 実行あたり 61 回（建てた場所での眠り 440 回の 14%）、patches で 138 回（2944 回の 4.7%）あり、constrained では成人到達率が −0.019 ± 0.008。閉じた既定でも 0.6〜10 回出るのは、他種族の身体が立っているタイルを囲んで場所が建ち、その身体がそこで眠るから（入れないのであって追い出されない）。
  - **上限 300 のままでは住み分けても崩壊する**（末尾）: constrained で base 11/12 が下限を割り（人間 17.6・獣 6.0、獣の絶滅 4/12）、池を重ねた `together` は 12/12。1 種族あたり 150 単位の世界は、分け方によらず下限の下に落ち着く（9-7b-1 と同じ）。
- 予想との照合: (2a) 個体数は予想（constrained 人間 60〜80・獣 50〜70、patches 各 90〜110）の上端か上（79・70、138・122）。絶滅 0 は当たり。よその地域 0.05 は予想の幅（0.03〜0.08）の内。`roomytogether` は 9-7b-1 の `ample`（61・63、101・98）より少なく絶滅も出た——最初の身体の置き方（種族を先に引く）で世界が変わった分と、閉じた定住場所の分。(2b) 当たり（誤差内）。他種族の場所で始まる眠りは予想（20 回未満）より多い（61・138）。
- 読み: **`VISION.md` の「種族は別の地域にいて時々接触する」は、食料の ID の場所だけで出る。** 種族の行に地域を書かなくてよい。閉じた定住場所は VISION の行として入れてよく、世界を変えない。世界の大きさは種族の数に比例して要る——本番の地図は種族ごとに `single` の世界 1 つ分の食料を持たせる（既定の `FoodCap` は 300 のまま。これは地図の設計）。
- 次にすること: 9-7b-2c 水と魚（水を「入れるが危ない」地形に、水の中に沸く ID、魚の行は水だけ）。
