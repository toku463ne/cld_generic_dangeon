# 6-4a の事前カウント: 父が休んでいる母へ送れる食料（`fatherroom`）

判断は [`docs/history/20261004.md`](../history/20261004.md) の「6-4a の事前カウント」。

## 1. 概要

- 確かめたかったこと: 父が手にした食料を、自分の命に効かないとき（失っても窓の中の死ぬ見込みが 0.1 以下しか上がらないとき）母の休む定住場所へ送る規則（ユーザの案）で、出生 1 回あたりどれだけ届くか。今の配分は出生 1 回あたり約 1.8 単位を母に渡している（[provision-recount](20261004-provision-recount.md)）。
- 分かったこと:
  - **母の休みの間に父が食べる・拾う食料は出生 1 回あたり 0.64〜0.67 単位、そのうち送れるのは 0.54〜0.58 単位**——配分の 3 割。
  - 父が足元の食料を食べも拾いもせずに残した決定は、出生 1 回あたり 1.4〜1.9（決めた tick で数えたので、同じ単位を何度も数える上限）。
- 読み: 父が「取った」食料だけを送ると配分の 3 割しか届かない（ユーザの見立て「まとめるなど選択肢が無いと十分届かない」のとおり）。足元の食料を、命に効かないなら送る形にすれば、上限は配分に近い（0.5 ＋ 1.4〜1.9）。
