# 7-4 気温（`Temperature`、`NormalTemp` 20・`TempBurn` 30、地図は全地域 11〜20 度）

判断は [`docs/history/20261003.md`](../history/20261003.md) の「7-4 の測定」。

## 1. 概要

- 確かめたかったこと: 地域の気温の範囲が明るさに沿って動き、平温からのずれで消耗が上がる（真昼は平温、暗闇で +30%）とき、世界がどれだけ縮むか。身体は気温を知覚せず、7-3a の「感じた消耗の上がり方」でだけ読む——睡眠負債に続く2つ目の原因で、その読みが「減りの加速をリスクととらえ適切に行動」（`VISION_CHECKS.md`）になるか。
- 分かったこと:
  - **個体数は 平坦 −21%（148 → 117）・制約 −33%（131 → 88）**。予想（−8〜−20%）より大きい。制約は東が空になるシードが 18 / 36 → 31 / 36 に増えた分が上乗せ（崩壊は 0 / 36。東に積もる食料は古びて 62〜72 で頭打ち）。
  - **成人到達率 0.98 → 0.83（両方の地図）。** 子は体力の上限が半分（`ChildAbility`）で、満腹の子でも夜（約 500 tick、暗闇で視界 0）を +30% の消耗では越えられない（計算: 上限 0.5 × 窓 1000 tick ÷ 1.3 ≒ 385 tick）。`templess` では満腹の子がちょうど夜の長さもった。出生は昼の終わりにそろう（7-1 以来）ので、生まれてすぐ夜に入る。
  - **眠っている割合が夜に寄った: 夕暮れから夜の前半で 8〜11%、昼は 0.3〜3%**（`templess` は 1日をとおして 1〜3%）。眠りは夕暮れに始まり、1日の 3 分の 1 で夜の終わりの前に明ける。1日の平均は 2.1 → 4.4%（平坦）・2.5 → 5.2%（制約）。
  - **夜に寄る原因は読みの非対称だった**（補助の確認: `BurnRead` を切ると夜の眠る割合は 1〜2% で昼と変わらない）。夕暮れに消耗が上がると、起きている手は感じた上がり方が窓の半分続くと読んで消耗を 2 倍以上に見積もるが、寝る手は眠る間と起きたあとを生理（今の消耗と負債）で読み、感じた上がり方を読まない。起きている手だけが重く読まれ、寝る手が勝つ。
  - **夕暮れの食事・拾う手は増えない**（予想は外れ）。1体あたりの食事は1日をとおして +15〜25%（身体が減って1体の取り分が増えた）で、夕暮れも同じ割合——夕暮れだけの備えは出ない。夕暮れに勝つのは食べる手ではなく寝る手だった。
  - 餓死は夜の後半（701〜800）に山（1.8〜1.9、`templess` は 801〜900 の 1.4）。睡眠不足による死は減った（−25〜35%。眠るようになった）。
- 性能: 1体あたり約 +7%（`PARAMETERS.md`）。表は個体数に比例して減った（561、88 体）。
- 次にすること: ユーザに確かめる——夜に寝るのが「規則に書かずに」出たが、寝る手が感じた上がり方を読まない非対称によるもので、O15 の言う「夜の視界の結果」ではない。このまま受け入れるか、寝る手にも感じた上がり方を読ませる（非対称を消す。夜に寝るのはおそらく消える）か。子が夜を越えられない件は、気温の範囲（地図の値）か子の能力の問題で、同じく判断が要る。

## 予想との照合（PLAN 7-4）

| 予想 | 結果 |
