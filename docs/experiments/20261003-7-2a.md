# 7-2a 値付けが視界を読む（`SightRead`）

判断は [`docs/history/20261003.md`](../history/20261003.md) の「7-2a の測定」。

## 1. 概要

- 確かめたかったこと: 「歩き続ける」の見込みに、1タイル進むと視界に入るタイルの数（暗闇 1・真昼 3）を掛けたとき、昼の交配・出生、夕暮れの食事と拾う手、個体数がどう動くか。
- 分かったこと:
  - **平坦では何も動かない**（対の差はすべて標準誤差の2倍以内。1日の中の食事・拾う手・餓死・体力も区間ごとに同じ）。
  - 制約では1日の平均の個体数が約 140 → 147 だが、対の差（人口 +13 ± 8、出生 +191 ± 148、餓死 +158 ± 123）はどれも有意でない。`sightblind` 側の標準誤差が大きく（東が空になったシードの混ざり方）、差はその揺れの中。
  - **夕暮れ（明るさ 0.49）の食事 1.29〜1.42 → 1.32〜1.42、拾う手 0.89〜0.98 → 0.90〜0.95——変わらない。**
- 読み: **見込みを昼に 3 倍にしても、手の選び方はほとんど変わらない。** 足元の食料は入りきれば食べ、交配は `ChildWorth` の重みで選ばれ、「歩き続ける」の危険の大きさが手の順位を変える場面が少ない（前身の教訓「情報を足しても居場所は動かない」と同じ形——足し算側の情報で、非ゼロになる場面が少ない）。**このままでは 7-2b（暗くなるまでの時間を読む）も動かない見込み**——明るさの見込みを窓の中で切り替えても、それが手の順位を変える場面が少ない。
- 次にすること: 7-2b の前に余地を数える——決定のうち、倍率を夜（1）に変えると最善の手が変わる割合。
- 崩壊: 制約 12 シードで両条件とも 0。36 シードの `lock` はメモリ不足で Claude Code に止められ、まだ測っていない。
