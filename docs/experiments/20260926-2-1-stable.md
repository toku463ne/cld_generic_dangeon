# 2-1: 変わらない事実の行だけを渡す（StableRows）

判断は [`docs/history/20260926.md`](../history/20260926.md) の「2-1: 3回目の測定」。前の版は [2-1](20260926-2-1.md)・[2-1-decay](20260926-2-1-decay.md)。

## 1. 概要

- 確かめたかったこと: 変わらない事実の行（最近通ったタイルは地域より乏しい——地域との比で持つ）だけを古びさせずに渡し、変わる事実（地域の今の豊かさ）は渡さない形で、文化が個体より長生きし、世界を悪くせずに動かすか。
- 分かったこと: **崩壊は無くなった**（両方の地図で 0 / 12）。**通ったタイルの行の証拠の 98% が孤児の証拠で、その年齢の中央値は 13,101〜13,663 tick——寿命の中央値（1201 tick）の約 11 倍**。**引き返しが減った**（平坦 5.3% → 3.9%、制約 8.9% → 7.5%、どちらも有意）——ユーザの最初の見立てどおり。**制約の地図の個体数が有意に増えた**（+7.75 ± 1.49）。**成人到達率と餓死数には有意な差が無い**（完了条件が名指しする2つ）。
- 次にすること: 完了条件の「世界を動かす」を何で判定するか、ユーザに確かめる（餓死数は出生とほぼ同じだけ動く釣り合いの量で、この世界では感度が低い）。

## 予想との照合（PLAN 2-1、StableRows）

| 予想 | 結果 |
| --- | --- |
| 崩壊しない。個体数は `untold` と有意に違わない | 崩壊しないは当たり。**個体数は制約の地図で有意に増えた**（+7.75 ± 1.49）。平坦 +3.42 ± 1.93 |
| 通ったタイルの行の孤児の証拠の年齢の中央値が寿命を超える。地域の行の又聞きは 0 | 当たり（約 13,000 tick、寿命の約 11 倍。地域は 0） |
| 引き返しは `untold` より多い | **外れ（逆）**: 減った（−0.014、両方の地図）。比で持つと、通ったタイルの推定が地域の豊かさに合わせて動き、`mixed` で起きたジグザグ（精密だが絶対値で持つ推定が、地域の変化に合わない）が消えた |
| 成人到達率は下がるかもしれない | 有意な差なし |
