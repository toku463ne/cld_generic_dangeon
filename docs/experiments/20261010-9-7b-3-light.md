# 9-7b-3 植物（`Seed` を持つ ID）——小の測定

判断は [`docs/history/20261010.md`](../history/20261010.md)。**小の測定**（constrained・4 シード・20000 tick・`-brief`）。基準は `roomy`（人間・獣が各 300 の池を自分の半分に持つ）、対照は `planted`（上限 600 を人間・獣・植物で 3 等分。植物は両種族が食べ、生えている単位の隣に戻り、20 単位から広がる。取り分は地図全体）と `strewn`（同じ植物が取り分で戻る＝広がらない）。コミット df8e2b5（数字は 12e3cd0 の 1 回目と同じ。2 回目は種族ごとの地域別人口比の表を簡易レポートに出すための再実行）。**4 シードなので差の有無だけを読む。**

## 1. 概要

- 確かめたかったこと: 植物は広がるか。種族をまたいで共有する池は住み分けを崩すか。個体数は変わらないか。
- 分かったこと:
  - **広がる植物は始めた場所に留まる。** `planted` の植物のある地域数は 2.0（4 地域のうち）、`strewn` は 4.0。隣にしか戻れない植物は、群れの縁で食べられ・古びる（`FoodLife`）ので、始めの 20 単位が落ちた豊かな地域（0 と 2）の群れから出られない。
  - **広がる植物は世界を貧しくする。** `planted` は合計 159 体（`roomy` 185、−14%）、出生 −25%。`strewn` は 189 で `roomy` と同じ。隣にしか戻れない池は、戻れる場所が群れの縁に限られて戻る速さが落ち（地面の植物は 58 で `strewn` の 40 より多く残る＝食べられていない）、池 1 つ分の食料が目減りする。
  - **共有する池は住み分けを崩す。** 人間が下半分（地域 2・3）にいる割合は `roomy` 0.056 → `planted` 0.169（`strewn` 0.095）、獣が上半分にいる割合は 0.051 → 0.117（0.092）。それでも 8 割以上は自分の半分にいる。
- 予想との照合: 個体数「同じ」→ 外れ（−14%）。植物が 4 地域に広がる → 外れ（2 地域）。住み分けが 0.08〜0.15 に崩れる → 当たり（人間 0.17、獣 0.12）。`strewn` は `planted` と同じ → 外れ（`strewn` は `roomy` と同じで、`planted` だけ貧しい）。
- 読み: 植物の「広がる」は、食べる者がいる世界では「留まる」として現れる——群れの縁が食べられる速さが広がる速さを上回る。VISION の「生息範囲を広げる」を出すには、戻る率を種の散布として群れの大きさに比例させる（単位ごとに種を落とす）か、縁から離れた場所にも低い率で飛ぶ（風・鳥）か、どちらかが要る。今の形は「植物は貧しい食料」として働き、それ自体は VISION と矛盾しない。共有の池が住み分けを 1 割ほど崩すのは、接触（段階10）の種になる。
- 次にすること: 9-7b を閉じる大の測定（`roomy` 基準に `planted`、`waters` で `fish` 対 `roomy`）。植物の広がり方（散布の形）は閉じたあとユーザと決める。
