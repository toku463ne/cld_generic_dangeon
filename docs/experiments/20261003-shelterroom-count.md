# 段階6 の事前カウント: 暖かく休める場所の余地（`shelterroom`）

判断は [`docs/history/20261003.md`](../history/20261003.md) の「段階6 の事前カウント（休める場所）」。

## 1. 概要

- 確かめたかったこと: 定住場所の「安全に休める」役割（ユーザ判断で段階6 をここから入る）が働く余地。今の世界（寒い夜、7-4）の夜の餓死のうち、夜が暖かければ夜明け（明るさが半分に戻る）までもった死がどれだけあるか。子と成人に分け、死んだ身体が明るさの落ち始めにどこにいたか（象限の中心までの距離）も数えた。
- 分かったこと:
  - **餓死の大半は夜**: 子 97〜98%、成人 78〜79%。
  - **成人の夜の餓死の 31〜32% は、暖かい夜なら夜明けまでもった。** 1シードあたり 15000 tick で約 210〜270 体。
  - **子は 5% だけ。** 子の夜の死は、寒さの分を足しても夜明けまで足りない——上限が半分で、夕暮れに生まれる子は暖かくても一晩もたない。7-4 で成人到達率が下がった分は、その夜の寒さより、寒さで身体が減り配分や食事の形が変わった分が大きいと読める（この数えは1晩の中しか見ない）。
  - 死んだ身体は、明るさの落ち始めに最寄りの象限の中心から中央値 10 タイル（25〜75% で 7〜13）。既定の速さで約 40 tick——夕暮れ（100 tick）の中で歩ける。
- 読み: 暖かく休める場所には成人について実在する余地がある。子を救うのは「暖かい場所」ではなく、夜の前に満たされること（親が運ぶ・蓄え）のほう。
- 次にすること: 休める場所の形（どこに・いくつ・何が暖かいか・身体がどう知るか）をユーザと決める。

## 2. 条件

| 項目 | 値 |
| --- | --- |
| コミット | c2e0b12 |
| マップ | flat / constrained (64x48) |
| tick 数 | 20000（tick 5000 より後の死） |
| シード数 | 12 |
| 条件 | base |

```
go run ./cmd/count -what shelterroom -map flat -w 64 -h 48 -seeds 12 -ticks 20000   # constrained も
```

最初の形（7be4b6e）は「明るさが 1 に戻るまで」もつかで読み、子は 0% だった。身体は夜明けの途中から食べられるので、「半分に戻るまで」に直した。
