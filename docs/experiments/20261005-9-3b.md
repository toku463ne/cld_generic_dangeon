# 9-3b 建てる損得を直す（`ReuseNights`・`SeekBed`）

判断は [`docs/history/20261005.md`](../history/20261005.md)。軽い形。`hopeful`（9-3、どちらも無し）を基準に、`unbedded`（`ReuseNights` だけ）と base（両方）を比べた。

## 1. 概要

- 確かめたかったこと: 戻る見込みを毎晩の体感から学び（`ReuseNights`）、建てる手を「建てずに眠る一番良い形」と比べる（`SeekBed`）と、寝床のそばの建築と flat の下がりが直るか。
- 分かったこと:
  - **建て始めは半減**（flat 166 → 82、patches 226 → 111、constrained 151 → 75）。残るのは、票が溜まる前の若い成人の建築と同点の抽選。予想の「30 以下」は行き過ぎだった。
  - **flat の個体数は +4.7〜+5.8 戻り、崩壊は 2/36 → 0〜1/36**。出生はどの地図でも増える向き（flat +114——建てる代金と仕事に費やされていた分が交配へ）。
  - **効きの大半は `ReuseNights`**（unbedded ≈ base）。`SeekBed` は建て始めと暖かい眠りをさらに削る（patches 144 → 111、13.4% → 7.3%）が、個体数は動かさない。意図（寝床を探すか建てるか）の形として残す。
  - 休める場所で始まった眠りは下がる（patches 25.8% → 7.3%）——偽の黒字が作っていた暖かさだったということ。
- 予想との照合: 向きは全部当たり。幅は建て始めだけ外した（激減→半減。事前の2回が若い成人を点火し続ける）。
- 次にすること: ユーザに報告し、9-4（繁殖能力と出生確率）へ。
