# 1-5: 配分の継承と突然変異（速度の分布）

判断は [`docs/history/20260926.md`](../history/20260926.md) の「1-5: 測定」。

## 1. 概要

- 確かめたかったこと: 子が親の配分（速さ ⇔ 体力の上限）を継ぎ、確率 0.1 で1段ずれるとき、配分の分布がどこへ動いて落ち着くか。上を締める（逓減を強める）と個体数と成人到達率は動くか。速度の分布（画面横断時間・最速 ÷ 中央値）をいくつにするか。
- 分かったこと: **配分の平均は速さの側へ少し動いて落ち着く**（0.50 → 0.52 平坦・0.53 制約。最後の 4 分の 1 とその前の差は有意でない）。分布は端に張り付かず、標準偏差は 0.158 → 0.060 に縮む。**最速 ÷ 中央値は 1.23 から 1.12〜1.14 へ縮むだけ**（一度広がる、の予想は外れ）。中央値の身体の画面横断時間は ×1 で 4.1〜4.2 秒。上を締めると個体数は動かず、成人到達率は**両方の地図で**わずかに下がる（−0.004・−0.007）。
- 次にすること: 中央値の身体をユーザが操作して快適か確かめる。快適なら速度の表と測定の既定値を確定し、1-5 を閉じる。

## 予想との照合（PLAN 1-5）

| 予想 | 結果 |
| --- | --- |
| 配分の平均は 1-4 の選択勾配の向きへ動く。制約では速さ、平坦では相手の側へ | **半分外れ**: 両方の地図で速さの側（+0.02・+0.03） |
| （数え上げのあとに足した）両方の地図で速さの側へ動き、0.50〜0.60 で止まる。20 世代（約 23000 tick）までに | 当たり（平坦 0.52・制約 0.53、tick 10000〜25000 で頭打ち） |
| 逓減があるので、配分は端に張り付かない | 当たり（標準偏差 0.06、最遅・最速の身体が残る） |
| 最速 ÷ 中央値は、世代とともに一度広がってから落ち着く | **外れ**: 広がらずに 1.23 → 1.12〜1.14 と縮んだ。最初の身体が一様に引くので、初めがいちばん広い |
| 上を締めても個体数は動かない | 当たり（−2.3・−1.2、有意でない） |
| 成人到達率は、制約の地図でだけ有意に下がる | **半分外れ**: 両方の地図で下がる（平坦 −0.004・制約 −0.007） |
