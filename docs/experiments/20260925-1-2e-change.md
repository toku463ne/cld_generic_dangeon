# 1-2e 数え上げ: 決定はどれだけ前の手を繰り返し、変わるときに何が起きているか

判断は [`docs/history/20260925.md`](../history/20260925.md) の「1-2e: 数え上げ」。

## 概要

- 確かめたかったこと: `VISION.md` の「判断はイベント単位」（`VISION_CHECKS.md` O3）を入れても、1-2r の世界が変わらずに済むか。毎 tick の決定のうち、前と違う手を選んだものの直前に、身体から見える出来事（足元の食料・見えている食料・次の一歩が陸の外か別の地域）があったかを数える。
- 分かったこと: **決定の 98% は前と同じ手。手が変わった決定の 83〜84% は、3つの出来事のどれかの直後に起きている。** 残りのうち、平坦な地図では 97%、制約の地図では 68% が「同じ見えている食料へ歩き続けて道が曲がった」だけ。**手を「1歩」ではなく「意図」（食べる／見えている食料へ歩く／向きを保って歩く）として持てば、3つの出来事と「着いた」で、手の変わり目の約 99.6%（平坦）・94.6%（制約）を捉えられる。** 同じ手が続く長さは最大 271 tick。
- 次にすること: 1-2e を「意図を持ち、出来事が起きたときと一定 tick 何も起きなかったときだけ決め直す」として実装する。

## 条件

| 項目 | 値 |
| --- | --- |
| コミット | 9f163d7（`cmd/count` の `change` は作業ツリーに足した状態で測った。世界のコードは 9f163d7 のまま） |
| マップ | flat (64x48) / constrained (64x48) |
| tick 数 | 20000（決定は tick 5000 より後だけ数える） |
| シード数 | 12（最初のシード 1） |
| 比較対象（base） | なし（1-2r の世界の中の割合） |

**再現方法**:

```
go run ./cmd/count -what change -map flat -w 64 -h 48 -seeds 12 -ticks 20000
go run ./cmd/count -what change -map constrained -w 64 -h 48 -seeds 12 -ticks 20000
```

**数え方**: 意思決定トレースで各決定を読み、同じ身体の前の決定からの変化で、上から順に最初に当てはまるものへ分ける。「足元の食料が変わった」は「食べる」が候補にあるかどうかが変わったこと。「見えている食料が変わった」は視界の食料の集合が変わったこと。「前の手の次の一歩」は、前の決定で選んだ移動をもう1歩進めた先のタイルが、陸の外・水・今いる地域と別の地域のどれか。

## 結果: flat

前の決定と同じ手を選んだ割合: 0.9833 ± 0.0000

| 直前に変わったこと | 決定に占める割合 | そのうち手が変わった割合 | 手が変わった決定に占める割合 |
| --- | --- | --- | --- |
| 足元の食料が変わった | 0.0132 ± 0.0001 | 0.5043 ± 0.0035 | 0.3987 ± 0.0003 |
| 見えている食料が変わった | 0.0235 ± 0.0002 | 0.0650 ± 0.0008 | 0.0912 ± 0.0004 |
| 前の手の次の一歩が陸の外か別の地域 | 0.0059 ± 0.0000 | 1.0000 ± 0.0000 | 0.3504 ± 0.0004 |
| どれでもない | 0.9574 ± 0.0003 | 0.0028 ± 0.0000 | 0.1598 ± 0.0004 |

「どれでもない」で手が変わった決定の内訳

| 内訳 | 割合 |
| --- | --- |
| 同じ見えている食料へ歩き続けて、道が曲がった | 0.9742 ± 0.0005 |
| 地域を歩き続ける手から、見えている食料へ歩く手に変わった | 0.0002 ± 0.0001 |
| その他 | 0.0256 ± 0.0005 |

同じ手が続いた長さ（tick、全シードの手の変わり目をまとめて）: 中央値 21、90% 点 177、99% 点 270、最大 271
