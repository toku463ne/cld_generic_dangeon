# 8-2b 閉じ込めを直したあと（`closed`・`foodless`・flat 36 シード）

判断は [`docs/history/20261004.md`](../history/20261004.md) の「8-2b 閉じ込めを直したあとの測定」。

## 1. 概要

- 確かめたかったこと: 建ち上がった定住場所に家族以外が閉じ込められる誤りを直したあと（594cefa）、締め出しの損がどれだけ残るか。
- 分かったこと:
  - **閉じた場所のせいで消える移動の手は決定あたり 0.03〜0.14**（直す前 0.53〜1.09）。
  - **個体数（base 対 `unsettled`、12 シード）**: patches +0.2 ± 5.9、constrained −0.4 ± 3.4——下がりは消えた。flat は −8.7 ± 7.6 で **12 シード中 1 つが崩壊**。
  - **flat を 36 シードで測り直すと**: 個体数 −5.4 ± 3.9（誤差の内）、出生 −9%、餓死 −9%、**崩壊 2 / 36**（`unsettled` は 0 / 36）。flat はこれまでどの段階でも崩壊していなかった。2 / 36 対 0 / 36 は偶然でも起こりうる差（両側の正確検定で p ≈ 0.5）だが、向きは定住場所の側。
  - `foodless`（閉じた場所に食料が戻らない）は base と区別がつかない——閉じた場所の上の食料は地面の 1%（patches 7%）。
- 予想との照合: 消える移動の手が 0.1 前後・下がりの大半が戻る は当たった（patches・constrained）。flat の崩壊は予想していなかった。
- 次にすること: ユーザに報告する（flat の崩壊したシードを調べるか、8-2c へ進むか）。
