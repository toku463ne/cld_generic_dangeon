# 3-3d: 配分の量を性比の釣り合いへ（ProvisionEachWith 0.0055）

判断は [`docs/history/20260927.md`](../history/20260927.md) の「3-3d の測定」。前は [3-3b](20260927-3-3b.md)・[3-3c](20260927-3-3c.md)。

## 1. 概要

- 確かめたかったこと: 母が配分を求める確率を `lean`（0.00375）と `doubled`（0.0075）の間の 0.0055（相手がいなければ 0.00275）にすると、成人の性比が釣り合いに近づくか。3つを並べて読む。
- 分かったこと:
  - **成人のうち女の割合 0.46〜0.48**（`lean` 0.33、`doubled` 0.57〜0.60）。完了条件の 0.4〜0.6 に入った。予想（0.45〜0.50）どおり。
  - **成人到達率 0.69**（`lean` 0.75、`doubled` 0.63〜0.64）。予想（約 0.69）どおり。母に回る食料は戻る食料の約 3 割（1シードあたり 5,500〜6,100 単位）。
  - 個体数は `lean` より −4.7〜−4.9（制約で約 2.4 SE、平坦で約 1.9 SE）、出生 +15%。崩壊 0。
  - 最後の代金から 1000 tick 以内に死ぬ割合は女 67〜69%、男 67〜69%——**雌雄で同じになった**。休み明けの母の体力は 69〜71、休みのあいだに受け取る体力は 56〜62。
- 次にすること: この値で 3-4（寿命と老いによる死）へ進む。
