# 5-2: 覚えている食料（SpotRead）

判断は [`docs/history/20261002.md`](../history/20261002.md) の「5-2 の測定」。事前カウントは [placeroom-count](20261002-placeroom-count.md)。

## 1. 概要

- 確かめたかったこと: 身体が見て残した食料の位置を覚え、視界の外の近い3つへ歩く続きを値付けに入れると、どれだけ使われ、世界がどう動くか。`unrecalled`（5-1）との対の差で読む。
- 分かったこと:
  - **よく使われ、よく当たる**: 覚えている食料へ歩く決定は決定の 4.7〜5.3%（98% は視界に食料が無いとき）。歩いた回数は1シードあたり約 2 万（15000 tick）、**そのうち 92% で食料がまだあった**。覚えている食料は身体1体あたり常に 0.12〜0.14 タイル（見たらすぐ取りに行くか、空なのを見て忘れる）。
  - **平坦: 体力の消耗の合計 −2.1%（有意）**、出生 −1.6%（−87 ± 44、2 SE の境目）、餓死 −74 ± 49（有意でない）、個体数は変わらない。
  - **制約: 崩壊しなかったシードでは同じ向き**、平均の差は seed 1〜12 の 1 シードの崩壊が出たもの。
  - **崩壊（制約）: 84 シードで base 6、`unrecalled` 5**。増えていない。罠の率は 5-1 の世界でも 5-2 の世界でも 6〜7%。
- 読み: 覚えている食料は、飢えた身体が見えない食料を取りに戻る経路として実際に働く（9 割当たる）。ただ世界はほとんど動かない——消耗が少し減るが、食料で頭打ちの個体数は変わらない。**覚えている食料は身体1体あたり 0.1 タイル余りしか溜まらないので、記憶の側はまだ増えていない**——5-3（記憶容量と保持順位）には、まだ溢れる側が無い。
- 次にすること: 5-3 の余地が無いことをユーザに伝え、5-3 を見送って 5-4（個体の行と M-1 見た異性の位置）へ進むかを確かめる。
