# 8-2c 定住場所では食料が腐りにくい（`ShelterFoodLife`）

判断は [`docs/history/20261005.md`](../history/20261005.md)。途中の段階なので軽い形（`MEASURE.md`「測定の作法」）。事前カウントは [`20261005-keeproom-count.md`](20261005-keeproom-count.md)。

## 1. 概要

- 確かめたかったこと: 休める場所の上の食料の寿命を3倍（`ShelterFoodLife` 3000）にしても、置く手の無い今は世界が動かないこと（事前カウント: 触れるのは全単位の 1% 未満）。`unkept`（8-2b3）と比べた。
- 分かったこと: **予想どおり、どの地図も誤差の内。**
  - flat（36 シード）: 個体数 +4.8 ± 4.3、崩壊 2 / 36 → **0 / 36**。どちらも良い向きの境目で、断定はしない（8-2b3 で見た「決まったシードではなく確率」と整合する揺れの範囲）。
  - patches（12 シード）: +2.9 ± 3.3。constrained: −3.0 ± 3.3。崩壊 0。
- 予想との照合: 「3 地図とも誤差の内、flat の崩壊 0〜2 / 36」——当たり。
- 次にすること: 8-2c を閉じ、「送る・置く」（食料を定住場所に置く手）へ。flat の「定住場所があるほど出生が減る」向き（8-2b3、−7.7）はそこでも引き続き見る。
