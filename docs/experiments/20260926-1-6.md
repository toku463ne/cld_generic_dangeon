# 1-6: 経験から学ぶ行（通ったタイル・地域・交配）

判断は [`docs/history/20260926.md`](../history/20260926.md) の「1-6: 測定と閉じる」。

## 1. 概要

- 確かめたかったこと: 真の表の世界についての行を、各身体が自分の経験から学ぶ行（通ったタイル・地域・交配）に置き換えると、何が変わるか。
- 分かったこと: **学んだ推定は世界の値に近づく**（地域の食料 / タイル: 平坦 0.0066 対 0.0055、制約 0.006〜0.007 対 0.006〜0.009）。通ったタイルの推定は地域より低い（平坦 −23%、制約 −6%）。**世界はほとんど変わらない**: 平坦では個体数・出生・成人到達率に有意な差なし、制約では個体数 −5.0・出生 −40（有意）。**予想の多くが外れた**: 交配は激減しない（子になる割合を学んでも、代金は子が生まれたときだけ払うので、交配の損得から割合が打ち消し合う）。真後ろへの手は減らずに増えた（通ったタイルの証拠が一生で 18〜29 しかなく、推定が揺れ、通ったタイルを豊かと誤って信じる身体が出る）。
- 次にすること: 1-6 を閉じる。段階2（伝承）の余地は、通ったタイルの行（証拠が少なく揺れる）にある。交配の行は、学んでも決定に効かない形なので、段階2で伝える意味は薄い。

## 予想との照合（PLAN 1-6）

| 予想 | 結果 |
| --- | --- |
| 交配が激減する（`truth` の 3 分の 1 以下）。出生も有意に減る | **外れ**: 交配の割合はほぼ同じ。子になる割合 c を学んでも、交配は「c の確率で代金を払って子、1−c で待つのと同じ」と読むので、死ぬ確率の上がり幅も子の値打ちも c 倍になり、交配するかどうかから c が消える（1-3 で見た「確率が打ち消し合う」と同じ）。余地の数え上げ（[1-6-room](20260926-1-6-room.md)）は、子ができなくても代金を払う形で数えていて、余地を大きく見誤った |
| 個体数は有意に下がる | 制約の地図だけ当たり（−5.0 ± 1.4）。平坦な地図は +1.8 ± 1.6 |
| 真後ろへの手は下がるが、数え上げより小さい | **外れ（逆）**: 平坦 +0.004・制約 +0.032 と増えた。通ったタイルの証拠が少なく、1つ食料を見るだけで推定が地域より大きく跳ね、通ったタイルを豊かと信じる身体が出る |
| 地域の推定の相対誤差は年齢とともに下がるが、30% を切らない | 平坦な地図では当たり（0.91 → 0.57） |
| 1 tick は約 2 倍重い | 当たり（約 50 → 約 105 µs） |
| （最初の予想）成人到達率が両方の地図で有意に下がる | 外れ（どちらも有意でない） |
