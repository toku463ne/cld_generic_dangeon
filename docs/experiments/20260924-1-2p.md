# 1-2p 測定（1-2 の測り直し）: 視界を入れると長く生きるが、横ばいにならない

判断は [`docs/history/20260924.md`](../history/20260924.md) の「1-2p: 視界だけでは横ばいにならない」。

## 1. 概要

- 確かめたかったこと: 視界（半径 1）を足した値付けの身体が、両方の地図で全滅せず横ばいになるか（PLAN 1-2 の予想を、知覚を入れた世界で判定する）。
- 分かったこと: **両方の地図で、体・tick が視界なしの約 2〜2.5 倍に延び、制約の地図では人口比が食料比にほぼ一致した。しかし横ばいにならず、20000 tick まで減り続けた**（平坦 5.5 体・0 / 12 崩壊、制約 1.6 体・3 / 12 崩壊）。原因は2つ見えた。**(1) 体力 60 以上の身体は、足元の食料を食べずにその上に留まる。(2) 空腹の身体の視界に食料がほとんど無い（約 1.5〜1.8%）。身体は満腹から餓死までの間に約 6.7 タイルしか動かず、自分が食べ尽くした狭い範囲から出られない。** 地面の食料は上限の 97〜99% まで戻っていた。
- 次にすること: (2) は向きの持続（PLAN 1-2q）で扱う。(1) の扱いと 1-2q の形をユーザと決める。

| | flat | constrained |

| 1000 tick 前（満腹から餓死まで）の位置からの距離 | **6.81 ± 0.02 タイル** | **6.67 ± 0.04 タイル** |

- **足元の食料の上に留まる。** 体力が 70 を超えると、1食（体力 30）は上限で切られる。今食べるより「1 tick 待ってから食べる」ほうが、窓の終わりの体力が同じで1 tick 遅いので、死ぬ確率がわずかに低い。体力 70 以下では、いつ食べても窓の終わりの体力が同じなので同点になる。**どちらも、4行目が「食料は着くまで、食べるまでそこにある」と読むから**（他の個体に先に食べられることを入れていない。PLAN 1-2p で決めたこと）。足元に食料がある決定の 9 割を超えるものが、この帯で起きている。
- **空腹の身体は、食料の無いところにいる。** 地図全体では 1 タイルあたり約 9% に食料があり、3×3 の視界には半分ほどの確率で入るはずだが、空腹の身体の視界には 1.5〜1.8% しか入らない。
- **身体は狭い範囲から出ない。** 1000 tick で約 6.7 タイル（まっすぐ歩けば 250 タイル）。視界に食料が無い決定（半径 1 で 8 割超）では移動が同点で無作為に選ばれ、無作為の歩行の広がりは tick 数の平方根でしか伸びない。**自分が食べ尽くした範囲に閉じ込められ、そこへ戻る食料（空きの数に比例し、地図全体に一様に散る）だけでは足りない。**

## 予想との照合

| 予想 | 結果 |
| --- | --- |
| （1-2）両方の地図で全滅しない。横ばいになる | **外れた。** 減り続けた。flat は 20000 tick で全シード生存だが、形は減少の途中 |
| （1-2）1-1 との対の差で餓死数が有意に減る（1体あたり半分以下） | **半分当たった。** 有意だが 3% 未満 |
| （1-2）制約: 人口比が面積比から食料比へ寄る | **当たった。** 食料比にほぼ一致 |
| （1-2）同じ符号が両方の地図で出る | 当たった |
| （1-2）§5 で「食べる」が上がり「待つ」が下がる | 食べるは上がり、待つは変わらない |
| （1-2p）移動の手が同点になる決定の割合が下がる | 数えていない（`forage` は足元の食料の決定だけを数えた）。「待つ」の割合が 1-1 と同じなので、下がったのは視界に食料がある決定（約 2 割）の中だけのはず |
| （1-2p）入ったタイルに食料がある割合が上がる | **当たった**（0.95% → 3.2〜3.3%） |
