# 8-2a2 1晩の節約を体感から学ぶ（`NightSaving`）

判断は [`docs/history/20261004.md`](../history/20261004.md) の「8-2a2 の測定」。

## 1. 概要

- 確かめたかったこと: テントの1晩の節約を体感（外で眠った寒さ − 中で眠った暖かさ）から読むと、テントが使われ、世界が動くか。flat と patches で `unbuilt`（6-5a）・`atdusk`（8-2a）と比べた。
- 分かったこと（base 対 `unbuilt`、12 シード × 40000 tick）:
  - **作られるテントは 1 シードあたり 176（flat）・155（patches）、テントで眠った夜は 369・316**——8-2a（104・142、209・294）から少し増えただけ。テント1つあたり約 2 夜で、消耗して消えたのは 5・10。ほとんどは持ち主と一緒に失われる。
  - 世界は動かない: 個体数 flat −4.5 ± 2.5、patches −2.0 ± 2.9。餓死・出生・成人到達率は誤差の内。眠っている割合 +0.6 ポイント（flat）。崩壊 0。
- 予想との照合（PLAN 8-2a2）: テントの夜が成人の眠りの 3〜4 割・個体数 +5〜+10% は外れた。
- 読み: 1晩の節約を正しく読んでも、テントを持ち続ける身体が少ない。最初のテントは同点の抽選（眠りに入るとき、作る手とそのままの手がどちらも危険 0）でしか作られず、暖かさを感じるまで次の判断は中立のまま。成人の死の多くは餓死で、身体は作ってから2夜ほどで死ぬ——使う夜の数を学ぶ前に終わる。
- 次にすること: ユーザに確かめる。
