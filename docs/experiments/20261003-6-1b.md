# 6-1b 休める場所を知り、歩いて寝る（`ShelterRead`）

判断は [`docs/history/20261003.md`](../history/20261003.md) の「6-1b の測定」。

## 1. 概要

- 確かめたかったこと: 休める場所を見て覚え、暗いときにその上で感じた消耗から暖かさを学び、値付けが「休める場所へ歩いて眠る」続きを読むと、身体がそこで眠るようになり、夜の餓死が減るか。
- 分かったこと:
  - **世界は動かない。** 個体数 平坦 +2.5 ± 2.7・制約 +2.8 ± 3.7、出生・餓死・成人到達率も誤差の内（平坦で老いによる死 +17 ± 3、餓死 −26 ± 16）。崩壊 0 / 36（東が空になるのは 31 / 36、7-4 以来と同じ）。
  - **休める場所で始まった眠りは 0.3〜0.4% のまま**（`shelterblind` と差なし）。予想（5〜10%）は外れ。
  - 補助の確認（4 シード）: 成人の 53〜55% が休める場所を覚え、**32〜37% が暖かさを学んでいる**（予想の 1〜3 割どおり）。**歩いて眠る続きが値付けに出る決定は 18〜21%、そのうち選ばれたのは 0.1〜0.2%。**
- 読み: 知る・学ぶ・読むはどれも働いているが、値付けは眠るより歩き続けるほうを選ぶ。暖かく眠るのは寒く眠るより安全に読まれるが、眠ること自体が探す時間を失い、満腹に近い成人は窓の中で死ぬ見込みが小さいので、眠りは同点か負債で消耗が上がってからしか選ばれない（7-3b 以来の眠りの形）。休める場所が値打ちを持つのは、眠ることに値付けが見える理由（夜の外敵、安全）ができてから。
- 次にすること: ユーザに確かめる——規則は残すか（重さは変わらない）、段階6 をどう続けるか。

## 予想との照合（PLAN 6-1b）

| 予想 | 結果 |
| --- | --- |
| 学ぶのは成人の 1〜3 割 | 当たり（32〜37%） |
| 休める場所で始まる眠りが数%〜1 割 | 外れ（0.3〜0.4%、規則なしと同じ） |
| 夜の餓死が減り、個体数 0〜+5% | 個体数は +2.5〜2.8 で誤差の内。餓死は平坦で −26 ± 16（有意でない） |
| 子には効かない | 当たり（成人到達率は誤差の内） |
| 崩壊は増えない | 当たり（0 / 36） |
| 1 tick は数% | 1体あたり変わらない |
