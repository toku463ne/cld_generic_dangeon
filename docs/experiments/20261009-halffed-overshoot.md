# 9-7b-1 の事前の数え上げ（最初の定義）: 上限だけ半分にした `halffed`

判断は [`docs/history/20261009.md`](../history/20261009.md)。`-brief`。`single`（1 種族・上限 300）を基準に、**上限だけ 150 にした `halffed`**（最初の身体は 200 のまま）を flat・constrained で測った。コミット 859799a（この定義の `halffed`）。

## 1. 概要

- 確かめたかったこと: 池を分けた世界で 1 種族が持つ「上限 150」で、1 種族がいくつ養えるか。
- 分かったこと: **測れなかった。** 200 体が 150 単位に乗る過剰で、flat・constrained とも 12/12 が最初の 3 世代（最大世代数 3〜3.75）で下限 20 を割った（餓死 335〜337、出生 155〜157）。最初の身体が上限に対して多すぎるときの崩れ方であって、養える数ではない。
- 次にすること: `halffed` を「上限と最初の身体を半分」に直す（コミット 9-7b-1 本体）。patches は走らせる前に止めた。
