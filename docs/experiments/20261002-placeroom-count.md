# 5-2 の事前カウント: 場所の行の余地（`placeroom`）

判断は [`docs/history/20261002.md`](../history/20261002.md) の「5-2 の事前カウント」。

## 1. 概要

- 確かめたかったこと: 1つのタイルを主語にする行（場所の行）に覚える値打ちがあるか。2つを数えた。(1) 食べた（拾った）タイルへ後で戻ったとき、そこに食料がある割合は、視界のタイル一般より高いか（PLAN 5-2 の「このタイルへ行った → 食料を得た」）。(2) 見て残した食料のタイルへ後で戻ったとき、食料はまだあるか。
- 分かったこと:
  - **(1) 食べたタイルは何も教えない**: 戻ったとき食料がある割合は 0.2〜2.1%、視界のタイル一般は 1.6%。食料は地域の中の無作為な陸のタイルへ戻るので、タイルに履歴は無い。
  - **(2) 見て残した食料は短いあいだだけ教える**: 同じ身体の 75〜80% がまた視界に入れ、ほとんどは 50 tick 以内（まだある 88〜90%）。51〜200 tick で 25〜27%、それより後は一般の割合（1.4〜4.9%）まで下がる——他の身体に食べられる。
  - 視界に食料が無い決定のうち、1000 tick 以内に見て残した食料がまだどこかにある割合は 5.7〜5.9%。
- 読み: PLAN 5-2 の形（タイルで食料を得た経験）は余地が無い——この世界ではタイルは食料の湧き方を覚えていない。余地があるのは「見て残した食料の位置」で、200 tick ほどで役に立たなくなる短い記憶。これは場所の行というより、物（食料の1単位）の位置の観測で、M-1（見た異性の位置）と同じ形。
- 次にすること: 5-2 の中身をユーザと決める。
