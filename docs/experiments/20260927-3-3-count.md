# 3-3 の事前カウント: 休んでいる母に戻る食料（`provision`）

判断は [`docs/history/20260927.md`](../history/20260927.md) の「3-3 の事前カウント」。

## 1. 概要

- 確かめたかったこと: 戻ってくる食料の一部を休んでいる母（出産して 400 tick のあいだの雌）に直接配る規則（ユーザの申し送り）で、配る確率をどれくらいにすれば母が払った分（45、食事 1.5 回分）を休みのあいだに取り戻せるか。相手（最後の子の父）が同じ地域にいる割合。
- 分かったこと:
  - 地図全体に戻る食料は 1 tick あたり約 0.51〜0.55 単位。休んでいる母は常に約 11〜12 体。**休んでいる母のいる地域で、母1体あたりに戻る食料は 1 tick あたり約 0.05 単位**。
  - 相手が同じ地域にいる割合は、平坦 0.97（地域が1つ）、制約 0.82。半分条件が効くのは制約の地図だけ。
  - 休み明けの母の体力は約 52（払う前の水準に戻り切っていない）。
- 決めた値（仮）: 戻る食料1単位ごとに、その地域の休んでいる母から1体を選び、**相手が同じ地域にいれば 0.07、いなければ 0.035** の確率でその母に配る。0.07 × 0.05 × 400 ≈ 1.4 単位（約 42）を休みのあいだに受け取る見込み。
