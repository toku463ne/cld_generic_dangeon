# 4-1 の事前カウント: 持つ余地（`carryroom`）

判断は [`docs/history/20261002.md`](../history/20261002.md) の「4-1 の事前カウント」。

## 1. 概要

- 確かめたかったこと: 食料を持てるようにする前に、1食が入りきらない（体力 > 体力の上限 − 1食）のに足元か視界に食料がある決定がどれだけあり、そのうち最善の手の死ぬ確率が 0 より大きい（持っておけば死ぬ確率を下げうる）ものがどれだけあるか。
- 分かったこと:
  - 満腹に近い時間は、休んでいる母 37〜40%、それ以外の成人 20〜21%、子 56〜57%（子は体力の上限が年齢で低い）。
  - **満腹に近く食料が見える決定は、決定の 1.7〜4.7%。ほとんどは視界にだけある**（足元は 0.2〜0.4%）。見えている食料は平均 1.0 単位。
  - そのうち最善の手の死ぬ確率が 0 より大きいのは、それ以外の成人 60〜61%、休んでいる母 26〜33%、子ほぼ 100%。1シードあたり（15000 tick）それ以外の成人 1500〜2500、休んでいる母 840〜1250、子 2000〜2760 の決定。
- 読み: 余地は小さいが実在する。足元に限ると 10 分の 1 になるので、**見えている食料へ歩く続きにも「1食が入りきらなければ持つ」を入れないと、持つ手はほとんど選ばれない**。4-1 の値付けはそう作る。
- 次にすること: 4-1（`Carry` 1）を実装し、`unheld`（4-0）と比べる。
