# 7-2 の事前カウント: 視界が見つける速さに足す分（`findrate`）

判断は [`docs/history/20261003.md`](../history/20261003.md) の「7-2 の事前カウント」。

## 1. 概要

- 確かめたかったこと: 値付けの「歩き続ける」続きは、踏んだタイルに食料がある割合（その地域の地面の食料 ÷ 陸 × 速さ）で読み、視界によらない。明るさごとに、空腹の成人が実際に食べる割合がこれとどれだけ違うか。7-2 で値付けが時刻（明るさ）を読んでも、続きの見込みに昼と夜の差が無ければ何も変わらないため。
- 分かったこと:
  - **探しているとき（移動・食べる・拾うの手）だけで比べると、暗闇では 0.69〜0.90 倍（モデルとほぼ同じ）、真昼では 2.05〜2.72 倍**、薄明はその間。昼の視界は見つける速さを 2〜3 倍にしているが、値付けはそれを読んでいない。
  - **暗闇では空腹の成人の tick の 43〜45% が相手へ向かう手（交配・要求の主へ歩く）**（真昼は 8〜9%）。夜は誰も相手が見えないので皆が交配の要求を出し、要求は視界の外まで届くので、空腹の成人が夜じゅう要求の主へ歩く。交配の手は意図にならないので、毎 tick 決め直す（7-1 で決定が増えた原因）。全体で比べた暗闇の 0.32〜0.45 倍は、探す時間が減ったため。
- 読み: 7-2 の前に、続きの見込みが視界を読む規則が要る（7-2a）。視界の幾何（1タイル進むと視界に入るタイルの数）から読めば、暗闇で 1 倍、真昼で 3 倍——測った 0.7〜0.9 倍・2〜2.7 倍に近い。夜の要求の殺到は 7-1 の規則から出た振る舞いとして記録し、今は直さない。
- 次にすること: 7-2a（続きの見込みに視界の倍率を掛ける）。
