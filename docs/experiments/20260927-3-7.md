# 3-7: 能力の年齢の曲線（ChildAbility 0.5、OldAge 3200）

判断は [`docs/history/20260927.md`](../history/20260927.md) の「3-7 の測定」。前は [3-6](20260927-3-6.md)。

## 1. 概要

- 確かめたかったこと: 速さと体力の上限を年齢に従わせる（生まれたとき 0.5 倍 → 成人 400 で 1 倍 → 3200 から寿命 4000 で 0.5 倍、0.25 刻み）と、子と老人の死に方・個体数がどう変わるか。`unaged`（3-6）との対の差で読む。
- 分かったこと:
  - **崩壊 0（両方の地図）**。個体数 −6.1〜−7.8、出生 −11%、餓死 −13〜−14%。
  - **成人前に死ぬ子は 0.3〜0.4% だけ**（成人到達率 1.00 → 0.987）。子は生まれたときの体力 50（上限も 50）で 500 tick もつので、400 tick の子の期間にはほとんど死なない。**死んだ年齢の 25% 点は 500**——生まれたときの体力が尽きるところで、半分の速さのまま自分で食べられなかった身体が、成人してすぐ死ぬ。
  - **老いによる死は増えた**（死の 5〜7% → 8.7〜9.9%）。予想（老人が弱くなり老いる前に餓死する）と逆向き。理由は確かめていない。
  - 成人の割合 0.72〜0.74 → 0.74〜0.76、女の割合 0.49〜0.51。
  - 1 tick の時間は 3-6 の 195 µs → 205 µs（1コア、`AgeStep` 0.25）。
- 次にすること: 段階3の前半（成長・老い・性別）を閉じ、次の段階をユーザと決める。
