# 10-2j 攻撃力・防御力の価格——小の掃引

判断は [`docs/history/20261011.md`](../history/20261011.md)。**小の測定**（constrained・4 シード・20000 tick・`-brief`）。基準 `warmed`（代金 0）、対照 `priced`（中立より上の段ごとに予算の 0.1）・`priced2`（0.2）。コミット d22cea5。

## 1. 概要

- 確かめたかったこと: 狩りが入った今、攻撃・防御の段は選択で動いているか。価格はそれを止めるか。
- 分かったこと: **代金 0 でも段は変異だけの定常（両端 約 1/4）にいる——選択は見えない。** 攻撃が最大の成人の割合 0.23、防御が最大 0.26（両種族の平均）。代金を付けると段は下へ寄る（0.1 で防御が最大 0.12、0.2 で攻撃・防御の 0 の段が 0.48）。個体数は誤差内、倒した数も誤差内。
- 予想との照合: 外れ（代金 0 で獣の攻撃・人間の防御が 0.3〜0.4 に寄ると書いた）。狩りは 20000 tick に 70 回ほどで、血統を動かすには少ない。
- 読み: 代金は分布を止める道具として働くが、止めるべき選択がまだ無い。**代金 0 のまま**にし、戦いが生死を分ける頻度が上がったとき（人間が獣を狩る、武器）に測り直す。
- 次にすること: 10-3 勝ち目の見込みと攻撃的（テストで確かめ、測らない——狩りの頻度では分布が動かない）、10-4 発信と好感度。
