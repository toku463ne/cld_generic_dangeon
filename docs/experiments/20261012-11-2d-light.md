# 11-2d 店の前では在庫が見える——小の測定

判断は [`docs/history/20261012.md`](../history/20261012.md)。**小の測定**（constrained・4 シード・20000 tick）。基準 `shopblind`（在庫が見えない 11-2c の世界）、対照 `warmed`（`ShopSight`）。コミット a6239d3。8:1 の世界。

## 1. 概要

- 確かめたかったこと: 在庫が見えれば、空の店への買い物の試みが消えるか。ほかは動かないか。
- 分かったこと: **消える**。断られた買い物 40798 → 595（−98.5%）。店で買った食料 217 → 253（+16%、誤差内）、送った 436 → 500（+15%）、作ったテント +13%（有意）、テントで眠った夜 +7%。人間 139 → 144（誤差内）、成人到達率 +0.007（誤差内）。
- 予想との照合: 当たり（断られた買い物 1000 以下、買った食料 ±10% は +16% だが誤差内、人間 ±3% は +4% だが誤差内）。
- 読み: 店の前で無駄にしていた tick が売り買いと他の手に戻った。残る 595 は店を目指して着いたときに空だった回数で、行はこれで学ぶ。
- 次にすること: **既定のまま入れ、11-2 を閉じる。** 11-3（身体どうしの売買）へ。
