# 7-2b の事前カウント: 暗くなることを読んで変わりうる決定（`nightroom`）

判断は [`docs/history/20261003.md`](../history/20261003.md) の「7-2b の事前カウント」。

## 1. 概要

- 確かめたかったこと: 7-2b（暗くなるまでの時間を学び、7-2a の倍率を窓の中で切り替える）が手の選び方を変えうる上限。成人の決定を、窓の全体が暗闇（倍率 1）として読み直し、選んだ手が最善から外れる割合を数えた。7-2b の実際の読み（窓の途中で暗くなる）は、今の読み（窓の全体が今の明るさ）とこの読みの間にあるので、これが上限になる。
- 分かったこと:
  - **明るいときの決定のうち、最善が変わるのは 1.8〜2.7%。**
  - 変わり方の 4 割強は「交配 → 待つ」、残りは移動・待つ・交配の入れ替わり。**「→ 食べる」は 1〜1.6%、拾う手はほぼ 0。** 暗くなる前に食べる・持つ、という形の変わり方がほとんど無い。
- 読み: 7-2b を入れても、夕方の準備は出ない見込み。窓（1000 tick）は満腹の身体が飢えるまでの長さと同じで、食べている成人は窓の中で死ぬ見込みがほぼ 0——暗くなることを知っても減らす危険が無い。準備が値打ちを持つのは、暗さが値付けに見える損を持つとき（睡眠、7-3）。
- 次にすること: 7-2b を入れるか、睡眠（7-3）を先にするかをユーザに確かめる。
