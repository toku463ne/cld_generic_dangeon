# 跳ね返しの 45° と、無作為に選ぶ形の比較

判断は [`docs/history/20260926.md`](../history/20260926.md) の「跳ね返し: 45° と無作為の比較」。

## 1. 概要

- 確かめたかったこと（ユーザの提案）: 跳ね返しで 45° 曲がる規則（真後ろになるときの `TurnOffReverse`）や跳ね返しそのものを、エンジンの既定である「同点の中から無作為」に戻すと、個体数・成人到達率・移動（1000 tick の変位）がどう変わるか。入れ替えずに対で比べる。
- 分かったこと: **無作為にしても移動は減らない**（変位はむしろ +0.5〜+1.2 タイル）。**しかし身体が縁（地図の端・水の隣）に集まる**: 跳ね返しを丸ごと無作為にする形（`drawwall`）で縁にいる割合が 2 倍（面積比の 2.0 倍・1.65 倍）、個体数 −5〜−6（有意）・出生 約 −100。1-2q で最初に試して捨てた形と同じ失敗（壁に沿う向きが引かれ、向きを保って縁を回る）。**真後ろのときだけ無作為にする形（`drawreverse`）は、個体数・成人到達率とも有意な差は無い**が、縁にいる割合は +0.025〜0.027（面積比の 1.35 倍・1.12 倍）。**45°（今の形）は縁にいる割合が面積比どおり**で、角や縁で周期的な軌道に捕まっている兆しは無い。
- 次にすること: 既定は 45° のまま。どちらも暫定で、1-6 以降の記憶による探索（壁沿いの回り込みなど）に置き換わるべきもの（ユーザ）。2つの条件は対照として残す。

## 読み方

- **「来た方向へ戻る目が出るので探索効率が落ちる」は起きなかった**: 変位はむしろ増えた。無作為に引いた向きの多くは壁に沿う向きで、縁に沿った長い直線になるため。
- **その代わり縁に集まる**。縁は食べ尽くされやすく（1-2q の記録）、`drawwall` では個体数と出生が有意に下がる。`drawreverse` は真後ろのとき（軸に沿った向きが正面から当たったとき）だけ引くので、影響は3分の1ほど。
- **45° は縁で周期的な軌道を作っていない**: 縁にいる割合が面積比と同じ（平坦）か下（制約）。角での循環があれば、縁の割合が面積比を上回るはず。
