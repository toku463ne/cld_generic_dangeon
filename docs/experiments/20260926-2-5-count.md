# 2-5 の事前カウント: 地域どうしの豊かさを伝える余地（`regions`）

判断は [`docs/history/20260926.md`](../history/20260926.md) の「地域どうしの豊かさを伝える余地」。前は [2-4](20260926-2-4.md)。

## 1. 概要

- 確かめたかったこと: 次に運ぶ行の候補「地域どうしの豊かさ（地図が決める食料の取り分なので変わらず、学ぶのに高くつく事実）」に、伝える余地があるか。2-4 の世界（何も渡さない）で数えた。
- 分かったこと:
  - **地域どうしの豊かさは、地図の取り分では決まっていない。** 制約の地図の取り分は 0.5 / 0.1 / 0.3 / 0.1 だが、地面にある陸のタイルあたりの食料は 0.0070 / 0.0061 / 0.0057 / 0.0060 とほぼそろい、**取り分 0.3 の地域 2 が一番少ない**。身体が豊かな地域に集まって食べるので、地面の食料がならされる。**「どの地域が豊かか」は身体の居場所で決まる量で、通ったタイルの行と同じく、世界の変わらない事実ではない**（程度は小さい）。
  - 余地は小さいが 0 ではない（制約の地図）。身体の 98% は、今いる地域以外のどれかを自分の証拠が重み未満でしか知らない。各地域の今の食料 / タイルを知っていれば決定の 5.2% の最善が変わり、地域どうしの比だけなら 4.4%。2-1 の事前カウントで通ったタイルの行が変えた 32〜35% の約 7 分の 1。
  - 平坦な地図では地域が1つで、比の余地は 0。
  - 対照（自分の推定で値付けし直す）は 0 で、数え方は身体の決定をそのまま再現している。
- 次にすること: この地図には、伝える値打ちのある「変わらない世界の事実」がほとんど無い。PLAN 2-1 が名指ししていた逃げ道（地図の側を見直す）をユーザと決める。

| コミット | d33d1db |

| tick 数 | 40000（決定は tick 5000 より後） |
| シード数 | 12（最初のシード 1） |
| 条件 | base（2-4、何も渡さない） |

```
go run ./cmd/count -what regions -map constrained -w 64 -h 48 -seeds 12 -ticks 40000
go run ./cmd/count -what regions -map flat -w 64 -h 48 -seeds 12 -ticks 40000
```

- 真: 決定のたびに、地域の率を各地域の今の陸のタイルあたりの食料（世界の値）に替えて値付けし直す（`World.ValueWith`。通ったタイルは身体の比 × その地域の率）。
- 比: 今いる地域の率は身体自身の推定のまま、ほかの地域をその推定 × 地域どうしの真の比にする（「地域どうしの豊かさ」の行が完全に伝わった場合）。
- 対照: 身体自身の推定で同じように値付けし直す。
- 損: その値付けでの、身体の手の値 − 最小（死ぬ確率 − 子の値打ち × 子の確率）。
