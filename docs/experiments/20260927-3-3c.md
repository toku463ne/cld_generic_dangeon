# 3-3c: 配分を、休みのあいだに燃える分まで（ProvisionEachWith 0.0075）

判断は [`docs/history/20260927.md`](../history/20260927.md) の「3-3c の測定」。前は [3-3b](20260927-3-3b.md)。

## 1. 概要

- 確かめたかったこと: 母が配分を求める確率を倍（相手が同じ地域にいれば 0.0075、いなければ 0.00375）にし、出産の代金と休みのあいだに燃える分の両方を埋めると、母が産後に死ぬのが減り、性比が釣り合いに近づくか。`lean`（3-3b）との対の差で読む。
- 分かったこと:
  - **行き過ぎた。成人のうち女の割合 0.33 → 0.57〜0.60**——今度は男が少ない。
  - 休み明けの母の体力 65 → 75〜77（予想 90 前後には届かない）。女が最後の出産から 1000 tick 以内に死ぬ割合 73〜78% → **60〜61%**。代わりに、男が最後の代金から 1000 tick 以内に死ぬ割合が 57〜60% → 72〜76% に上がった（女が多くなり、男が交配の代金を多く払う）。
  - **母に回る食料が戻る食料の約 4 割になった**（1シードあたり 7,750〜8,600 単位）。そのぶん子が飢え、**成人到達率 −0.11〜−0.12**（0.75 → 0.63〜0.64）、**個体数 −10〜−12**（有意）。成人の割合 0.62 → 0.53。崩壊 0。
- 読み: 配分の量で性比は右にも左にも動く——0.00375 で女 0.33、0.0075 で 0.57〜0.60。釣り合い（0.5）はその間にある。ただし配分を増やすほど、その食料は子から取られる。
- 次にすること: 配分の量をどこに置くか（性比を釣り合わせる中間の値か、どちらかの値のまま 3-4 へ進むか）をユーザと決める。
