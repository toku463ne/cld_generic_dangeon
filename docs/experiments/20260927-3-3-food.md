# 3-3 の続き: 食料の戻る確率の掃引（`food2`・`food4`）

判断は [`docs/history/20260927.md`](../history/20260927.md) の「食料の戻る確率の掃引」。前は [3-3](20260927-3-3.md)。

## 1. 概要

- 確かめたかったこと（ユーザの申し送り）: 3-3 で女の割合（0.23）と産後に死ぬ割合（80〜83%）が改善しきらないのは、配分と回復の設計の構造的な欠陥か、この地図の食料が貧しいだけか。規則を何も変えず、食料の戻る確率だけを 1・2・4 倍にした。
- 分かったこと:
  - **個体数は食料に比例して増える**: 平坦 167 → 337 → 663、制約 167 → 331 → 654（ほぼ 2 倍・4 倍）。出生・餓死・配られた食料も同じだけ増える。崩壊 0。
  - **1体あたりの指標はどれも動かない**: 成人のうち女の割合 0.229 → 0.230 → 0.239（平坦）・0.229 → 0.219 → 0.238（制約）。女が最後の出産から 1000 tick 以内に死ぬ割合 83% → 83% → 81%（平坦）・80% → 80% → 78%（制約）。休みのあいだに母1体が受け取る体力 21〜25、休み明けの母の体力 58〜60 は、どの水準でも同じ。休んでいる母の数が食料と同じだけ増え（19 → 38〜39 → 81〜83）、1体あたりの配分は変わらない。
  - 地面の食料は上限の 6〜7%（base）で、上限は効いていない——戻る確率を上げれば、地面に出る食料は本当に増えている。増えた分は身体の数に吸われる。
- 判定（申し送りの読み方）: **食料の水準を上げても改善しない**。地図を豊かにしても身体が増えて、1体あたりの条件は同じところに戻る——この世界の1体あたりの条件は食料の水準ではなく、身体の振る舞い（産んで増え、食料と釣り合うまで）が決めている。**頭数が増えると1体あたりが薄まる問題は、地図の調整では解けない構造の問題**。配分の仕組み（頭数に依存しない形）か、母の振る舞いの側に立ち返る。
- 次にすること: どちらに立ち返るかをユーザと決める。
