# 1-2p 実装前の数え上げ: 視界の半径

判断は [`docs/history/20260924.md`](../history/20260924.md) の「1-2p 数え上げ: 視界の半径は 1」。

## 概要

- 確かめたかったこと: 視界の半径ごとに、食料が見える割合と、新しく食料が見える頻度が釣り合いに届くか（PLAN 1-2p「実装前に数えること」）。あわせて、視界に食料が無い決定の割合（向きの持続を別の段階にするかの判断材料）。
- 分かったこと: **半径 0（自分のタイルだけ＝1-2 の1回目）は釣り合いの 0.72 倍で届かず、半径 1（前身の「自分のセル＋周囲1セル」と同じ形）で 7.6〜7.7 倍になる。** ただし半径 1 では、**決定の約 84% で視界に食料が無い。**
- 次にすること: 視界の半径の既定値を 1 にして、1-2p（知覚だけ）を実装する。向きの持続は入れない（history 参照）。

## 条件

| 項目 | 値 |
| --- | --- |
| コミット | 258737b |
| マップ | flat (64x48) / constrained (64x48) |
| tick 数 | 20000（全員が死んだシードはそこで終わる） |
| シード数 | 12（最初のシード 1） |
| 比較対象（base） | 半径どうし（0〜8）、および釣り合いの頻度 |

**再現方法**:

```
go run ./cmd/count -what sight -map flat -w 64 -h 48 -seeds 12 -ticks 20000
go run ./cmd/count -what sight -map constrained -w 64 -h 48 -seeds 12 -ticks 20000
```

**数え方**:

- 1-2 の世界（`base`、知覚なしの値付け）を tick の間で読む。次の決定が始まる状態。
- 半径 r の視界は、自分のいるタイルを中心とする (2r+1)×(2r+1) のタイル。半径 0 は自分のタイルだけ。
- 「新しく見えた」は、いま視界の中にあり、前の tick にはその身体の視界の中に無かった（もっと遠かった、または無かった）食料の数。視界の中に戻ってきた食料も含む。体・tick あたり。
- 距離は、身体の位置から食料のタイルの中心まで（タイル）。着くまでの tick は距離 ÷ `Speed`。
- 釣り合いの頻度は `EnergyBurn` ÷ `FoodEnergy` ＝ 0.333%。

## 読み方

- **半径 0 の値は、1-2 の1回目の実測と合う。** 新しく見えた 0.24% は、`cmd/count -what meet` の「入ったタイルに食料があった割合 × 入った頻度」（約 0.95% × 0.25）と同じ量で、1-2 の1回目の「食べる」0.25% とも合う。**半径 0 には自分で食べ尽くした分がすでに入っている**（1-2 の世界は足元の食料をすべて食べるため）。
- **半径 1 以上には、その分が入っていない。** 1-2 の世界の身体は隣のタイルの食料を食べないので、視界の中の食料は残っている。知覚を入れた身体は見えた食料を食べに行くので、自分の周り (3×3) が空になり、新しく見える頻度は下がる。[足元の数え上げ](20260924-1-2-underfoot.md)が外れたのと同じ形の誤差で、向きは「多めに見積もる」側。
- **その誤差の大きさの目安**: 半径 0 で、食べ尽くしが入る前（1-1 の世界）と入った後（1-2 の世界）の比は、入ったタイルの当たり方で 0.18 ÷ 0.44 ≈ 0.4 倍（[1-2 の1回目](20260924-1-2.md)）。半径 1 で同じだけ下がっても、7.6 × 0.4 ≈ 3 倍で釣り合いを超える。**半径 1 が釣り合いを割るには、0.13 倍まで下がる必要がある。**
- **視界に食料が無い決定は、半径 1 で約 84%。** そのあいだ移動は同点で、無作為の歩行のまま。上の見積もりは、その無作為の歩行で新しく見える頻度を数えたものなので、この割合はすでに入っている。
- 半径を上げると、見える割合も頻度も大きく伸びる。**半径の選び方は「釣り合いを超える一番小さい半径」**（PLAN 1-2p）で、大きいほうへは寄せない。
