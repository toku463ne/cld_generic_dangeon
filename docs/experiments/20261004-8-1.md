# 8-1 建てて寝る手（`Building`）

判断は [`docs/history/20261004.md`](../history/20261004.md) の「8-1 の測定」。

## 1. 概要

- 確かめたかったこと: 建てるスキルのある身体（半分）が眠りに入るときに「建てて寝る」を選べるとき、建つ場所の数・使われ方・本人が戻るか（使う回数の学習が始まるか）、世界が動くか。比べるのは 6-5a（`unbuilt`）。
- 分かったこと（base 対 `unbuilt`、12 シード × 40000 tick）:
  - **建つのは 1 シードあたり 134〜146 か所**（1000 tick あたり約 3.5）。
  - **休める場所で始まる眠りは 0.7〜0.8% → 6.6〜9.2%。** 建てた場所で（建てたときを除いて）始まった眠りは 1 シードあたり 112〜171 回。
  - **建てた本人が戻って眠ったのは 1 シードあたり 1.4〜3.4 回**——建てた場所の 1〜2%。戻る回数の見込み（`Memory.Reuse`）はほぼ 0 のままで、建てるのは同点の抽選のまま。
  - **世界は動かない**: 個体数 平坦 98.7 → 93.1（−5.6 ± 4.7）、制約 74.5 → 79.4（+4.9 ± 3.8）、どちらも誤差の内で向きも逆。餓死・出生も誤差の内。成人到達率は制約で +0.008 ± 0.0035。崩壊 0 / 12（両方）、制約 36 シードで 0 / 36。
- 予想との照合（PLAN 8-1）: 建つ数（数十 / 10000 tick）・本人がほぼ戻らない・休める場所の眠りが 1 割前後・崩壊なし は当たった。個体数 −5〜−15%・餓死が少し減る は外れた（どちらも動かない）。暖かさを学んだ成人の割合はこの測定に無い。
- 読み: 建てた場所は使われる（建てた場所の眠りは本人以外がほとんど）が、建てた本人には一晩の暖かさしか返らず、その一晩も代金 10（寒さの節約約 6 より大きい）でならされる。戻る経験が無いので、ユーザの決めた「戻る回数 × 1晩の節約」の値打ちは学ばれず、建てることは抽選の副産物にとどまる。
- 次にすること: ユーザに確かめる。
