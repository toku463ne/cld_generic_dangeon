# 8-2b2 交配の求めを合意とする（`MateConsent`）

判断は [`docs/history/20261004.md`](../history/20261004.md) の「8-2b2 の測定」。途中の段階なので軽い形（`MEASURE.md`「測定の作法」）。

## 1. 概要

- 確かめたかったこと: 交配の求めを定住場所に入る合意にすると、flat の崩壊（8-2b で 2 / 36）が消えるか。`unsettled`（定住場所なし）・`unconsented`（8-2b）と比べた。
- 分かったこと:
  - **flat（36 シード × 40000 tick）**: 崩壊 2 / 36（`unconsented`）→ **1 / 36**（`unsettled` は 0 / 36）。個体数 −5.4 ± 3.9 → −3.2 ± 2.7、出生 −9% → −8%。
  - **patches（12 シード）**: 個体数 −3.7 ± 6.0（`unconsented` は +0.2）。どちらも誤差の内。
  - **constrained（12 シード）**: 個体数 **−6.0 ± 2.4**（`unconsented` は −0.4 ± 3.4）。出生は −1%。境目の差で、向きは合意の側が悪い。
- 予想との照合: flat の崩壊 0〜1 / 36 は当たった。個体数の下がりは flat・patches では誤差の内（当たり）、constrained の −6 は予想していなかった。
- 次にすること: ユーザに報告する。
