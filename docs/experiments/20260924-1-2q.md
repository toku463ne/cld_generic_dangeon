# 1-2q 測定（1-2 の測り直し）: 向きを保つと平坦な地図で横ばいに近づく。制約の地図はまだ減り続ける

判断は [`docs/history/20260924.md`](../history/20260924.md) の「1-2q: 平坦はほぼ横ばい、制約は減り続ける」。

## 1. 概要

- 確かめたかったこと: 視界（1-2p）に「同点では向きを保ち、より悪い向きからは跳ね返る」（1-2q）を足した値付けの身体が、両方の地図で全滅せず横ばいになるか（PLAN 1-2 の予想と完了条件）。
- 分かったこと: **両方の地図で 12 / 12 シードが 40000 tick まで生き残った**（向きを保たない `restless` は両方の地図で 11 / 12 が崩壊）。**平坦な地図は約 145 体で横ばいに近い**が、30000 tick で約 8% のゆっくりした下がりが残る。**制約の地図は 62 体（10000 tick）から 37.5 体（40000 tick）へ減り続け、横ばいの区間は無い。** 人口比は食料比のほうへ寄った。
- 次にすること: 制約の地図の減り続ける原因を調べる。1-2 の完了（tick 数・シード数の既定値）はそのあと。

## 予想との照合（PLAN 1-2）

| 予想 | 結果 |
| --- | --- |
| 両方の地図で全滅しない。横ばいになる | **半分当たった。** 両方で全滅しない（0 / 12）。flat はほぼ横ばい（ゆっくり下がる）、constrained は減り続ける |
| 1-1 との対の差で餓死数が有意に減る（1体あたり半分以下） | **flat は当たった**（200 → 66.5）。**constrained は有意だが半分以下ではない**（200 → 162.5） |
| 制約: 人口比が面積比から食料比へ寄る | **当たった** |
| 同じ符号が両方の地図で出る | 当たった |
| §5 で「食べる」が上がり「待つ」が下がる | **当たった**（食べる 0.19〜0.22% → 0.31〜0.33%、待つ 11% → ほぼ 0） |
