# 3-1 の事前カウント: 性別が交配から何を奪うか（`sex`）

判断は [`docs/history/20260926.md`](../history/20260926.md) の「3-1 の事前カウント」。

## 1. 概要

- 確かめたかったこと: 異性の成人だけが交配の候補に出るようにすると、今の世界（2-4）の交配から何が消えるか。
- 分かったこと:
  - **交配の手が候補にある決定の 92〜95% で、視界の成人は1体だけ。** 性別を入れると、その約半分（47.6〜48.4%）で候補が 0 になる。予想（3〜4 割）より多い——候補が複数ある決定がほとんど無いので、「候補が減ると名指しが重なりやすくなる」はほとんど効かない。
  - **今の出生の約半分（50.3〜50.7%）は、仮の性別で同性どうしの親から生まれている。** 出生が減る上限は約半分。
  - ただし交配の機会は出生よりずっと多い（1シードあたり決定 3.6〜4.5 万 対 出生 約 2,000）。出生が食料で頭打ちになっているなら、機会が半分になっても出生はあまり減らない。
- 次にすること: 3-1 を実装し、出生・個体数・成人到達率を `sexless`（2-4）との対の差で読む。

## 2. 条件

| 項目 | 値 |
| --- | --- |
| コミット | a8fae60 |
| マップ | flat / constrained (64x48) |
| tick 数 | 20000（tick 5000 より後） |
| シード数 | 12 |
| 条件 | base（2-4） |

仮の性別は身体の ID から SplitMix64 の仕上げで決める（乱数は引かない）。

```
go run ./cmd/count -what sex -map flat -w 64 -h 48 -seeds 12 -ticks 20000
go run ./cmd/count -what sex -map constrained -w 64 -h 48 -seeds 12 -ticks 20000
```
