# 4-4 の事前カウント: 食料が地面にある長さ（`foodage`）

判断は [`docs/history/20261002.md`](../history/20261002.md) の「4-4 の事前カウント」。

## 1. 概要

- 確かめたかったこと: 食料が古びる規則（4-4）を、普段食べられる食料に触れずに、身体のいなくなった陸に閉じ込められた食料（[lock-count](20261002-lock-count.md)）だけに効かせる長さがあるか。
- 分かったこと: 食べられる（拾われる）までに地面にあった tick は中央値 23〜27、99% で 203〜446。1000 tick を越えたのは制約で 0.18%、平坦で 0。最後に地面に残っていた単位は平坦で中央値 25 tick、制約で 8507 tick（seed 3 の東に閉じ込められた分）。
- 読み: 普段の食料と閉じ込められた食料の間に大きな隙間がある。寿命 1000 tick なら普段の食料にはほぼ触れない。
- 次にすること: `FoodLife` 1000 で 4-4 を実装する。
