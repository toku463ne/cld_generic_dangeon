# 8-2a3 残されたテントを拾う（`DropTents`）

判断は [`docs/history/20261004.md`](../history/20261004.md) の「8-2a3 の測定」。

## 1. 概要

- 確かめたかったこと: 持ち主が死んだテントが地面に残り、テントを持たない身体が拾うと、テントが持ち主より長く世界に残り、使われるか。flat と patches で `unbuilt`（6-5a）・`buried`（8-2a2）と比べた。
- 分かったこと（base 対 `unbuilt`、12 シード × 40000 tick）:
  - **死んで残ったテントは 1 シードあたり 290（flat）・271（patches）、そのうち拾われたのは 249・237（86〜87%）。** 1つのテントが何人もの手を渡る（作られたのは 174・145）。
  - **テントで眠った夜は 688・597**（8-2a2 の約 2 倍）。**消耗まで使い切られたテントは 122・103**（8-2a2 は 5・10）——使う夜の数を学ぶ身体がようやく出てきた。
  - 世界は動かない: 個体数 flat −1.6 ± 4.0、patches −3.1 ± 1.9。餓死・出生・成人到達率は誤差の内。眠っている割合 +0.6〜1.0 ポイント。崩壊 0。
- 予想との照合（PLAN 8-2a3）: 拾われる割合 5〜8 割（実際は 86〜87%）、テントの夜 1.5〜2 倍（約 2 倍）、世界は大きく動かない、崩壊なし は当たった。子の寒い夜（成人到達率）は動かなかった。
- 読み: テントは持ち主より長く世界を巡るようになり、使い切る経験も生まれた。それでも寒さの節約は世界を動かすほど大きくない（テントの夜は全部の眠りの一部）。
- 次にすること: ユーザに報告し、8-2b（個人・家族の定住場所）へ。
