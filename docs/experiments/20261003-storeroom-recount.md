# 段階6 の事前カウントの数え直し: 夜と寒さのある世界で（`storeroom`）

判断は [`docs/history/20261003.md`](../history/20261003.md) の「段階6 の余地の数え直し」。前の数え: [20261002-storeroom-count](20261002-storeroom-count.md)（4-4 の世界、夜なし）。

## 1. 概要

- 確かめたかったこと: 段階7（夜・夜の視界・睡眠・寒い夜）を先にしたあと、自分のための蓄え（定住場所に置く）の余地が生まれたか。成人（上限が満ち）が食べられず持ちきれない食料を見る割合と、そのあと窓の中で食料を必要とするか。明るさ別にも分けた。
- 分かったこと:
  - **余りを見る決定は今も 0.01%、1シードあたり 15000 tick で 4〜5 回。** 明るさで分けても 0.02〜0.04% を超えない（夜は 0〜0.01%）。
  - 余りを見たあと、窓の中で体力が1食以下に落ちる割合は 0.40〜0.42 → **0.64〜0.84**、餓死は 2〜4% → **13〜15%** に上がった（寒い夜で、満ちた身体も窓の中で困る）。
- 読み: 余りがあれば蓄える値打ちは前より大きいが、**余りを見る場面そのものがほとんど無い**——成人は満ちる前に食べ、満ちたら1つ持つので、置く手を足しても選ばれる場面は 1シードあたり数回。自分のための蓄えとしての定住場所は、まだ世界を動かさない見込み。
- 次にすること: 段階6 の入り方をユーザと決める。
