# 8-1b 自分の場所を知り、見込みを正から始める（`OwnPlaces`・`ReusePrior`）

判断は [`docs/history/20261004.md`](../history/20261004.md) の「8-1b の測定」。

## 1. 概要

- 確かめたかったこと: 自分の建てた場所に印を付けて帰り道にも値打ちを足し（A）、戻る回数の見込みを 2 回から始める（B）と、建てた本人が戻るようになるか。食料が散らばる flat と4か所に固まる patches で、`unbuilt`（6-5a）・`neutral`（8-1）と比べた。
- 分かったこと（12 シード × 40000 tick）:
  - **8-1（`neutral`）はどちらの地図でも世界を動かさない**（patches 116.2 → 116.7、flat 98.7 → 93.1 は誤差の内）。patches の 2 シードの試し走りで見えた −25% は揺らぎだった。patches では休める場所で始まる眠りが 26%、本人の戻りは 1 シードあたり 19 回（場所あたり 6%）——flat（1.4 回）より多い。
  - **A＋B は世界を悪くする。** flat: 個体数 98.7 → 61.3（−38%）、**崩壊 3 / 12**、出生 −35%。patches: 116.2 → 101.8（−12%）、出生 −10%、餓死 −12%。建つ数は flat 639・patches 838（8-1 の 5 倍・3 倍）、本人の戻りは 12・55 回（場所あたり 2%・7%）。眠っている割合は 3 ポイント上がった。
- 原因（追加の数え、flat・2 シード・15000 tick、コミットしない計器）: 成人の決定のうち「自分の場所へ歩いて寝る」続きが選ばれた手の計画になる割合は `unbuilt` 0.4% → `neutral` 1.5% → base 7.4%、交配の手は 54.7% → 50.5%。さらに帰り道の値打ちを外して（建てる手にだけ残して）4 シード × 20000 tick で試しても flat は 97 → 43 で、**害の主因は建てる手の値打ちそのもの**。戻る回数の見込み × 1晩の節約（約 12）を「窓の中の予備」として体力に足すと、空腹の身体が「建てて今眠る」を安全と読む——実際にはその体力は何晩も先にしか入らない。休んでいる母の配分（窓の中に実際に入る体力）とは性質が違う。
  - 見込みを「どう眠るか」（建ててから眠るか、そのまま眠るか）にだけ使い、「眠るか起きているか」には使わない形を試すと（4 シード × 20000 tick、コミットしない）、flat 96.8 → 95.8（害なし、建つ数 97）、patches 120.8 → 109.8（−9%、建つ数 192、戻り 14）。
- 読み: 窓の外の値打ちを窓の中の体力として足すと、生存の読み方そのものを歪める。値打ちを入れる場所を変える必要がある（ユーザ判断）。
- 次にすること: ユーザに確かめる。
