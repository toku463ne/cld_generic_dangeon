# 段階6 の事前カウント: 蓄える余地（`storeroom`）

判断は [`docs/history/20261002.md`](../history/20261002.md) の「段階6 の事前カウント」。

## 1. 概要

- 確かめたかったこと: 定住場所（置ける・古びにくい・隠れる）が自分のための蓄えとして働く余地。食べられず（1食が入りきらない）持ちきれない（手持ちが一杯）食料を見た成人が、そのあと窓（1000 tick）の中で食料を必要とするか。
- 分かったこと:
  - **体力の上限が満ちた成人が余りを見るのは決定の 0.01% 以下、1シードあたり 15000 tick で 3〜4 回。** 子や老人を含めると 0.13〜0.19%（上限が小さいので1食で満ちる）。
  - 追った余りのうち、窓の中で体力が1食以下に落ちたのは約 4 割で、落ちるまで中央値 756〜785 tick、そのとき余りを見た場所から 8〜14 タイル。餓死は 0〜4%。
- 読み: **自分のための蓄えには余地がほぼ無い。** 食料の手に入りやすさが時間で変わらず、身体は満ちる前に食べ、満ちたら1つ持つ（4-1）ので、置く手を足しても選ばれる場面が無い。
- 次にすること: 段階6 の切り方をユーザと決める（手に入りやすさが時間で変わる段階7 を先にするか、など）。

## 2. 条件

| 項目 | 値 |
| --- | --- |
| コミット | 64ca577 |
| マップ | flat / constrained (64x48) |
| tick 数 | 20000（tick 5000 より後の決定） |
| シード数 | 12 |
| 条件 | base（4-4） |

```
go run ./cmd/count -what storeroom -map flat -w 64 -h 48 -seeds 12 -ticks 20000   # constrained も
```

子と老人を含めた最初の形（コミット 0adbb8b）では、余りを見た決定は 0.13〜0.19%。上限が小さいので、1食以下に落ちたうち 25% は余りを見た直後だった（上限の小さな身体では1食が上限の大きな部分を占める）。読みを成人に絞った。
