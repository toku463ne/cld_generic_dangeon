# 3-8: 老人は交配できない（OldBarren）

判断は [`docs/history/20260928.md`](../history/20260928.md) の「3-8 の測定」。事前カウントは [oldbirths-count](20260928-oldbirths-count.md)。

## 1. 概要

- 確かめたかったこと: 年齢 `OldAge`（3200）以上の身体が交配できなくなると、出生・個体数・死因・性比がどう動くか。`oldmating`（M-3）との対の差で読む。
- 分かったこと:
  - **出生 −7〜−8%**（平坦 −418 ± 50、制約 −357 ± 39）。予想（−5〜−8%）の範囲。
  - **老いによる死 +45〜+51%**（平坦 281 → 424、制約 329 → 477）。死のうち老いの割合は 5.2% → 8.4%（平坦）、6.5% → 10.1%（制約）。餓死は出生と同じだけ減った。
  - **個体数は変わらない**（平坦 −1.2 ± 2.8、制約 −1.3 ± 3.9）。崩壊 0（両方の地図・両方の条件）。
  - 成人の割合 +1.5〜+2.4 ポイント（子が減った分）。成人のうち女の割合は −0.010〜−0.014 で、有意の境目か下（平坦 2.0 SE、制約 1.4 SE）。成人到達率は変わらない。
  - 変えた条件の世界で、出生の親に老人はいない（`oldbirths`、平坦: 0 / 1776 出生・シードあたり）。成人のうち老人の割合は 8.2% → 10.0%。
- 読み: 出生を縛るのは払える女の数なので、効いたのは老いた母の分（事前カウントで 7〜8%）で、老いた父の分は若い男が埋めた。老人は代金を払わなくなり長く生きて老いで死ぬ。個体数は食料で頭打ちなので、減った出生は入れ替わり（餓死）が減る形で吸収された。
- 次にすること: 段階3の続きをユーザと決める。
