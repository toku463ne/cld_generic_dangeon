# 4-0: 休んでいる母は休みが明けることを読む（RestAhead）

判断は [`docs/history/20261002.md`](../history/20261002.md) の「4-0 の測定」。事前カウントは [ties-count](20261002-ties-count.md)。

## 1. 概要

- 確かめたかったこと: 休んでいる母が値付けを休み明けの消耗で読み、休みの残りで浮く分を予備として足すと、足元の食料を食べるようになり、休み明けの体力・性比・個体数がどう動くか。`restblind`（3-8）との対の差で読む。
- 分かったこと:
  - **休んでいる母が足元に食料のある決定で食べた割合 0.26〜0.27 → 0.71**（両方の地図）。休みのあいだに自分で食べた回数 0.23〜0.31 → 0.63〜0.72。**休み明けの母の体力 62〜68 → 76〜78**。最善の手の死ぬ確率がちょうど 0 の決定は 42〜50% → 11〜15%（残りは体力 0.9 以上の満腹に近い母）。
  - **成人のうち女の割合 0.47〜0.52 → 0.60〜0.62**（平坦 +0.100 ± 0.010、制約 +0.131 ± 0.009）。**完了条件の 0.4〜0.6 をわずかに外れた。**
  - 出生 +9〜15%（平坦 +473 ± 65、制約 +727 ± 58）、餓死も同じだけ増えた（+423 ± 71、+719 ± 64）。**個体数は変わらない**（平坦 −1.8 ± 2.5、制約 −3.7 ± 3.5）。崩壊 0。成人到達率は変わらない。成人の割合 −3〜−4 ポイント（子が増えた分）。
  - 休んでいる母は 1 tick あたり 40〜44 → 49〜50 体に増え、配られた食料も +8〜20% 増えた（母1体あたりの配分は変わらない）。
- 読み: 予想どおり、食べ控えは予測の誤りだった。母が自分で食べて休み明けの体力が上がり、産後に生き残る女が増えて、女の割合が釣り合いを越えた——3-3c で配分を増やしすぎたときと同じ向き。個体数は食料で頭打ちなので、出生の増加は入れ替わり（餓死）に吸収された。
- 次にすること: 女の割合が 0.6 を越えたので、配分の量（`ProvisionEachWith`・`ProvisionEachAlone`）を下げて戻すか、このまま 4-1 へ進むかをユーザと決める（PLAN 4-0 の完了条件）。
