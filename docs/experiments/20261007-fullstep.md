# 表の天井の丸め（`FullStep` 5）: 世界は動かないか

判断は [`docs/history/20261007.md`](../history/20261007.md)。`exact`（表を正確な体力の上限ごとに作る、2026-10-07 以前の形 ＝ 9-5b の base と同じ世界）を基準に、base（表の天井を体力 5 の倍数に切り上げて共有）を比べた。flat 12 シード。規則ではなく値付けの近似の変更なので、見るのは「世界が動かないこと」と速さ。

## 1. 概要

- 確かめたかったこと: 表の天井を 1 段未満だけ粗くしても世界が動かないか。`cmd/speed` の 1 シードで個体数が 65 → 40 と違ったので、それが規則の影響かどうか。
- 分かったこと:
  - **世界は動かない**: 個体数 +7.3 ± 9.4、崩壊 1/12 → 1/12、出生・餓死・成人到達率・最大世代数・変位・決定の割合・配分の枠の割合、すべて誤差内。予算の段の割合・成人の平均予算（1.097 → 1.076、−0.021 ± 0.023）・ドリフト・相関も誤差内。`cmd/speed` の個体数の違いは 1 シードの世界の違いだった。
  - **速い**: `cmd/experiment` の 1 本（flat、40000 tick、2 並列）が 9-5b では約 100 秒だったのが 16〜19 秒。`cmd/speed` は constrained seed 5 で 547 → 169 µs/tick、表 1287 → 521、ヒープ 1.8 → 0.57 GB。
  - **9-5b の欠けていた数字が埋まる**: `exact` 列は 9-5b の base と同じ世界で、計器を直したので、9-5b で NaN だった行が読める——予算のドリフト（後半 − 前半）0.004 ± 0.017（誤差内。価格が止めている）、成人の平均予算 1.097 ± 0.018。
- 次にすること: ユーザの判断で 9-5b の patches・constrained を `FullStep` 入りで取り直す。
