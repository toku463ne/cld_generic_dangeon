# 8-2b3 所有・締め出しを外す

判断は [`docs/history/20261005.md`](../history/20261005.md)。途中の段階なので軽い形（`MEASURE.md`「測定の作法」）。

## 1. 概要

- 確かめたかったこと: 定住場所の所有・締め出し・交配の合意を外す（できた場所は誰でも入れる）と、flat の崩壊（8-2b で 2 / 36）と constrained の下がり（8-2b2 で −6.0）が消えるか。`unsettled`（定住場所なし）と比べた。
- 分かったこと:
  - **constrained（12 シード）**: 個体数 +1.0 ± 3.9——8-2b2 の −6.0 は消えた。崩壊 0。
  - **patches（12 シード）**: 個体数 −4.0 ± 5.7（誤差の内）。崩壊 0。休める場所で始まった眠りは 25%（8-2b2 とほぼ同じ）。
  - **flat（36 シード × 40000 tick）**: **崩壊 2 / 36 のまま**（`unsettled` は 0 / 36）。個体数 −7.7 ± 4.3、出生 −8%。**締め出しを全部外しても flat の崩壊と下がりは残る——「崩壊は締め出しの副作用」という 8-2b2 までの読みは誤りだった。** 残るのは定住場所そのもの（暖かく眠れる場所が増えること）の効果で、出生が減る向き。崩壊した 2 シードが初めて下限を割った tick は 25332 ± 14010（1本は 11000 前後、1本は終わり際）。8-2b で崩壊したのはシード 3・23、今回早く落ちたのはシード 5——決まったシードが壊れるのではなく、確率が上がる形。
- 予想との照合: constrained の 0〜+5% は当たり。休める場所の眠りが 7% を超えるのも当たり（flat 7.6%・patches 25%・constrained 9.1%）。**flat の崩壊 0 / 36 と 0〜+5% は外れ**（2 / 36、−7.7）。外れの根は、8-2b の切り分けで「締め出しを一時的に外すと崩壊しない」を少数シードで見て一般化したこと。
- 次にすること: ユーザに報告する。flat の「定住場所があるほど出生が減る」は 8-2c（腐りにくさ）で定住場所の価値が変わったあとも引き続き見る。
