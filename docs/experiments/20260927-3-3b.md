# 3-3b: 母1体ごとの配分（ProvisionEach）

判断は [`docs/history/20260927.md`](../history/20260927.md) の「3-3b の測定」。前は [3-3](20260927-3-3.md)・[食料の掃引](20260927-3-3-food.md)。

## 1. 概要

- 確かめたかったこと: 休んでいる母が1 tick ごとの自分の確率（相手が同じ地域にいれば 0.00375、いなければ半分）で配分を求め、戻る食料を地面より先に受け取る形にすると、(1) 母1体あたりの配分が頭数（食料の水準）によらなくなるか、(2) 産後に死ぬ割合と女の割合が良くなるか。`perunit`（3-3）との対の差と、食料の 1・2・4 倍で読む。
- 分かったこと:
  - **(1) 頭数によらなくなった。** 母1体が休みのあいだに受け取る体力は、食料 1・2・4 倍で平坦 42.9・42.7・42.7、制約 39.6・39.8・39.8（狙いは 45）。3-3 では 25 → 23 → 22 と薄まっていた。休み明けの母の体力も 64.5〜65.7 で水準によらない。
  - **(2) 女の割合は上がった**: 成人のうち女の割合 0.23 → **0.33〜0.34**（食料 2・4 倍で 0.35〜0.38 までわずかに上がる）。出生 +25%、餓死も同じだけ増え、成人到達率 −0.064、個体数は変わらない。崩壊 0。
  - **しかし産後に死ぬ割合はあまり下がらない**: 女が最後の出産から 1000 tick 以内に死ぬ割合 78〜83% → 73〜78%。**休み明けの母の体力は 58 → 65 にしか上がらなかった**（予想 85〜95）。予想の外れの理由: 母は休みのあいだにも毎 tick 体力を燃やす（400 tick で 40）。配分の 43 は出産の代金を埋めるが、休みのあいだの燃える分は母が自分で食べて賄うので、休み明けに満腹には戻らない。そこでまた交配して 45 を払うと 20 前後しか残らない。
- 次にすること: 配分の確率を、出産の代金と休みのあいだの燃える分の両方を埋める水準（約 2 倍）に上げるか、このまま 3-4 に進むかをユーザと決める。
