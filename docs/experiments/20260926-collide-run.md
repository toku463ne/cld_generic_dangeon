# 衝突: 他の身体のいるタイルへ入れないとき

判断は [`docs/history/20260926.md`](../history/20260926.md) の「衝突: 測定」。数え上げは [20260926-collide](20260926-collide.md)。

## 1. 概要

- 確かめたかったこと: 衝突（占有タイルは次の1歩の候補から外し、意図の次の1歩が塞がったら決め直す）で、決定の割合がどれだけ増え、個体数・選択勾配・速さがどう動くか。
- 分かったこと: **決定の割合は 0.084 → 0.099（平坦）・0.107 → 0.124（制約）**。数え上げからの見積もり（約 0.10・0.13）どおりで、跳ね上がらない。きっかけの 16〜17% が `blocked`。**個体数は動かない**（−2.7 ± 2.5・+0.6 ± 2.3）——今の地図（64×48 に約 170 体、タイルの 6% ほど）では、空間はまだ個体数の制約にならない。出生はわずかに減った（約 −30）。**速さの側の有利が半分ほどに縮んだ**（+0.26 → +0.15、+0.29 → +0.13）。1 tick は 44 → 48 µs（+10%。増えた決定の分）。
- 次にすること: 空間が効くのは、身体が集まる場所（定住場所・巣・狭い地形）ができてから。そこで改めて測る。

## 読み方

- **判断回数は跳ね上がらない。** 塞がった意図は決め直しで空いたタイルへ向かうので、`blocked` は1回で済む。混雑して四方を囲まれた身体だけが待つことになるが、今の密度ではほとんど無い（待つの割合は 0.01% のまま）。
- **空間はまだ効かない。** 身体はタイルの 6% ほどにしかおらず、食料が食べ尽くされているので散っている。「混雑地で移動が制限され、空間も個体数の制約になる」は、身体が集まる理由（定住場所・巣・水辺・狭い通り道）ができてから現れるはず。
- **速さの有利が縮んだ。** 速い身体ほど1 tick に進む距離が長く、他の身体の手前で決め直す回数も多いと読めるが、この測定では確かめていない。
