# 7-3b 睡眠圧・睡眠負債・寝る手（`Sleep`、`SleepTicks` 333）

判断は [`docs/history/20261003.md`](../history/20261003.md) の「7-3b の測定」。

## 1. 概要

- 確かめたかったこと: 睡眠圧（起きていた時間で高まる）・睡眠負債（消耗を上げ能力を下げる）・寝る手（圧が `WakeAt` を超えると出て、寝ると 1日の 3 分の 1 眠る。接触で目覚める）を入れたとき、身体がどれだけ眠り、いつ眠り、負債が世界をどう動かすか。値付けは睡眠専用の項を持たず、7-3a の消耗の読みと、寝る手の生理（眠る間は食べず、起きると負債を返した消耗）で読む。
- 分かったこと:
  - **眠っている割合は 2.1〜2.5%**（1日の 3 分の 1 を眠る身体なら 33%）。眠るのはおもに昼の後半〜夕方（2.5〜3.2%）で、夜明け前後が一番少ない（0.9〜1.2%）——夜に寄らない。満腹の成人は窓（自分の体力と同じ）の中で死ぬ見込みがほぼ 0 で、寝る手は同点の中から引かれたときに選ばれる。
  - 負債は慢性で、**餓死のうち負債が大きいもの（死因「睡眠不足」）が 331〜406（死の 7〜9%）**。老いによる死は 503 → 219（老人の多くが老いる前に負債の消耗で飢える）。
  - **個体数は変わらない**（平坦 148 対 148、制約 129 対 131）。出生 −3%（有意）。決定の割合 +0.008（眠る手は意図にならず、目覚めると決め直す）。
  - 1日のリズム（夜明けの食事・昼の終わりの出生）はそのまま。
- 読み: 眠る理由がまだ無い世界では、寝る手は値付けで勝たず、身体は負債を抱えたまま生きる（ユーザの見立て「敵もいない世界、夜寝るのに十分な理由がない」のとおり）。O15（夜に寝ることが結果として出る）は不満のまま。暗くなり始めを知覚して先読みに使う（7-2b）は後の段階で。
- 性能: 表 872（`sleepless` 877）——負債で消耗が身体ごとに変わっても表は増えない（7-3c）。1表の行 13.5 → 15.8、ヒープ 237 → 320 MB、1 tick 303 → 360 µs。
- 崩壊（制約 36 シード）: 0。東の身体がいなくなったシードは 18 / 36（7-1 以来の率）で、4-4 の古びる規則で崩壊しない。

## 予想との照合（PLAN 7-3b）

| 予想 | 結果 |
| --- | --- |
| 1日に1回まとめて眠り、夜に寄る（夜の眠る割合が昼の 2 倍以上） | 外れ。眠るのは 2〜2.5% で、昼の後半に寄る |
| 満腹の成人は手が同点になりやすく、眠るのは負債で危険が見えてから——夜に寄らず負債が溜まったままになる恐れ | 当たり（この恐れのとおり。ユーザに申し出て、今は夜に寝なくてよいと決まった） |
