# 3-5b: 寿命を 4000 に（Lifespan 4000）

判断は [`docs/history/20260927.md`](../history/20260927.md) の「3-5b の測定」。前は [3-5](20260927-3-5.md)・[3-5-allee](20260927-3-5-allee.md)。

## 1. 概要

- 確かめたかったこと: 寿命を 3000 → 4000 に延ばし繁殖できる期間を 2000 → 3000 にすると、3-5 の崩壊（制約の 1 / 12）と個体数の低下がなくなるか。`short`（3-5）・`ageless`（3-4）と並べて読む。
- 分かったこと:
  - **崩壊 0（両方の地図）**。崩壊しなかったシードの谷の最小は 76 → 112（制約）、124 → 144（平坦）。
  - **老いによる死は死の 13〜16%**（予想 15〜20% どおり。`short` は 32〜35%）。
  - **個体数は `short` より上がった**（平坦 +13.3 ± 2.1、制約 +28.8 ± 12.8）。`ageless` よりはまだ 8〜10 少ない。成人到達率は `short` より −0.05〜−0.06（0.72〜0.73。`ageless` の 0.67〜0.69 よりは高い）。成人のうち女の割合 0.49〜0.52。
  - 数が少ないと相手が見えにくい帯（個体数 110 未満）には入らなくなった（制約で 110〜140 の成人 tick は全体の 1%）。
  - 老いで死んだ成人のうち子を持たなかったのは 0.3〜1%。
- 次にすること: 3-6（能力の年齢の曲線）へ。

## 3. 崩壊

- flat: 崩壊したシード: 0 / 12（下限 20）。 崩壊しなかったシードの個体数の谷（tick 1 以降の最小）: 平均 150.0 ± 1.0、最小 144（12 シード）
- constrained: 崩壊したシード: 0 / 12（下限 20）。 崩壊しなかったシードの個体数の谷（tick 1 以降の最小）: 平均 140.9 ± 3.2、最小 112（12 シード）
