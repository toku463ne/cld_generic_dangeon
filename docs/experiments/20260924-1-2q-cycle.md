# 1-2q 数え上げ: 地面の食料の周期と、平坦な地図のゆっくりした減少

判断は [`docs/history/20260924.md`](../history/20260924.md) の「1-2q: のこぎりと減少は別のもの」。

## 概要

- 確かめたかったこと: [1-2q の測定](20260924-1-2q.md)で見えた2つ——平坦な地図の地面の食料の「約 6000 tick ののこぎり」と、平坦な地図の人口のゆっくりした減少（30000 tick で約 8%）——が同じもの（全員が満腹で同時に始まったことの減衰）かどうか。のこぎりの振れ幅が時間とともに小さくなるか、減少がのこぎりの谷を追うかを見る。
- 分かったこと: **別のもの。** (1) 本当の周期は 6000 tick ではなく **300 tick（食事1回ぶん）**で、6000 tick は 2000 tick ごとのチェックポイントが 300 tick の周期を読んだ見かけ。(2) 周期は、全員の「体力 mod 30」が同じ値にそろっていることから来る。**留まりのせいで食事が上限で切られないので、このそろいは崩れず、振れ幅は 60000 tick まで小さくならない。** (3) **始めの体力をばらすと振れ幅は約 7 分の 1 になるが、人口の減り方は変わらない**（平坦: 10000 tick 145.0 → 60000 tick 128.4、ばらした世界 145.5 → 129.5）。減少は、のこぎりの減衰でも、のこぎりの谷でもない。
- 次にすること: 平坦な地図の減少と制約の地図の減少は、同じ形（地面の食料が増えながら人口が減る）をしている。共通の原因として調べる。

## 条件

| 項目 | 値 |
| --- | --- |
| コミット | 7027d36 |
| マップ | flat (64x48) / constrained (64x48) |
| tick 数 | 60000 |
| シード数 | 12（最初のシード 1） |
| 比較対象（base） | 同じシードで、始めの体力を (1, `EnergyMax`] で一様にばらした世界 |

**再現方法**:

```
go run ./cmd/count -what cycle -map flat -w 64 -h 48 -seeds 12 -ticks 60000
go run ./cmd/count -what cycle -map constrained -w 64 -h 48 -seeds 12 -ticks 60000
```

**数え方**:

- `base` の世界を毎 tick 読み、地面の食料と人口を記録する。
- 「ばらした世界」は、同じシードで作った世界をセーブし、各身体の体力を (1, `EnergyMax`] の一様乱数に書き換えて読み直したもの。乱数は数え上げ側の別の源から引き、世界の乱数には触れない。世界の規則ではなく、比較のための反実仮想の始まり。
- 自己相関は 10000 tick 以降の地面の食料について、シードごとに取る。**傾向（食料がゆっくり増える）を除いていない**ので、傾向が大きい系列ではどのずれでも高く出る。周期の判定には「半周期（150）で負、1周期（300）で正」の対を使う。
- 「体力 mod 30」は最後の tick の生きている身体について、0.1 刻みで数えた値の種類。
- 死亡の位相: 10000 tick 以降、tick mod 300 ごとに地面の食料の平均を取り、低いほうから 1/4 の位相を「谷」とする。死亡のうち谷の位相で起きた割合。
- 振れ幅: 5000 tick の区間の中での最大 − 最小。「シード平均の食料」は 12 シードの平均の系列の振れ幅、「シードごと」は各シードの振れ幅の平均。

## 読み方

- **周期は 300 tick。** flat の base で、自己相関は半周期（150）で負、1周期（300）と 2周期（600）で 0.97。2000 tick のずれは 300 の倍数から 200 ずれているので負になり、6000 tick（300 の 20 倍）で正に戻る。**1-2q のレポートの「約 6000 tick ののこぎり」は、2000 tick ごとのチェックポイントが 300 tick の周期を読んだ見かけ**（3 回ごとに同じ位相に戻る）。
- **周期の出どころは、体力の位相がそろっていること。** flat の base では、最後の tick で全シードの全個体の「体力 mod 30」が1つの値だった。全員が 100 で始まり、全員が毎 tick 同じ量を燃やし、1食はちょうど 30 を足す。**留まり（体力 70 を超えると食べない）のせいで食事が上限で切られないので、この一致は規則が保ち続ける。** 全員が同じ tick に「今食べる」の点を越え、食料がまとめて減る。
- **振れ幅は小さくならない。** flat の base で 10000 tick 以降、シード平均の振れ幅は 60〜67 のまま（シードごとは約 70〜74）。シード平均とシードごとがほぼ同じなので、シードどうしの位相もずれていない。**始まりの減衰ではない。** constrained の base は振れ幅が 45 から 22 へ下がり、体力 mod 30 が 2 つの値をとるシードがあった。1食が上限で切られることが、たまに起きているため。
- **死亡の位相はそろいから決まる。** base では、体力が 0 になる位相が全員同じなので、死亡は1つの位相に集まる（flat では谷の 1/4 に 100%、constrained では 0%）。どちらの値も「谷が死を起こす」ことの証拠にはならない。ばらした世界では 0.28〜0.29 で、一様（0.25）に近い。
- **減少は、そろいが無くても同じ。** flat の人口は 10000 tick から 60000 tick で、base 145.0 → 128.4、ばらした世界 145.5 → 129.5。constrained も両方で減り続けた（base 62.4 → 25.3、ばらした世界 78.8 → 30.5）。**ばらした世界でも地面の食料は増え続けている**（flat 52 → 83、constrained 157 → 245）。
- ばらした世界の自己相関がどのずれでも高いのは、傾向（食料が増え続ける）を除いていないため。周期の判定には使わない。
