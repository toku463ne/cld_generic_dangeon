# 1-2q 数え上げ: 直線の往復と死亡

判断は [`docs/history/20260925.md`](../history/20260925.md) の「1-2q: 死亡の多くは直線の往復で終わる」。

## 概要

- 確かめたかったこと: クライアントで制約の地図（シード 2）を見ると、飢えかけた身体が1本の列を上下に往復していた。軸に沿った向き（東西南北）は、跳ね返すとちょうど逆向きになるので、向きを保つ身体は同じ列（または行）を往復し続け、幅 3 タイルの帯しか見ない。これがどれだけ死亡を説明するか。
- 分かったこと: **平坦な地図では、tick 5000 より後の死亡の 47.7% が直線の往復で終わっている。生きている身体のうち往復しているのは約 3% なので、往復は死ぬ確率を約 16 倍にする。** 制約の地図では死亡の 26.5%（生きている身体の約 4%、約 7 倍）。生きている身体の 6〜7 割は軸に沿った向きを持っているが、往復に捕まっているのはその一部。
- 次にすること: 跳ね返しがちょうど逆向きになるときは、斜めへ曲がる規則を1つ足す（1-2r）。制約の地図の残り 4 分の 3 の死亡は、別に調べる。

## 条件

| 項目 | 値 |
| --- | --- |
| コミット | 8f469f7（`cmd/count` の `shuttle` は作業ツリーに足した状態で測った。世界のコードは 8f469f7 のまま） |
| マップ | flat (64x48) / constrained (64x48) |
| tick 数 | 40000 |
| シード数 | 12（最初のシード 1） |
| 比較対象（base） | 生きている身体のうち往復している割合（死亡のうちの割合と比べる） |

**再現方法**:

```
go run ./cmd/count -what shuttle -map flat -w 64 -h 48 -seeds 12 -ticks 40000
go run ./cmd/count -what shuttle -map constrained -w 64 -h 48 -seeds 12 -ticks 40000
```

**数え方**:

- **直線の往復**: 直前の 1000 tick（満腹から餓死までの tick 数）の位置の広がりが、x か y のどちらかで 1 タイル未満。1000 tick 分の記録がそろっていない身体は数えない。
- 死亡は tick 5000 より後だけ数える（始まりの2回の食事の波で、立っている場所に関係なく減るため）。
- 生きている身体は tick 5000・10000・20000・40000 で読む。「向きが軸に沿っている」は直前の移動の向きが東西南北のどれか。

## 見て分かったこと

`go run ./cmd/shot -map constrained -w 64 -h 48 -seed 2 -from-tick 36900 -follow 97 -shots 2 -every 300 -out shots`

- シード 2 の身体 #97（tick 37301 に餓死）は、水の左側にある地域 3 の帯（地域 2 との境目と水のあいだ、幅 8 タイル）を南北に往復していた。**その帯には食料が1つも無く**、隣の地域 2 と、地域 3 の右岸には食料が多く残っていた。帯の中ではどの移動も地域 3 に留まるので全て同点になり、向きを保つ。南は地図の端、北は地域 1 との境目で跳ね返り、ちょうど逆向きになる。
- 同じ帯に、体力の少ない（黒い）身体が何体も集まっていた。
