# 7-3d 生命・睡眠・子孫の順（門。`ForceAt` 0.625・`ForceMax` 0.9・`StayAwake` 0.1）

判断は [`docs/history/20261004.md`](../history/20261004.md) の「7-3d の測定」。

## 1. 概要

- 確かめたかったこと: 睡眠圧が `ForceAt` に達したら交配の門が閉じ、その場で眠る（命の危険があれば `ForceMax` まで起きていられる）と、身体がどれだけ・いつ眠り、世界がどう変わるか。
- 分かったこと:
  - **眠っている割合 4〜5% → 22%**（予想 25〜33% よりやや下）。死因「睡眠不足」は 0 に。
  - **個体数 平坦 −10%（118 → 106）・制約 −11%（94 → 83）、出生 −29〜−31%。** 老いによる死が増え（+68% / +54%）、成人の割合 0.67 → 0.76〜0.77。成人到達率は変わらない。
  - **眠りは夜に寄らない。** 1日の中で眠っている割合は昼の前半が一番高く（201〜300 で 0.34〜0.36）、夜は 0.21〜0.26、夜明け前後が低い（0.14〜0.19）。7-4 の夜の寄り（夜 8〜11%、昼 3% 以下）は、眠りの大半が睡眠圧で強制されるようになって薄れた。
  - 休める場所で始まった眠り 0.3% → 1.3〜1.5%（予想の 1% 前後）。強制された身体がたまたまそこにいる分で、歩いて行く形はまだ出ない。
  - 崩壊 0 / 36。ただし制約の地図で東が空になるシードが 31 → 36 / 36。
  - 1体あたりの 1 tick は軽くなった（眠っている身体は決めない）。
- 読み: 睡眠圧は体内時計を持たないので、強制される時刻は身体ごとの起きてからの時間で決まる。値付けは眠りが近いことを読まないので、「どうせ眠るなら夜に・休める場所で」が選べない。O15（結果として夜に寝る）は 7-4 より遠のいた。
- 次にすること: `VISION.md`（夜に寝ることが多くなる）との食い違いとして、ユーザに確かめる。候補: 値付けが強制される眠りまでの時間を読み、その前にいつ・どこで眠るかを選ぶ。
