# 10-2h 好む地形（平地・森）——小の測定

判断は [`docs/history/20261010.md`](../history/20261010.md)。**小の測定**（constrained・4 シード・20000 tick・`-brief`）。基準 `warmed`（下半分が森、獣は森を好み人間は平地を好む。好む地形以外は消耗 1.5 倍。狩りは 5000 から、空腹のときだけ）、対照 `peaceful`（狩りなし、地形は同じ）。コミット 3839882。

## 1. 概要

- 確かめたかったこと: 好む地形で住み分けを固めると、獣が人間の地域へ入る割合と、よその地域で倒される人間が減るか。
- 分かったこと: **少し減るだけ。** 獣が人間の半分にいる割合は 0.068（10-2g）→ 0.045、よその地域で倒された人間は 41.5 → 33、倒された人間 82 → 78.5、人間は `peaceful` の −19%（10-2g は −20%）、絶滅 0/4。1.5 倍の消耗は境を越える短い狩りを止めない。
- 予想との照合: 向きは当たり、大きさは外れ（0.03・15・50・−10% と書いた）。
- 読み: VISION では平地は獣の「苦手」ではなく「好む地形以外」で、消耗 1.5 倍は境を越える代金としては軽い。地形で完全に分けるには、獣の苦手な地形（高台）を境に置くか、境に食料の無い帯を置くかという地図の設計になる。規則としての好む地形はこれで閉じる。
- 次にすること: 10-2i（共用の休める場所をその地域の種族のものに）の測定、10-2j 価格。
