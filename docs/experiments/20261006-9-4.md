# 9-4 繁殖能力を予算の枠にする（`AllotFertility`）

判断は [`docs/history/20261006.md`](../history/20261006.md)。軽い形。`unfertile`（9-3b、繁殖能力なし・成立 ＝ 出生）を基準に、`evenfert`（確率と代金だけ: 段の差 0・代金 0 で選択が無い）と base（段 0.8・0.9・1.0、1段 1/3）を比べた。constrained は 5 並列が OOM で落ち、3 並列で取り直した（同じコミット）。

## 1. 概要

- 確かめたかったこと: 繁殖能力（0〜2 の段、成立した交配から子が生まれる確率は両親の見込みの積）を予算の枠にし、交配の代金を成立のたびに払う形にしたとき、選択圧が立つか・どちらへ寄るか・世界は動くか。
- 分かったこと:
  - **選択は3地図とも繁殖能力の低い側へ強く寄る**: 段 0 の成人は flat 74%・patches 66%・constrained 74%（引きは 1/3）、最大段は 1〜2% まで削られる。受胎の失敗は数 tick と `MateEnergy` を失うだけで安く、1/3 の予算を取り戻す取引が勝つ。
  - **出生率の傾きは正で有意**: 最高段 − 最低段の交配1回あたりの出生は +0.20〜+0.21 ± 0.01（3地図）。`VISION.md`「確率は繁殖能力に依存」を満たす。
  - **個体数は flat +9.3 ± 3.0・patches +9.6 ± 3.9 で増え、constrained は誤差内（−1.6 ± 3.4）**。段 0 は中立より予算が 1/3 多いので、集団全体が速さ・体力を約 15% 買った状態になる——「中立」の置き場所がそのまま世界の強さになる。崩壊は増えない（flat 1/36 → 0）。
  - **確率と代金だけ（`evenfert`）は flat で −8.1 ± 3.8（−10%、2σ）、patches・constrained は誤差内。** 成立した交配は出生の 1.2〜1.3 倍になる（中立の対で受胎 0.81）。
- 予想との照合: (b)「低い側へ寄る」は当たり（74% は予想の「1/3 を超える」より強い）。(a)「確率と代金だけでは動かない」は flat で外れ（−10%）。(c)「個体数 −5〜+5%」は flat・patches が上に外れた（+9〜11%——段 0 の予算の払い戻しを数えていなかった）。
- 次にすること: ユーザに報告。9-5（両親から混ぜて継ぐ・予算の継承）へ。
