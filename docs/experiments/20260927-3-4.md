# 3-4: 休んでいる母は体力をあまり燃やさない（RestBurn 0.5）

判断は [`docs/history/20260927.md`](../history/20260927.md) の「3-4 の測定」。前は [3-3d](20260927-3-3d.md)。

## 1. 概要

- 確かめたかったこと: 休んでいる母の消耗を 0.5 倍（休みのあいだ 40 → 20）にすると、休み明けの母の体力が上がり、産後に死ぬ割合が下がるか。`busy`（3-3d）との対の差で読む。
- 分かったこと:
  - **休み明けの母の体力は上がらず、下がった**（平坦 71 → 65、制約 69 → 61）。予想（約 90）と逆向き。
  - **原因: 休んでいる母が自分で食べなくなった。** 足元に食料のある決定で食べる割合が 0.84〜0.85 → **0.32〜0.33**、休みのあいだに自分で食べる回数が 0.87〜0.96 → 0.23〜0.28。消耗が下がると、値付けでは食べても食べなくても死ぬ確率がほぼ同じ（0 に近い）になり、食べる手が選ばれにくくなる——と読む（値付けの中身は確かめていない）。節約した 20 の大半を、食べる回数が約 0.65 回（約 20）減ることで失っている。
  - それでも**個体数は増えた**（平坦 +16.5 ± 1.4、制約 +18.1 ± 2.7）、出生 +11〜15%。成人のうち女の割合 0.46〜0.48 → **0.51〜0.57**（予想の 0.6 前後より小さく、制約では釣り合いに近い）。女が最後の出産から 1000 tick 以内に死ぬ割合 67〜69% → 63〜64%。成人到達率 −0.008〜−0.022。崩壊 0。
- 次にすること: この形で 3-5（寿命）へ進むか、母が食べ控える件を扱うかをユーザと決める。
