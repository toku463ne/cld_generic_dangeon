# 13-1 訓練ステージで遺伝子型の分布が動くか——小の測定

判断は [`docs/history/20261012.md`](../history/20261012.md)。**小の測定**（trainhuman・trainbeast・4 シード・20000 tick、`warmed` のみ）。コミット 7848b31。訓練ステージはその種族だけ、好む地形の 1 地域で、自分の食料が 1:1 の地図と同じ密度（地図全体に上限 600 の全部）で戻る。

## 1. 概要

- 確かめたかったこと: 訓練ステージで遺伝子型の分布が tick 0 から動くか（選択）。また、後半には落ち着くか。
- 分かったこと: **動く**。どちらの種族も、繁殖能力が下がり（−0.74・−0.72。どちらも 20σ 超）、視野が上がり（+0.24・+0.35）、速さへの配分が上がる（+1.48・+1.61。11 段のうち 4.9 → 6.4）。予算は種族で向きが逆で、人間は +0.57、獣は −0.59。どれもシードの向きが揃っていて、漂流ではない。後半で落ち着いたのは繁殖能力・視野・予算。**速さへの配分は後半も上がり続けた**（終わり − 中間: 人間 +0.73 ± 0.20、獣 +0.46 ± 0.24）。崩壊は 0/4・0/4。数は人間 214、獣 216（1:1 の地図の 78・91 より多い——ほかの種族も狩りも無いため）。
- 予想との照合: 予算 −0.3〜−0.8 は獣だけ当たり、人間は逆向き。繁殖能力 −0.2〜−0.5 は外れ（もっと下がった）。視野 +0.1〜+0.3 は人間で当たり。終わり − 中間が誤差内は外れ（速さへの配分）。人間 70〜100・獣 60〜100 は外れ（密度を直したので倍以上）。
- 読み: 訓練ステージは「ある程度進化した種」を作れる。`VISION_CHECKS` の巣の行の前半（tick 0 と違う）の材料が揃った。速さへの配分がまだ動いているので、訓練の長さは 20000 tick では足りない。40000 tick（10 年）で落ち着くかは、13-2 でセーブを作るときの大の測定で読む。
- 次にすること: 13-2 セーブ（血統）。
