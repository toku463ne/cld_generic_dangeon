# 7-3e 強制される眠りを先読みする（`SleepAhead`）

判断は [`docs/history/20261004.md`](../history/20261004.md) の「7-3e の測定」。気温と食料の格子は別のレポート [20261004-climate](20261004-climate.md)。

## 1. 概要

- 確かめたかったこと: 値付けが強制される眠りまでの tick を読み、起きている手はその眠りを窓から差し引き、見込みを起きている時間の平均の視界で読むと、身体がいつ眠るようになるか（O15）、世界がどう変わるか。
- 分かったこと:
  - **眠っている割合 22% → 32〜33%**（`VISION.md` の「1/3日寝続ける」の量）。
  - **1日のリズムがそろった**: 眠っている割合は昼の後半から上がり、夕暮れと夜の前半（401〜600）で 0.67〜0.69、夜の後半に起き出し、夜明け前後は 0.03〜0.06。暗闇（明るさ 0）の平均 0.39〜0.40、真昼 0.22〜0.25。**夜の眠る割合が昼より高い**（O15 の向き）。ただし眠りの中心は夜の真ん中ではなく夕暮れ、身体は夜の後半に起きて暗い中で食べる。
  - **成人到達率 0.83 → 0.95**（両方の地図）。子も同じ時刻に眠り、寒い夜を起きて過ごさなくなった（7-4 で下がった分が戻った）。
  - 個体数 平坦 −13%（106 → 93）・制約 −5%（83 → 79、有意でない）。出生 −27〜−29%（眠る時間が増え、眠い身体は交配しない）。餓死 −26〜−29%。
  - 休める場所で始まる眠り 1.3〜1.5% → 0.8%（下がった）。眠りの時刻をそろえる力のほうが、場所へ歩く力より強い。
  - 崩壊 0 / 36（東が空になるのは 36 / 36、7-3d と同じ）。
- 格子（[climate](20261004-climate.md)）から: 夜に寄るのは寒い夜のある世界だけ。暗闇も平温（20 度）だと、真昼の眠りのほうが多い（0.36〜0.45 対 0.31〜0.35）。そろえているのは夕暮れの寒さの読み（感じた消耗の上がり方、7-4 で受け入れた非対称）と強制の先読みの組み合わせで、視界の明るさの読みだけでは夜へ寄らない。
- 次にすること: O15 の扱いをユーザに確かめる（向きは満たすが、眠りの中心は夕暮れ。寒さを外すと昼に寄る）。

## 予想との照合（PLAN 7-3e）

| 予想 | 結果 |
| --- | --- |
| 夜の眠っている割合が昼より有意に高い（夜 0.3 以上・昼 0.2 以下） | 向きは当たり（暗闇 0.39〜0.40・真昼 0.22〜0.25）。中心は夕暮れ |
| 眠っている割合の合計は 22% 前後のまま | 外れ。32〜33% に増えた |
| 個体数は 7-3d より上がる（+0〜+10%） | 外れ。平坦 −13%、制約 −5%（有意でない） |
| 休める場所へ歩いて眠るのが少し増える（2〜4%） | 外れ。0.8% に下がった |
| 崩壊は増えない | 当たり（0 / 36） |
| 1 tick はほぼ同じ | 1体あたり +8%、ヒープ 267 → 446 MB |
