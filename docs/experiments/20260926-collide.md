# 衝突の数え上げ: 移動はどれだけ他の身体のいるタイルへ入るか

判断は [`docs/history/20260926.md`](../history/20260926.md) の「衝突: 数え上げ」。

## 概要

- 確かめたかったこと: 「他の身体が立っているタイルへは入れない」を入れる前に、それがどれだけの移動に効き、その移動が決めた tick か意図に従っている tick か。
- 分かったこと: **タイルをまたぐ移動の 91〜94% は意図に従っている tick に起きる**（決める tick は 6〜9%）。意図に従っていて塞がったタイルへ入る移動は身体×tick の 1.5%（平坦）・2.1%（制約）。塞がったタイルに食料があるのは 0.9% だけ。
- 次にすること: 「判断のときだけ占有タイルを候補から外す」だけでは衝突の 9 割に届かない。意図に従っている途中で塞がったときの扱いを決める（ユーザに確かめる）。

## 条件

| 項目 | 値 |
| --- | --- |
| コミット | 45e5f0c（世界のコードは 9db592c のまま） |
| マップ | flat (64x48) / constrained (64x48) |
| tick 数 | 20000（tick 5000 より後） |
| シード数 | 12（最初のシード 1） |

**再現方法**:

```
go run ./cmd/count -what collide -map flat -w 64 -h 48 -seeds 12 -ticks 20000
go run ./cmd/count -what collide -map constrained -w 64 -h 48 -seeds 12 -ticks 20000
```

「塞がっている」は tick の始めに他の身体が立っていたタイル（同じ tick のうちに先に動いた身体は、tick の始めの位置で数えた）。

## 結果: flat

| 量 | 値 |
| --- | --- |
| 他の身体と同じタイルにいる身体×tick の割合 | 0.06674 ± 0.00025 |
| タイルをまたぐ移動の、身体×tick あたりの割合 | 0.28019 ± 0.00031 |
| そのうち決めた tick の移動の割合 | 0.05781 ± 0.00018 |
| 塞がったタイルへの移動 ÷ タイルをまたぐ移動（決めた tick） | 0.08599 ± 0.00057 |
| 塞がったタイルへの移動 ÷ タイルをまたぐ移動（意図に従った tick） | 0.05720 ± 0.00018 |
| 意図に従っていて塞がったタイルへ入る移動の、身体×tick あたりの割合 | 0.01510 ± 0.00006 |
| 塞がったタイルへの移動のうち、そのタイルに食料があった割合 | 0.00922 ± 0.00013 |
