# 3-1: 性別（Sexes）

判断は [`docs/history/20260926.md`](../history/20260926.md) の「3-1 の測定」。事前カウントは [3-1-count](20260926-3-1-count.md)。

## 1. 概要

- 確かめたかったこと: 身体に性別を持たせ、異性の成人どうしだけが交配できるようにすると、世界の結果（出生・個体数・成人到達率）がどう変わるか。`sexless`（2-4）との対の差で読む。
- 分かったこと:
  - **出生が減った**: 平坦 −679 ± 44（−12%）、制約 −1,321 ± 131（−23%）。餓死もほぼ同じだけ減った（出生と餓死は釣り合う量）。予想（出生は食料で頭打ちなのでほとんど変わらない）は外れた。
  - **個体数**は平坦で有意でない（−0.92 ± 2.14）、制約で −14.75 ± 6.99（約 2 SE、シードの間で大きく散る。谷の最小 93）。成人到達率は変わらない。崩壊 0。
  - **成人の割合が上がった**（平坦 0.26 → 0.35、制約 0.25 → 0.42）。子が減り、子の代金を払う回数が減った大人が長く生きる。
  - **成人の性比が大きく片寄る**: 成人のうち少ない側の性の割合は平坦 0.33、制約 0.28（釣り合いは 0.5）。生まれるときは半々なので、片寄りは成人の死に方から来る。少ない側の性は相手に困らず交配を多く払い、子の代金で死にやすくなって、さらに少なくなる——という正の帰還を疑っている（確かめていない）。
  - 真後ろへの手がわずかに増え（+0.006〜0.015）、決定の割合が下がった（交配のきっかけが減った）。
- 次にすること: 3-2（寿命と老いによる死）の事前カウントで、性比の片寄りの仕組み（性別ごとの交配の回数と死んだ年齢）も数える。
