# 8-2c 事前カウント: 腐りにくさの効く余地（`cmd/count -what keeproom`）

判断は [`docs/history/20261005.md`](../history/20261005.md)。

## 1. 概要

- 確かめたかったこと: 定住場所（休める場所のタイル）の上で食料が腐りにくくなる規則（8-2c）が、置く手の無い今、どれだけの単位に触れるか。
- 分かったこと: **触れるのはどの地図でも全単位の 1% 未満。**
  - flat: 現れた単位のうち腐るのは 14%、腐りのうち定住場所の上は 6.7% → 積は約 0.9%。
  - constrained: 腐り 18% × 定住場所の上 2.8% → 約 0.5%。
  - patches: 食料が速く食べられ、そもそも腐りが 0.6%（定住場所の上の割合は 32% と高いが、母数が無い）。
- 読み: 置く手が無いうちは、食料が定住場所の上に来るのは湧きの偶然だけで、規則の意味は「送る・置く」（次の段階）で初めて生まれる。8-2c 単独では世界は動かない見込み。
- 次にすること: 規則を入れ、`unkept` と対の差で「動かない」ことを確かめて先へ進む。
