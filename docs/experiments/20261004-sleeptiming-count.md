# 7-3e の事前カウント: 強制される眠りを先読みする余地（`sleeptiming`）

判断は [`docs/history/20261004.md`](../history/20261004.md) の「7-3e の事前カウント」。

## 1. 概要

- 確かめたかったこと: 値付けが「あと何 tick で眠らされるか」を読み、今眠るか強制されるまで起きているかを比べられたら、夜に眠る方へ動く余地があるか。眠れて（睡眠圧が `WakeAt` を超え）まだ強制されていない成人の決定ごとに、今眠る場合と強制される時刻に眠る場合で、窓の起きている部分の真の視界の倍率（食料の見つけやすさ）と、眠っている間の寒さの倍率を比べた。
- 分かったこと:
  - **暗闇（明るさ 0）の決定では、今眠るほうが起きている部分の視界が 2 割明るい**（2.17 対 1.80）。今眠るほうが 10% 以上明るいのは 68〜71%。暗闇の決定は数として一番多い（1シードあたり 2.7〜4.9 万）。
  - 真昼では逆（1.81〜1.83 対 2.11〜2.15）、薄明はほぼ同じ。
  - **寒さは逆向き**: 暗闇で今眠ると眠りは寒い（1.20 対 1.09〜1.10）。休める場所で眠れば消える。
- 読み: 夜に眠る方へ動く余地は実在するが、それは**値付けが起きている時間の明るさの違いを読むとき**だけ。今の値付けは今の明るさが続くと読むので、先読みだけ足しても「今眠る」と「あとで眠る」の視界は同じに読まれ、寒さの差（夜に眠ると寒い）だけが残って夜から遠ざける。7-2b で残した学ぶ側（暗く・明るくなるまでの時間）から、起きている部分の平均の視界の倍率を出せば、表を増やさずに読める（窓の中を切り替える 7-2b の読み方と違い、倍率1つ）。
