# 4-4 食料が古びる（`FoodLife` 1000）

判断は [`docs/history/20261002.md`](../history/20261002.md) の「4-4 の測定」。

## 1. 概要

- 確かめたかったこと: 食料が現れてから 1000 tick で古び空きになる規則で、身体のいなくなった陸に閉じ込められる食料（[lock-count](20261002-lock-count.md)）が上限へ戻り、制約の地図の緩やかな崩壊が消えるか。普段の世界は動かないか。
- 分かったこと:
  - **崩壊（制約 84 シード）: `unspoiled` 6 → base 0。** 東の身体がいなくなったのは 9 対 6 で、率は変わらない（古びる規則は小集団を救わない）。
  - **東に積もる食料の最大は 64〜73 単位**（`unspoiled` は 215〜261）。見込み（約 65〜70）どおり。
  - 東がいなくなった世界は西だけで落ち着く: seed 3・53 で tick 8000 以降 107〜137（平均約 123）。
  - **平坦は1ビットも変わらない**（12 シードすべての指標で差 0）——平坦では 1000 tick 残る単位が無く、古びる規則は一度も働かなかった。
  - 制約の対の差（12 シード）は、崩壊を除いて有意な差なし（真後ろへの手 +0.0023 ± 0.0009 のみ2倍を越えるが小さい）。
- 読み: 罠は閉じ込めであり、古びる規則で外れた。孤立した小集団が消えること自体は残る（地図の作りの性質）。
- 次にすること: 5-4（M-1）へ戻る。罠が外れたので、5-4 の事前カウントの「薄い世界」の標本は今後ほとんど出ない。

## 予想との照合（PLAN 4-4）

| 予想 | 結果 |
| --- | --- |
| 平坦では何も動かない | 当たり（差 0。一度も古びなかった） |
| 東がいなくなる率は変わらない（36 シードで 6 前後） | 当たり（84 シードで 6 対 9） |
| 東に積もる食料は 100 を越えない（見込み 65〜70） | 当たり（64〜73） |
| そうなった世界は崩壊せず 110〜130 前後で落ち着く | 当たり（107〜137、平均約 123） |
| 崩壊は 6〜7% から 0〜1 へ | 当たり（6 / 84 → 0 / 84） |
| 東がいなくならなかったシードは有意に動かない | 当たり（対の差は崩壊のほか有意な差なし） |
| 1 tick は変わらない | 当たり（236 対 241 µs、`PARAMETERS.md`） |

## 完了条件（PLAN 4-4）

- 地面・手持ちが寿命で古びる・寿命の前に古びない・帳簿が閉じる（`TestFoodDecays`・`TestFoodLedgerClosesWithDecay`）、保存と読み込みで続く（`TestSaveLoadContinues`）: 満。
- 対の差（両方の地図、12 シード）・崩壊 84 シード（両条件）・`lock` 36 シード以上: 満（`lock` は 84 シード）。崩壊は減り、東が空になった世界は崩壊しない。
