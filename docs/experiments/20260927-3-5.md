# 3-5: 寿命と老いによる死（Lifespan 3000）

判断は [`docs/history/20260927.md`](../history/20260927.md) の「3-5 の測定」。前は [3-4](20260927-3-4.md)。

## 1. 概要

- 確かめたかったこと: 生まれて 3000 tick たった身体が死ぬ（死因「老い」）と、死因の割合・出生・個体数がどう変わるか。`ageless`（3-4）との対の差で読む。
- 分かったこと:
  - **老いによる死は死の 32〜35%**（予想 15〜20% の約 2 倍）。餓死は −41〜−46%——長く生きた身体が消えて食料が空き、ほかの身体が餓死しにくくなった。死んだ年齢の中央値は 1,400 → 2,100〜2,250 に上がり、3000 まで生きる身体が増えた。老いは半分を超えない（完了条件）。
  - 成人到達率 +0.10〜+0.11（0.67〜0.69 → 0.78〜0.79）。出生 −14〜−18%。成人のうち女の割合は 0.49 前後に戻った（3-4 の 0.51〜0.57 から）。
  - **個体数が下がった**: 平坦 −21.33 ± 1.87、制約 −39.17 ± 12.64。**制約の地図で 1 / 12 が崩壊**（seed 10、tick 19,267）、崩壊しなかったシードの谷の最小 76（seed 3）。
  - **崩壊の形（seed 10）**: 食料が尽きたのではなく、tick 13,000 ごろから出生が死を下回り続け、6,000 tick かけて 103 → 20 に減った（500 tick ごとに出生 5〜22、死 11〜30）。身体が薄くなると視界（3×3）に異性の成人が入りにくくなり、出生が減ってさらに薄くなる——**数が少ないと増えにくくなる罠**と読む（確かめていない）。寿命が無ければ、薄い世界で身体は長く生きていずれ相手に出会うが、寿命があると相手に出会う前に老いで死ぬ。
- 次にすること: 寿命の長さ（または崩壊の扱い）をユーザと決める。
