## 実験

```
go run ./cmd/experiment -map flat -w 64 -h 48 -seeds 12 -ticks 10000
```

| オプション | 意味 |
| --- | --- |
| `-map` | 地図。`flat`（全面が陸・地域1つ）/ `constrained`（地域4つ・陸を二分する水の帯） |
| `-w` / `-h` | 地図の幅・高さ（タイル数）。必須 |
| `-seeds` | シード数。必須 |
| `-seed0` | 最初のシード（既定 1） |
| `-ticks` | 1回の実行の tick 数。必須 |
| `-variants` | 比べる条件をカンマ区切りで。先頭が base（既定 `base`） |
| `-floor` | 崩壊の下限。個体数がこれ以下になったシードは、そこで計算を打ち切る（既定 0 ＝ 絶滅。1-3 で決める） |

標準出力に `MEASURE.md` の形式のレポート（§2〜§9 と補助の表）を出す。§2 には代表シード・定常化 tick と、それを再生する `cmd/client` のコマンド行（「UI での再生」）も出す。崩壊したシードは代表シードの候補から外すので、全シードが崩壊した実験では出ない。tick ごとの表は、生存しているシードだけの平均と生存シード数を出し、全シードが下限を割ったあとの行は省く。§1 概要は人が書く。シードごとの実行時間は標準エラーに出す。保存則の検算が合わない tick があれば、その場で止まる。

## クライアント（見る）

```
go run ./cmd/client -map constrained -w 64 -h 48 -seed 7 -from-tick 840
```

| オプション | 意味 |
| --- | --- |
| `-map` / `-w` / `-h` | 地図と大きさ。`cmd/experiment` と同じ。必須 |
| `-variant` | 条件（既定 `base`） |
| `-seed` | 世界の種（既定 1） |
| `-from-tick` | この tick まで描画せずに計算し、そこから描画する（既定 0） |
| `-scale` | 1タイルあたりのピクセル数（既定 12） |

実験のレポートに出た「UI での再生」の行をそのまま叩けば、その実験の典型的な1本を定常化 tick から見られる。

操作: スペースで一時停止、一時停止中は → で1 tick 進む、↑↓ で速さ（1フレームあたり 1〜64 tick）。

画面: 地面の色は地域、青は水、赤い四角は食料、丸は個体（白いほど体力が多く、黒いほど餓死に近い）。左上は tick・個体数・地面の食料・速さ。
