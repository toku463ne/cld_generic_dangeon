## 実験

```
go run ./cmd/experiment -map flat -w 64 -h 48 -seeds 12 -ticks 10000
```

| オプション | 意味 |
| --- | --- |
| `-map` | 地図。`flat`（全面が陸・地域1つ）/ `constrained`（地域4つ・陸を二分する水の帯） |
| `-w` / `-h` | 地図の幅・高さ（タイル数）。必須 |
| `-seeds` | シード数。必須 |
| `-seed0` | 最初のシード（既定 1） |
| `-ticks` | 1回の実行の tick 数。必須 |
| `-variants` | 比べる条件をカンマ区切りで。先頭が base（既定 `base`）。`base` は既定の設定、`random` は窓 0（無作為に選ぶ 1-1 の対照）、`blind` は視界なし・向きを保たない（1-2 の1回目）、`restless` は視界ありで向きを保たない（1-2p） |
| `-floor` | 崩壊の下限。個体数がこれ以下になったシードは、そこで計算を打ち切る（既定 0 ＝ 絶滅。1-3 で決める） |

標準出力に `MEASURE.md` の形式のレポート（§2〜§9 と補助の表）を出す。§2 には代表シード・定常化 tick と、それを再生する `cmd/client` のコマンド行（「UI での再生」）も出す。崩壊したシードは代表シードの候補から外すので、全シードが崩壊した実験では出ない。tick ごとの表は、生存しているシードだけの平均と生存シード数を出し、全シードが下限を割ったあとの行は省く。§1 概要は人が書く。シードごとの実行時間は標準エラーに出す。保存則の検算が合わない tick があれば、その場で止まる。

## クライアント（見る）

```
go run ./cmd/client -map constrained -w 64 -h 48 -seed 7 -from-tick 840
```

| オプション | 意味 |
| --- | --- |
| `-map` / `-w` / `-h` | 地図と大きさ。`cmd/experiment` と同じ。必須 |
| `-variant` | 条件（既定 `base`） |
| `-seed` | 世界の種（既定 1） |
| `-from-tick` | この tick まで描画せずに計算し、そこから描画する（既定 0） |
| `-scale` | 1タイルあたりのピクセル数（既定 12） |
| `-follow` | 追う個体。ID か `hungriest`（`-from-tick` の時点で体力が一番少ない個体）。既定は追わない |

実験のレポートに出た「UI での再生」の行をそのまま叩けば、その実験の典型的な1本を定常化 tick から見られる。

操作: スペースで一時停止、一時停止中は → で1 tick 進む、↑↓ で速さ（1フレームあたり 1〜64 tick）、`[` `]` で下の履歴の幅（1ピクセルあたり 1〜256 tick）、クリックでその個体を追う（何も無いところをクリックでやめる）、`f` で体力が一番少ない個体を追う、`t` で全員の軌跡。

画面:
- 地面の色は地域、青は水、赤い四角は食料、丸は個体（白いほど体力が多く、黒いほど餓死に近い）。軌跡は直近 300 tick の位置。
- 追っている個体は黄色。枠は視界、線は向き、食料へ伸びる線は直前の決定で歩いて食べると読んだ食料。左上の文字に体力・年齢・向きと、直前の決定の手を死ぬ確率の低い順に出す（`via` はその確率をどの続きで読んだか）。
- 下の帯は tick 0 からの履歴で、右端が今。白が個体数、赤が地面の食料、0 からの目盛り。縦の線は 1000 tick ごと（1ピクセル 64 tick 以上では 10000 tick ごと）。**1ピクセルに入る tick の最小と最大を縦の線で描く**ので、1ピクセルより速い周期は帯として見え、遅い波のようには見えない。

## 画面の無いところで見る

```
go run ./cmd/shot -map constrained -w 64 -h 48 -seed 2 -from-tick 20000 -follow hungriest -trails -out shots -shots 4 -every 300
```

`cmd/client` と同じ絵を PNG に書き、左上に出る文字を標準出力に出す。オプションは `cmd/client` と同じものに加えて、`-out`（書き出すディレクトリ。必須）、`-shots`（枚数。既定 1）、`-every`（間の tick 数。既定 300）、`-trails`（全員の軌跡）。ファイル名は `地図-条件-s種-t tick.png`。ebiten は import しただけで画面を要求するので、描画は `view` パッケージに置き、窓を開くのは `cmd/client` だけにしてある。

## 実装前の数え上げ

```
go run ./cmd/count -what reach -map flat -w 64 -h 48 -seeds 12
```

| `-what` | 数えるもの |
| --- | --- |
| `reach` | 食料だけの世界での、最寄りの食料までの距離と到達比 |
| `underfoot` | 1-1 の世界（`random`）で、足元に食料が来た頻度（必ず食べたら食べられた頻度）と釣り合いの頻度の比。`-ticks` が必須 |
| `split` | 1-1 の世界（`random`）で、真の表の値付けで最善と2番目の手に差がつく決定の割合と、足元に食料があるとき「食べる」が単独で最善の割合。窓の長さ・体力の帯ごと。`-ticks` が必須、`-every`（既定 50）で読む間隔 |
| `sight` | `base` の世界で、視界の半径（0・1・2・3・5・8。自分のタイルを中心とする (2r+1)×(2r+1) のタイル）ごとに、視界に食料がある割合、新しく食料が見えた頻度と釣り合いの比、一番近い見えている食料までの距離。`-ticks` が必須 |
| `forage` | `base` の世界で、足元に食料がある決定を体力の帯ごとに（食べた割合・食べるが同点で最善の割合）、空腹の身体の視界に食料がある割合、満腹から餓死までの tick 前の位置からの距離、最善の手が同点の決定の割合と、そこで直前の移動が最善の手の中にある割合。`-ticks` が必須 |
| `cycle` | `base` の世界で、地面の食料の周期（いくつかのずれでの自己相関）、生きている身体の「体力 mod 1食」がとる値の数、食料の谷の位相に死亡が偏るか、区間ごとの振れ幅と人口。全員が満腹で同時に始まる世界と、始めの体力をばらした世界の両方で出す。`-ticks` が必須 |
| `explore` | `blind`・`restless`・`base` の世界で、窓（0〜1000・9000〜10000 tick）ごとの未踏タイル率・食料視認率と窓のあとの寿命の順位相関、1000 tick ごとの窓を通して生きていた身体が次の 1000 tick で死ぬかを未踏タイル率・食料視認率・体力で見分ける AUC。`-ticks` が必須 |
| `shuttle` | `base` の世界で、tick 5000 より後の死亡のうち直線の往復（直前の 1000 tick の位置の広がりが x か y で 1 タイル未満）で終わった割合と、生きている身体のうち往復している割合・向きが軸に沿っている割合（tick 5000・10000・20000・40000）。`-ticks` が必須 |
| `meet` | `random` と `base` の世界で、個体が入ったタイルのうち食料があった割合と、真の表の3行目の読み（その地域の食料 ÷ 陸のタイル数）の比。`-ticks` が必須 |
